## 本层内容介绍

这里是“高级语言程序设计”课程下的“课件与复习”目录，主要用于整理课堂讲授、章节讲义或复习课件。

**阅读建议：**按课堂章节顺序阅读，记录核心概念与例题；复习时回到不熟悉的章节查漏补缺。

### 本层有哪些内容

本目录及子目录共收录 **14 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（11 份）**：[VsCode的安装和C++程序的运行环境配置方法.pdf](VsCode%E7%9A%84%E5%AE%89%E8%A3%85%E5%92%8CC%2B%2B%E7%A8%8B%E5%BA%8F%E7%9A%84%E8%BF%90%E8%A1%8C%E7%8E%AF%E5%A2%83%E9%85%8D%E7%BD%AE%E6%96%B9%E6%B3%95.pdf)、[期末模拟卷1.pdf](%E6%9C%9F%E6%9C%AB%E6%A8%A1%E6%8B%9F%E5%8D%B71.pdf)等；完整列表见本页导航。
- **演示文稿（3 份）**：[单向链表.pptx](%E5%8D%95%E5%90%91%E9%93%BE%E8%A1%A8.pptx)、[网上练习系统使用方法.pptx](%E7%BD%91%E4%B8%8A%E7%BB%83%E4%B9%A0%E7%B3%BB%E7%BB%9F%E4%BD%BF%E7%94%A8%E6%96%B9%E6%B3%95.pptx)等；完整列表见本页导航。
