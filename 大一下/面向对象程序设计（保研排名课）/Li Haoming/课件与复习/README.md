## 本层内容介绍

这里是“面向对象程序设计”课程下的“课件与复习”目录，主要用于整理课堂讲授、章节讲义或复习课件。

**阅读建议：**按课堂章节顺序阅读，记录核心概念与例题；复习时回到不熟悉的章节查漏补缺。

### 本层有哪些内容

本目录及子目录共收录 **8 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（8 份）**：[C++复习 2026.docx](C%2B%2B%E5%A4%8D%E4%B9%A0%202026.docx)、[C++模拟题2026.docx](C%2B%2B%E6%A8%A1%E6%8B%9F%E9%A2%982026.docx)等；完整列表见本页导航。
