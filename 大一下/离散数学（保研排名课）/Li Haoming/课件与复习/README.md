# 课件与复习

<!-- directory-guide:start -->
## 本层内容介绍

这里是“离散数学”课程下的“课件与复习”目录，主要用于整理课堂讲授、章节讲义或复习课件。

**阅读建议：**按课堂章节顺序阅读，记录核心概念与例题；复习时回到不熟悉的章节查漏补缺。

### 本层有哪些内容

本目录及子目录共收录 **8 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **演示文稿（1 份）**：[LS课程总结.ppt](LS%E8%AF%BE%E7%A8%8B%E6%80%BB%E7%BB%93.ppt)。
- **文档与说明（7 份）**：[第1章-命题逻辑(校订版).pdf](%E7%AC%AC1%E7%AB%A0-%E5%91%BD%E9%A2%98%E9%80%BB%E8%BE%91%28%E6%A0%A1%E8%AE%A2%E7%89%88%29.pdf)、[第2章-谓词逻辑(校订版).pdf](%E7%AC%AC2%E7%AB%A0-%E8%B0%93%E8%AF%8D%E9%80%BB%E8%BE%91%28%E6%A0%A1%E8%AE%A2%E7%89%88%29.pdf)等；完整列表见本页导航。
