# 培养方案与推免参考

本目录保存维护者提供的四份原始文件，供学期、专业、课程性质和推免属性核对。原始 Word、Excel、PDF 不作改写。

- 2023 计科、软工培养方案：用于课程建议学期、必修/限修/选修和专业归属。
- 2027 届学院推免细则：第 3 页说明学业成绩采用本科前三学年专业免研排名课程的平均成绩，并规定考试成绩的计算口径。
- 推免课程导出表：按“专业 + 课程代码/名称”区分“是否资格课”和“是否排名课”；二者不能混为一谈。

非课程资料只在直接支持本次培养方案或推免核对时作为参考收录。竞赛项目补充表感谢 **Li Haoming** 提供；原始资料版权及署名不变。
