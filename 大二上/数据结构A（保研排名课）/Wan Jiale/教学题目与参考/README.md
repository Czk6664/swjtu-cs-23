## 本层内容介绍

这里是“数据结构A”课程下的“教学题目与参考”目录，主要用于整理教学题目、思考题或配套参考材料。

**阅读建议：**先独立分析题目，再对照已有参考材料检查思路；是否含解答以具体文件为准。

### 本层有哪些内容

本目录及子目录共收录 **5 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（5 份）**：[习题6-7-4题目.pdf](%E4%B9%A0%E9%A2%986-7-4%E9%A2%98%E7%9B%AE.pdf)、[习题9-10-4题目.pdf](%E4%B9%A0%E9%A2%989-10-4%E9%A2%98%E7%9B%AE.pdf)等；完整列表见本页导航。
