## 本层内容介绍

这里是“数字电子技术实验”课程下的“实验指导与参考”目录，主要用于整理实验目的、步骤或操作参考材料。

**阅读建议：**实验前阅读准备事项与操作过程，明确要观察和记录的结果，再动手完成实验。

### 本层有哪些内容

本目录及子目录共收录 **10 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（10 份）**：[可逆计数器芯片74HC190.pdf](%E5%8F%AF%E9%80%86%E8%AE%A1%E6%95%B0%E5%99%A8%E8%8A%AF%E7%89%8774HC190.pdf)、[实验2-从代码到电路202410.pdf](%E5%AE%9E%E9%AA%8C2-%E4%BB%8E%E4%BB%A3%E7%A0%81%E5%88%B0%E7%94%B5%E8%B7%AF202410.pdf)等；完整列表见本页导航。
