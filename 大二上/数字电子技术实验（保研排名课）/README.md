## 本层内容介绍

**课程入门：**数字电子技术实验的学习方向是数字电路的搭建、测试和实验验证。

**建议学习方法：**先读实验指导，确认逻辑功能和接线要求，再完成电路验证并记录实际现象。

下方“本层有哪些内容”展示本仓库实际收录的资料，课程方向介绍不代表这里已覆盖全部教学内容。先按资料类别或贡献者选择入口，再阅读对应文件；课程安排和推免属性见本页原有表格。
