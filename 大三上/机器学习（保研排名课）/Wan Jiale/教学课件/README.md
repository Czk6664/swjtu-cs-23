## 本层内容介绍

这里是“机器学习”课程下的“教学课件”目录，主要用于整理课堂讲授、章节讲义或复习课件。

**阅读建议：**按课堂章节顺序阅读，记录核心概念与例题；复习时回到不熟悉的章节查漏补缺。

### 本层有哪些内容

本目录及子目录共收录 **1 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（1 份）**：[第5章+神经网络.pdf](%E7%AC%AC5%E7%AB%A0%2B%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C.pdf)。
