2  一阶谓词逻辑表示法
n 命题： 一个非真即假的陈述句
    若命题的意义为真 ，称它的真值为真， 记为 T。 例如： 3<5
     若命题的意义为假 ，称它的真值为假， 记为 F。 例如： 太阳从西边升起
     一个命题可在一种条件下为真 ，在另一种条件下为假 。例: 1＋1＝10
n 谓词： P (x1, x2,…, xn)
    命题个体 x1, x2, … , xn ： 某个独立存在的事物或者某个抽象的概念；
    谓词名 P： 刻画个体的性质 、状态或个体间的关系 。
个体是常量：
一元谓词 Teacher (Zhang)： “老张是一个教师 ”
二元谓词 Greater (5, 3)： “5>3”
三元谓词 Works (Smith, IBM, engineer)： “Smith作为一个工程师为IBM工作 ”
个体是变量： “x<5” ： Less(x, 5)
个体是函数： Teacher (father (Li) )
个体是谓词： 二阶谓词 Works (engineer (Smith), IBM)

2  一阶谓词逻辑表示法
n 主要优点
    自然：接近于自然语言的形式，接近于人们对问题的直观理解
   明确：表示的知识明确 、易于理解
   精确：谓词逻辑的真值只有“真 ”与“假 ”，其表示 、推理都是精确的
   灵活：知识和处理知识的程序是分开的，无须考虑处理知识的细节
n 主要缺点
   知识表示能力差：只能表示确定性知识 ，不能表示非确定性知识
   知识库管理困难：缺乏知识的组织原则，知识库管理比较困难
   存在组合爆炸：使用推理规则， 当系统知识量较大时，容易组合爆炸
   系统效率低：把推理与知识含义截然分开，推理过程冗长，系统效率低

3  产生式表示法
n 产生式系统组件功能设计
  规则库: 用于描述相应领域内知识的产生式集合
  综合数据库：用于存放问题求解过程中各种当前信息的数据结构
  控制系统（推理机构）：推理机核心程序 ，负责整个产生式系统的运行 ，实现对问题的求解



控制系统功能：
  从规则库中选择与综合数据库中的已知事实进行匹配 。
  匹配成功的规则可能不止一条 ，进行冲突消解 。
  执行某一规则时 ，如果其右部是一个或多个结论 ，则把这些结论加入到综合数据库中如果其右部是一个或多个操作 ，则执行这些操作 。
  对于不确定性知识 ，在执行每一条规则时还要按一定的算法计算结论的不确定性 。
  检查综合数据库中是否包含了最终结论 ，决定是否停止系统的运行 。

4  框架表示法
n 1975年， 明斯基提出了框架表示法： 人们对现实世界中各种事物的认识都是以一种类似于框架的结构存储在记忆中 。
n 框架（frame ）是一种描述所论对象（事物 、事件或概念）属性的数据结构 。

   一个框架由若干个被称为“槽 ”（slot） 的结构组成， 每一个槽又可根据实际情况划分为若干个“侧面 ”（faced） 。
   一个槽用于描述所论对象某一方面的属性。
   一个侧面用于描述相应属性的一个方面。
   槽和侧面所具有的属性值分别被称为槽值和侧面值。

4  框架表示法
   示例： 将下列一则地震消息用框架表示： “某年某月某日， 某地发生
6.0级地震， 若以膨胀注水孕震模式为标准， 则三项地震前兆中的波速比为0.45， 水氡含量为0.43， 地形改变为0.60。 ”

n 常见等价式

1.3 机器学习评价


• P表示算法预测这个样本为1（好西瓜） ；
• N表示算法预测这个样本为0（坏西瓜） ；
• T表示算法预测的和真实情况一样， 即算法预测正确，
• F表示算法预测的和真实情况不一样， 即算法预测不对 。
• TP： 正确地标记为正， 即算法预测它为好西瓜 ，这个西瓜真实情况也是好西瓜  (双重肯定是肯定） ；
• FP：错误地标记为正， 即算法预测它是好西瓜 ，但这个西瓜真实情况是坏西瓜；
• FN：错误地标记为负， 即算法预测为坏西瓜，（ F算法预测的不对） 但这个西瓜真实情况是好西瓜（双重否定也是肯定） ；
• TN： 正确地标记为负， 即算法标记为坏西瓜，（ T算法预测的正确） 这个西瓜真实情况是坏西瓜 。

1.4 集成学习
   Boosting
•   个体学习器存在强依赖关系： 每个弱学习器不是独立构建的， 而是依赖于前一个学习器的输出和错误 。 即 每个弱学习器的目标是弥补之前模型的不足，共同提高整体模型的性能。
•    串行生成
•   每次调整训练数据的样本分布： 每一轮训练后增加被前一轮模型错误分类的样本的权重， 从而使后续的弱学习器更关注这些难分类的样本。

1.4 随机森林


 随机森林 (Random Forest， 简称 RF) 是 bagging 的一个扩展变种
 数据采样的随机性
 特征/属性选择的随机性




随机森林 （Random Forest） 是在 Bagging 的基础上再引入了随机特征， 进一步提高每个基模型之间的独立性 。在随机森林中， 每个基模型都是一棵决策树。

1.4 随机森林
n 随机森林案例： 判断蘑菇有没有毒
假设有一堆蘑菇，每只蘑菇有颜色 、形状 、气味等特征，要判断它有没有毒。
  单棵决策树： 可能因为某次训练数据中“红色=有毒 ”太多，就死记硬背“所有红色蘑菇都有毒 ”——但现实中可能有例外，导致过拟合。
  随机森林：
随机选数据： 从所有蘑菇中有放回地随机抽样（比如抽1000次，有些蘑菇被抽多次，有些没被抽到） 。
随机选特征： 每棵树在判断时，只看一部分特征（比如有的树只看颜色+气味，有的看形状+大小），避免所有树都依赖同一个强特征。
每棵树独立判断： 每棵树都用自己的数据和特征训练，给出“有毒 ”或“无毒 ”。

即使个别树犯错， 整体结果依然稳健！

1.4 随机森林

随机森林的三大“ 随机 ”之处
1.数据随机： 每棵树用不同的训练子集 。
2.特征随机： 每棵树分裂节点时， 只从随机子集中选最佳特征（比如总共有20个特征， 每次只看5个） 。
3.结构随机： 由于数据和特征都随机， 每棵树长得都不一样 。
正是这种“多样性 ”， 让随机森林不容易过拟合， 泛化能力很强 。

BP算法的缺点

1. 梯度消失（ Vanishing Gradient ）
•现象：在深层网络中，反向传播时梯度逐层相乘，若激活函数导数小于 1 （如 Sigmoid 、Tanh），梯度会指数级衰减。
•后果： 靠近输入层的权重几乎不更新，深层网络难以训练。
•典型场景：使用 Sigmoid 激活的 5 层以上网络，训练停滞。


2. 梯度爆炸（ Exploding Gradient ）
•现象：某些权重过大时，梯度在反向传播中指数级增长。
•后果：参数更新剧烈，损失发散，训练崩溃。
•典型场景： RNN 中更常见，但在深层 MLP 中也可能出现。

1.3 深度学习模型
n 各种深度卷积网络      残差模块为什么有效？
问题背景： 深度网络的“退化 ”
•   理论上， 更深的网络至少不应比浅层网络差 。但实验发现 当网络深度增加到一定程度（如 >20 层）  ,  训练误差反而上升——并非过拟合， 而是优化困难 ，称为 退化问题
核心思想：
•   不直接学习目标映射 H(x)， 而是学习残差映射 F(x)=H(x)−x
•   标准网络： 希望几层堆叠后输出 H(x)                       其中x 通过捷径连接
•   残差网络： 让堆叠层学习 F(x)， 最终输出为：          （shortcut/skip connection）直接加到输出上

•   在反向传播时 ，梯度可通过 shortcut 直接回传到浅层：即使              ，梯度仍能通过 +1 项传递 ，避免完全消失
•   加速收敛： 梯度更稳定 ，训练更快
•   模块化设计 ，残差块可灵活堆叠

1.3 深度学习模型
n 卷积神经网络的特性


局部连接（ Local Connectivity ）
•每个神经元只与输入的局部区域（感受野）连接，而非全连接。
•大幅减少参数量，避免过拟合。


权值共享（ Weight Sharing）
•同一个卷积核在整个输入上滑动，参数共享。
•进一步减少参数，提升平移鲁棒性。

平移等变性 / 平移不变性
•卷积层具有平移等变性（输入平移 → 特征图平移）；
•池化/全连接层引入平移不变性（小范围平移不影响最终分类） 。

1.3 深度学习模型
n 卷积神经网络的特性
1. 对几何变换敏感
•   缺乏旋转 、缩放 、仿射不变性：标准 CNN 无法识别旋转后的物体（除非数据增强覆盖该角度） 。
•   解决方案：数据增强 、STN（空间变换网络） 、等变 CNN 。
2. 长距离依赖建模弱
•   卷积核感受野有限 ，难以建模图像中远距离像素的关系（如“天空在顶部 ，地面在底部 ”） 。
•   解决方案：引入注意力机制 。
3. 空间信息在深层丢失
•   多次下采样（stride/pooling） 导致精确定位能力下降， 不利于分割 、关键点检测 。
•   解决方案：编码器-解码器结构（如 U-Net） 、空洞卷积 、特征金字塔 。
4. 固定输入尺寸限制（传统 CNN）
•   全连接层要求固定输入尺寸 。
•   现代改进：用全局平均池化（ GAP ）替代 FC 层， 支持任意尺寸输入 。

Long Short-Term Memory

LSTM 的核心思想： 不是让所有信息都无差别地传递， 而是通过‘ 门 9 来
决定： 哪些信息要保留， 哪些要丢弃， 哪些要输出
•   标准 RNN 的隐藏状态更新是“全有或全无 ”的，容易遗忘早期信息；
•   LSTM 引入了细胞状态（ Cell State）作为“主干记忆通道 ”，并通过三个门（ Gate）来调控信息的写入 、删除和读取；
•   这种设计使得 LSTM 能够选择性地长期保存重要信息， 同时过滤无关噪声。

1.1  搜索的概念
n 基本概念



求解一个问题时， 涉及两个方面：一是该问题的表示， 如果一个问题找不到一个合适的表示方法，就谈不上对它求解。
另一方面则是选择一种相对合适的求解方法 。由于绝大多数需要人工智能方法求解的问题缺乏直接求解的方法， 而搜索可以作为一种求解问题的通用策略。

1.1  搜索的概念
n 基本概念
定义： 根据问题的实际情况， 利用已有知识， 构造一条代价较小的推理路径，使问题得到解决的过程 。
本质： 在状态空间中寻找从初始状态到目标状态的一条有效路径 。
  搜索中需要解决的核心问题


1.1  搜索的概念
n 搜索策略
  按照搜索方向划分：
•    正向搜索（数据驱动） ： 从初始状态出发 →  目标（如广度优先搜索BFS 、深度优先搜索DFS）
•    逆向搜索（ 目的驱动） ： 从目标状态反推 → 初始
•    双向搜索： 两端同时搜索， 中间汇合（效率更高）

  按照信息运用方式划分：
•    盲目搜索： 不利用问题领域知识， 按固定策略遍历状态空间
•    启发式搜索： 利用问题领域知识（启发信息） 引导搜索，减少盲目扩展 。

定义： 在所搜过程中， 首先扩展最新产生的(即最深的)节点的方式称为深度优先搜索(depth-first search) 。深度相等的节点可以任意排列 。

•       兼具 BFS 的完备/最优性 + DFS 的低空间消耗！

1.3  启发式搜索
n 盲目搜索的不足： 效率低， 耗费过多的计算空间与时间 。
通过分析宽度优先 、深度优先搜索算法,其主要的差别是OPEN表中待扩展节点的顺序问题 。怎么找到一种方法用于排列待扩展节点的顺序， 即选择最有希望的节点加以扩展，搜索效率将会大为提高。
n 启发信息的引入：  搜索过程一般需要某些有关具体问题领域特性的 、与具体问题求解过程有关的 、并可指导搜索过程朝着最有希望方向前进的控制信息， 我们把此种信息叫做启发信息 。启发信息一般可分为以下三类：
（辅助选择节点） 用于扩展节点的选择, 即决定应先扩展哪一个节点, 以免盲目扩展。
（辅助选择操作算子） 用于生成节点的选择,决定应生成哪些后续节点,以免盲目地生成过多无用节点。
（辅助删除节点） 用于删除节点的选择,即决定应删除哪些无用节点（剪枝） , 以免造成进一步的时空搜索浪费。

1.3  启发式搜索
n把利用启发信息的搜索方法叫做启发式搜索方法
  在状态空间搜索中 ，启发式被定义成一系列操作算子，并能从状态空间中选择最有希望到达问题解的路径 。
  启发式策略： 利用与问题有关的启发信息进行搜索 。
n核心思想
利用问题领域知识（启发信息） 引导搜索， 减少盲目扩展 。
n 本节课重点关注第一种启发信息的运用
用于扩展节点的选择, 即决定应先扩展哪一个节点, 以免盲目扩展 。这种搜索总是选择“最有希望 ”的节点作为下一个被扩展的节点 。

反证法： 假设最优路径代价为C*， 但是该算法返回的路径代价为C>C*， 那么最优路径上一定存在某个未扩展的节点n（如果最优路径上的所有节点都被扩展，那么算法返回的就是C*， 而不会大于它） 。
f(n)>C*  (否则n将是已经扩展节点）
f(n)=g(n)+h(n) (根据定义)
f(n)=g*(n)+h(n) (因为n在一条最优路径上)
f(n)<=g*(n)+h*(n) (根据可容许性质， h(n)<=h*(n))
f(n)<=C* (根据定义 C*=g*(n)+h*(n))
得出矛盾结论 ，反证了A*一定只返回代价最优路径！

1.3 强化学习概述
n 机器学习回顾     机器学习分类
  监督学习：通过学习从输入到输出的映射关系来进行模型训练，训练数据样本含有标签， 即每个输入样本都有与之对应的输出相关联。

  无监督学习：从未标记的数据中学习数据的结构 、模式或分布，训练数据不包含目标变量。


  强化学习：通过观察环境 、执行动作并从奖励中学习， 旨在使智能体在环境中学会采取一系列动作， 以最大化累积奖励。

1.3 强化学习概述
n 强化学习vs.机器学习




















强化学习与监督学习的区别?
    没有监督者， 只有奖励/惩罚信号
    反馈是延迟的， 不是顺时的
    时序性强， 不适用于独立分布数据
    Agent行为会影响后续信息的接收

1.3 强化学习概述
n 强化学习的提出
   1953到1957年， Bellman提出了求解最优控制问题的一个有效方法动态规划（dynamic programming） 。
   1957年， Bellman还提出了最优控制问题的随机离散版本， 就是著名的马尔可夫决策过程（ Markov decision processe, MDP）
   1960年， Howard提出马尔可夫决策过程的策略迭代方法， 这些都成为现代强化学习的理论基础。
   1989年，Watkins提出了Q-Learning ，也把强化学习的三条主线扭在了一起。
    2016年， Deep Mind用深度强化学习设计实现AlphaGo， 人机对战打败李世石。

1.3 强化学习概述
n 强化学习背景
强化思想最先来源于心理学的研究 。1911年Thorndike提出了效果律（ Law of Effect ）：一定情景下让动物感到舒服的行为,  就会与此情景增强联系 (强化)  , 当此情景再现时, 动物的这种行为也更易再现；相反 ，让动物感觉不舒服的行为 ，会减弱与情景的联系 ，此情景再现时 ，此行为将很难再现 。换个说法， 哪种行为会“记住 ”，会与刺激建立联系 ，取决于行为产生的效果。

关键点：
•主网络频繁更新 ，用于预测当前 Q 值；
•目标网络冻结一段时间 ，用于提供稳定的 TD 目标；
•二者不是同步更新， 而是“主网络跑， 目标网络偶尔抄作业 ”。

如果没有目标网络（即 Q,=Q）： 当你更新 θ 时 ，预测值和目标值同时变化 → 就像“追着自己的尾巴跑” ，容易发散 。
引入目标网络后：y 由固定参数 θ-决定 ，在 C 步内不变 。所以优化目标是静态的 ，梯度方向更可靠 。

   句法分析： 对句子和短语的结构进行分析， 找出词 、短语等的相互关系以及各自在句子中的作用等 。在语言自动处理的研究中， 句法分析的研究是最为集中的， 这与乔姆斯基 （Chomsky） 的贡献是分不开的。 主要方法有： 上下文无关文法 、句法分析树 、格文法 、转移网络等。
   语义分析： 通过分析找出词义， 结构意义及其结合意义， 从而确定语言所表达的真正 （实际） 含义或概念 。在语言自动理解中， 语义越来越成为一个重要的研究内容。（尤其是对话系统）

 最大匹配法： 在计算机中存放一个分词用词典， 从待切分的文本中按自左到右的顺序截取一个定长的汉字串， 与词典中的词进行匹配， 若匹配不成功， 则把该字符串从右边逐次减去一个汉字， 再与词典中的词进行匹配，直到成功为止。

  逐词遍历匹配法： 逐词遍历匹配法中存放的词按由长到短的顺序， 逐个与待切分的语料文本进行匹配， 直到把文本中的所有词都切分出来为止。

   计算Attention权重







 点积结果取softmax ，得到Attention权重(0-1之间);
 softmax函数将点积结果转换为0到1之间的值， 即将原始得分转换为概率分布， 表示每个token相对于其他所有token的Attention权重；
  由于点积操作的结果可能非常大， 因此引入缩放因子(输入维度dk的平方根)， 让输入保持在一个合理的范围内；

多头注意力拼接
并行运行缩放点积注意力，独立的注意力输出矩阵通过Concat连接并线性转换为预期的维度
