## 本层内容介绍

这里是“计算机网络”课程下的“课件”目录，主要用于整理课堂讲授、章节讲义或复习课件。

**阅读建议：**按课堂章节顺序阅读，记录核心概念与例题；复习时回到不熟悉的章节查漏补缺。

### 本层有哪些内容

本目录及子目录共收录 **7 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（7 份）**：[CH2_物理层V2.4.pdf](CH2_%E7%89%A9%E7%90%86%E5%B1%82V2.4.pdf)、[Ch1_概述_v2.3.pdf](Ch1_%E6%A6%82%E8%BF%B0_v2.3.pdf)等；完整列表见本页导航。
