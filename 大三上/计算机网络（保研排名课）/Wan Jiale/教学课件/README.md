## 本层内容介绍

这里是“计算机网络”课程下的“教学课件”目录，主要用于整理课堂讲授、章节讲义或复习课件。

**阅读建议：**按课堂章节顺序阅读，记录核心概念与例题；复习时回到不熟悉的章节查漏补缺。

### 本层有哪些内容

本目录及子目录共收录 **3 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（3 份）**：[Ch5_网络层_V2.4.pdf](Ch5_%E7%BD%91%E7%BB%9C%E5%B1%82_V2.4.pdf)、[Ch6_传输层_V2.4.pdf](Ch6_%E4%BC%A0%E8%BE%93%E5%B1%82_V2.4.pdf)等；完整列表见本页导航。
