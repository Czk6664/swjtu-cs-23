## 本层内容介绍

这里是“计算机网络”课程下的“xhl课件”目录，主要用于整理课堂讲授、章节讲义或复习课件。

**阅读建议：**按课堂章节顺序阅读，记录核心概念与例题；复习时回到不熟悉的章节查漏补缺。

### 本层有哪些内容

本目录及子目录共收录 **12 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（6 份）**：[Computer Networking A Top-Down Approach (7th Edition).pdf](Computer%20Networking%20A%20Top-Down%20Approach%20%287th%20Edition%29.pdf)、[ch1_引言.pdf](ch1_%E5%BC%95%E8%A8%80.pdf)等；完整列表见本页导航。
- **演示文稿（6 份）**：[ch1_引言.pptx](ch1_%E5%BC%95%E8%A8%80.pptx)、[ch2_物理层.pptx](ch2_%E7%89%A9%E7%90%86%E5%B1%82.pptx)等；完整列表见本页导航。
