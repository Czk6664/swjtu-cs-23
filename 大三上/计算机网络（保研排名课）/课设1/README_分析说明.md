## PPPoE协议分析

### Session阶段数据包

- **总数**: 647个
- **Session ID**: 0x8cfb (36091)
- **客户端MAC**: b0:25:aa:5b:26:c4
- **服务器MAC**: 00:00:5e:00:01:01
- **客户端IP**: 10.169.227.162

### 典型头部字段(数据包#1)

```
以太网: 目标MAC(00:00:5e:00:01:01) + 源MAC(b0:25:aa:5b:26:c4) + 类型(0x8864)
PPPoE: Version(1) + Type(1) + Code(0x00) + Session ID(0x8cfb) + Length(42)
PPP: Protocol(0x0021 = IPv4)
IP: 源IP(10.169.227.162) + 目标IP(101.91.29.17) + 协议(TCP)
TCP: 源端口(63067) + 目标端口(443) + 标志(ACK)
```

## 如何使用

### 查看报告
1. 打开 `课设答案总结.md` - 获取简洁答案
2. 打开 `教务处网站访问完整分析报告.md` - 查看详细分析

### 使用Wireshark查看数据包
```bash
# 打开文件
wireshark 程泽凯.pcapng

# 过滤特定数据包
frame.number == 140  # 查看第140号数据包
frame.number >= 140 && frame.number <= 146  # 查看TCP三次握手

# 过滤协议
pppoes  # 只显示PPPoE Session包
tcp.port == 443  # 只显示HTTPS流量
dns  # 只显示DNS包
```

### 运行分析脚本
```bash
# 生成完整报告
python generate_complete_report.py

# 分析登录信息
python analyze_jwc_login.py

# 导出数据包详情
python export_packet_details.py > 输出.txt
```
