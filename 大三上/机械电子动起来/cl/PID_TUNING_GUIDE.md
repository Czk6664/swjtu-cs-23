# PID自动调参指南

## 📋 文件说明

### 1. **grid_search_tuner.ino** - 基础网格搜索
- **测试数量**: 125次 (5×5×5)
- **总耗时**: ~10分钟
- **搜索范围**: 
  - Kp: 12.0 - 20.0
  - Ki: 0.5 - 2.0
  - Kd: 0.008 - 0.020
- **适合**: 快速找到可用参数

### 2. **advanced_tuner.ino** - 自适应精细搜索 ⭐推荐
- **测试数量**: 250次 (两阶段各125次)
- **总耗时**: ~20分钟
- **搜索策略**: 
  - 阶段1: 粗搜索大范围
  - 阶段2: 精细搜索最优区域
- **适合**: 获得最优参数

## 🚀 使用步骤

### 步骤1: 上传程序
```
1. 打开 advanced_tuner.ino（推荐）或 grid_search_tuner.ino
2. 连接Arduino
3. 上传程序
```

### 步骤2: 准备测试
```
1. 将小车放置在平坦地面
2. 手扶小车保持直立状态
3. 打开串口监视器（波特率9600）
4. 等待5秒倒计时
```

### 步骤3: 开始测试
```
1. 倒计时结束后松手
2. 程序自动测试所有参数组合
3. 实时显示测试进度和最佳参数
4. 每次发现更好参数会显示 "★ NEW BEST! ★"
```

### 步骤4: 应用结果
```
1. 测试完成后，串口会输出最优参数
2. 复制这些参数到 cl.ino 的第28-30行
3. 重新上传 cl.ino
4. 享受平衡效果！
```

## 📊 评分系统

程序使用综合评分（越小越好）：

```
Score = 平均角度误差 
      + 0.3 × 最大倾斜角度 
      + 200 × 跌倒次数 
      + 0.05 × 角度方差 
      + 0.2 × 振荡幅度
```

**评分指标**:
- **平均角度误差**: 偏离直立的平均程度
- **最大倾斜角度**: 最大偏离角度（防止剧烈摆动）
- **跌倒次数**: 超过15°的次数（重惩罚）
- **角度方差**: 稳定性指标
- **振荡幅度**: 抖动程度（越小越平滑）

## ⚠️ 注意事项

1. **安全第一**: 
   - 在空旷地面测试
   - 准备随时扶住小车
   - 避免障碍物

2. **电池电量**: 
   - 确保电池充足（测试耗时较长）
   - 低电量会影响结果

3. **初始姿态**: 
   - 每次测试开始时保持直立
   - 避免初始倾斜过大

4. **环境一致**: 
   - 在同一地面测试
   - 避免地面不平或打滑

5. **参数验证**: 
   - 找到最优参数后，多次测试验证
   - 可能需要微调

## 🐛 故障排除

### 问题1: 小车立即跌倒
**解决**: 
- 检查初始角度是否接近0°
- 增加 SETTLE_TIME 到 1500ms
- 手动扶稳后再松手

### 问题2: 所有参数得分都很高
**解决**:
- 检查MPU6050连接
- 检查电机方向是否正确
- 验证编码器是否工作

### 问题3: 找不到好参数
**解决**:
- 扩大搜索范围
- 检查机械结构（重心、轮子）
- 确认硬件无故障

### 问题4: 串口无输出
**解决**:
- 检查波特率是否为9600
- 重新上传程序
- 检查USB连接

## 📈 参数理解

### Kp (比例增益)
- **作用**: 快速响应倾斜
- **太大**: 剧烈震荡
- **太小**: 反应迟钝，容易跌倒
- **典型值**: 12-20

### Ki (积分增益)
- **作用**: 消除稳态误差
- **太大**: 超调、不稳定
- **太小**: 无法完全直立
- **典型值**: 0.5-2.0

### Kd (微分增益)
- **作用**: 抑制震荡，提前预测
- **太大**: 对噪声敏感
- **太小**: 震荡明显
- **典型值**: 0.008-0.020
