# 定时器中断PID控制说明

## 修改概述

已将PID控制从主循环改为定时器中断驱动，确保PID更新的精确性和优先级。

## 主要改进

### 1. **精确的控制频率**
- 使用MsTimer2库实现5ms定时器中断（200Hz）
- 不再依赖`delay()`函数，避免时间漂移
- PID控制周期固定，提高稳定性

### 2. **更高的优先级**
- PID计算在中断服务程序触发下执行
- 不受主循环其他任务影响
- 保证实时性和响应速度

### 3. **代码结构优化**
```cpp
// 定时器中断服务函数
void timerISR() {
  pid_update_flag = true;  // 设置更新标志
}

// 统一的PID更新函数
void updatePID() {
  readMPU6050();
  calculateAngle();
  calculateSpeed();
  // ... PID计算
  setMotor();
}
```

## 使用的库

需要安装 **MsTimer2** 库：
1. 打开Arduino IDE
2. 工具 -> 管理库
3. 搜索 "MsTimer2"
4. 安装

## 关键参数

```cpp
const int PID_INTERVAL = 5;  // 5ms间隔 = 200Hz
```

可以根据需要调整：
- 5ms (200Hz) - 推荐，平衡性能和稳定性
- 10ms (100Hz) - 较低频率，适合简单系统
- 2-3ms (333-500Hz) - 更高频率，需要更强处理器

## 工作流程

1. **setup()**: 初始化定时器，启动中断
2. **timerISR()**: 每5ms触发一次，设置标志
3. **主循环**: 检测标志，调用updatePID()
4. **updatePID()**: 执行完整的PID控制流程

## 优势

✅ **时间精确**: 固定5ms周期，无累积误差
✅ **高优先级**: 中断驱动，不被其他任务阻塞
✅ **更稳定**: 控制频率恒定，系统响应一致
✅ **易调试**: 清晰的执行流程

## 注意事项

⚠️ 中断服务函数要尽量简短
⚠️ 避免在中断中使用Serial.print()
⚠️ 使用volatile关键字声明共享变量
⚠️ 确保传感器读取速度足够快

## 测试建议

1. 先用角度环测试定时器是否正常工作
2. 观察控制频率是否稳定在200Hz
3. 对比修改前后的平衡效果
4. 根据实际情况微调PID_INTERVAL
