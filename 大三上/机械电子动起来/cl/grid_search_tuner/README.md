# 三环PID网格搜索调参系统

## 功能概述

这是一个用于自平衡小车的三环PID自动调参系统，支持：
- **角度环**：控制小车直立平衡
- **速度环**：控制小车速度
- **位置环**：控制小车位置

## 使用方法

### 1. 选择搜索模式

在代码第46行修改 `SEARCH_MODE` 变量：

```cpp
const int SEARCH_MODE = 2;  // 0=角度环, 1=速度环, 2=位置环
```

### 2. 调参顺序（重要！）

**必须按以下顺序调参：**

1. **先调角度环** (`SEARCH_MODE = 0`)
   - 这是最基础的控制环，确保小车能够直立
   - 速度环和位置环参数设为0
   - 调好后记录最佳参数

2. **再调速度环** (`SEARCH_MODE = 1`)
   - 使用已调好的角度环参数（第49-51行）
   - 调整速度环参数范围（第54-56行）
   - 调好后记录最佳参数

3. **最后调位置环** (`SEARCH_MODE = 2`)
   - 使用已调好的角度环和速度环参数（第571-577行）
   - 调整位置环参数范围（第59-61行）
   - 调好后记录最佳参数

### 3. 参数搜索范围配置

#### 角度环搜索范围（第49-51行）
```cpp
float kp_angle_range[] = {27};  
float ki_angle_range[] = {1.5};     
float kd_angle_range[] = {0.10};
```

#### 速度环搜索范围（第54-56行）
```cpp
float kp_speed_range[] = {1.5};  
float ki_speed_range[] = {0.1};     
float kd_speed_range[] = {0.03};
```

#### 位置环搜索范围（第59-61行）
```cpp
float kp_position_range[] = {0.5, 1.0, 1.5, 2.0, 2.5};  
float ki_position_range[] = {0.0, 0.01, 0.02, 0.03, 0.05};     
float kd_position_range[] = {0.0, 0.05, 0.1, 0.15};
```

### 4. 测试配置

- **测试时长**：每组参数测试20秒（第69行）
- **稳定时间**：参数切换后等待1秒（第70行）
- **总测试次数**：根据参数数组自动计算

### 5. 性能评估指标

#### 角度环评分
```
得分 = 平均角度误差 + 0.5×最大角度 + 100×跌倒次数 + 0.1×角度方差
```

#### 速度环评分
```
得分 = 平均速度误差 + 0.1×速度方差 + 2×平均角度误差 + 100×跌倒次数
```

#### 位置环评分
```
得分 = 平均位置误差 + 0.1×位置方差 + 0.5×最大位置误差 + 2×平均角度误差 + 100×跌倒次数
```

## 运行流程

1. **上传代码**到Arduino
2. **将小车放置在直立位置**
3. **等待10秒倒计时**
4. **自动开始测试**
   - 每组参数测试20秒
   - 实时显示测试进度和得分
   - 自动记录最佳参数
5. **测试完成**
   - 串口输出最佳参数
   - 自动应用最佳参数并持续运行

## 注意事项

1. **安全第一**
   - 确保小车有足够的活动空间
   - 测试时人员保持安全距离
   - 设置了25度倾角保护，超过会自动停止电机

2. **调参技巧**
   - 先用较大的参数间隔进行粗调
   - 找到大致范围后，缩小间隔进行精调
   - 每次调参前确保前一环已经稳定

3. **参数范围建议**
   - 角度环：Kp通常较大(20-40)，Ki较小(1-3)，Kd很小(0.01-0.2)
   - 速度环：Kp中等(1-3)，Ki很小(0.05-0.2)，Kd很小(0.01-0.05)
   - 位置环：Kp较小(0.5-3)，Ki极小(0-0.05)，Kd较小(0-0.2)

4. **硬件要求**
   - MPU6050陀螺仪（I2C地址0x68）
   - 编码器（引脚2和3）
   - 双电机驱动（L298N或类似）

## 控制架构

```
位置环 → 速度环 → 角度环 → 电机输出
  ↓        ↓        ↓
 PID      PID      PID
  ↓        ↓        ↓
速度设定  角度设定  PWM
```

位置环输出作为速度环的设定值，速度环和角度环共同控制电机输出。
