## 七、为什么没有Discovery阶段?

### PPPoE连接建立流程

```
时间轴:
  │
  ├─ [Discovery阶段] ← 只在连接建立时发生一次
  │   ├─ PADI (客户端广播)
  │   ├─ PADO (服务器响应)
  │   ├─ PADR (客户端请求)
  │   └─ PADS (服务器确认,分配Session ID)
  │
  ├─ [Session阶段] ← 持续数据传输
  │   └─ 使用Session ID进行通信
  │
  └─ [开始抓包] ← 此时连接已建立
```

### 原因分析

1. **PPPoE连接在抓包前已建立**
   - Discovery阶段已完成
   - Session ID (0x8cfb) 已分配
   - 抓包只捕获到后续的数据传输

2. **Discovery阶段的特点**
   - 仅在拨号连接时发生
   - 持续时间极短(通常<1秒)
   - 一旦建立,除非断开重连,否则不会再次出现
