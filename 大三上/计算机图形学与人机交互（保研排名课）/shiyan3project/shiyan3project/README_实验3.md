# 实验3 - 图形学基本算法实现2023112621

## 项目说明

本项目基于实验2的绘图软件，添加了以下实验3要求的功能：

### 已实现功能

#### (1) 直线绘制算法
- ✅ 中点画线法 (MidpointLine)
- ✅ Bresenham画线法 (BresenhamLine)
- 菜单：直线算法 -> 选择算法

#### (2) 圆绘制算法
- ✅ 中点画圆法 (MidpointCircle)
- ✅ Bresenham画圆法 (BresenhamCircle)
- 菜单：圆算法 -> 选择算法

#### (3) 线宽修改（扫描线填充法）
- ✅ 1像素、3像素、5像素线宽
- ✅ 10像素线宽（使用扫描线填充算法）
- 菜单：线宽 -> 选择线宽

#### (4) 线型修改
- ✅ 实线 (SOLID)
- ✅ 虚线 (DASH)
- ✅ 点线 (DOT)
- ✅ 点划线 (DASHDOT)
- 菜单：线型 -> 选择线型

#### (5) 区域填充
- ✅ 栅栏填充法 (FenceFill) - 扫描线填充多边形
- ✅ 种子填充法 (SeedFill) - 四连通区域填充
- 菜单：填充 -> 选择填充方式

#### (6) Bezier曲线
- ✅ de Casteljau递推算法实现
- ✅ 支持多个控制点
- ✅ 实时预览控制多边形和曲线
- 菜单：绘图工具 -> Bezier曲线

## 编译配置步骤

### 1. 更新资源文件

由于.rc文件是二进制格式，需要在Visual Studio中手动添加菜单：

1. 在Visual Studio中打开 `shiyan3project.sln`
2. 在解决方案资源管理器中，双击 `shiyan3project.rc`
3. 展开 "Menu" 节点
4. 参考 `menu_additions.txt` 文件中的菜单定义，添加新菜单项
5. 保存资源文件

### 2. 添加文件到项目

确保以下文件已添加到项目中：
- Algorithms.h
- Shape.h
- ShapeImpl.h

在Visual Studio中：
1. 右键点击项目 -> 添加 -> 现有项
2. 选择上述头文件

### 3. 编译项目

1. 选择 Debug 或 Release 配置
2. 选择 x64 平台
3. 点击 "生成" -> "生成解决方案"

## 使用说明

### 基本操作

1. **选择绘图工具**：从"绘图工具"菜单选择要绘制的图形
2. **选择算法**：从"直线算法"或"圆算法"菜单选择绘制算法
3. **设置线宽**：从"线宽"菜单选择线宽
4. **设置线型**：从"线型"菜单选择线型样式

### 绘制Bezier曲线

1. 选择菜单：绘图工具 -> Bezier曲线
2. 在画布上依次点击添加控制点
3. 实时预览控制多边形（灰色）和Bezier曲线（蓝色）
4. 右键完成绘制

### 区域填充

#### 栅栏填充（扫描线填充）
1. 选择菜单：绘图工具 -> 多边形（用于填充）
2. 依次点击多边形的顶点
3. 右键完成，自动填充多边形

#### 种子填充
1. 先绘制一个封闭区域（如矩形、多边形等）
2. 选择菜单：填充 -> 种子填充
3. 点击封闭区域内部任意点进行填充

### 算法对比

可以通过切换不同算法绘制相同图形，观察算法效果：
- 中点画线法 vs Bresenham画线法
- 中点画圆法 vs Bresenham画圆法

## 算法实现细节

### 中点画线法
- 使用增量决策参数
- 根据斜率选择不同的递增方向
- 时间复杂度：O(max(dx, dy))

### Bresenham画线法
- 整数运算，效率更高
- 使用误差累积方法
- 适用于任意斜率

### 中点画圆法
- 利用圆的八对称性
- 增量决策参数
- 只需计算1/8圆弧

### Bresenham画圆法
- 类似中点画圆法
- 使用不同的决策参数
- 八对称性绘制

### 扫描线填充
- 计算多边形与扫描线的交点
- 交点排序后填充
- 用于实现粗线宽

### 种子填充
- 四连通区域填充
- 使用队列实现
- 从种子点开始扩散

### de Casteljau算法
- 递推计算Bezier曲线点
- 支持任意阶Bezier曲线
- 数值稳定性好
