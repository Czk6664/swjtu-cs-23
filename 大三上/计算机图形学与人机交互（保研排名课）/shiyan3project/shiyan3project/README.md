## 本层内容介绍

这里是“计算机图形学与人机交互”课程下的“shiyan3project”目录，主要用于整理该项课程实践的相关材料，具体内容见下方文件与子目录。

**阅读建议：**先读任务或报告了解目标，再看代码、数据和结果；借鉴方法后独立完成自己的任务。

本目录及子目录共收录 **17 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **代码与脚本（10 份）**：[Algorithms.h](Algorithms.h)、[Resource.h](Resource.h)等；完整列表见本页导航。
- **文档与说明（1 份）**：[README_实验3.md](README_%E5%AE%9E%E9%AA%8C3.md)。
- **图片与图形（2 份）**：[shiyan3project.ico](shiyan3project.ico)、[small.ico](small.ico)。
