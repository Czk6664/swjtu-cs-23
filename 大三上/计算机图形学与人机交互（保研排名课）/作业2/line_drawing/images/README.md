# 图片文件夹

请将你的截图放在这个文件夹中：

## 需要的图片

1. **screenshot.png** - 程序运行效果截图
   - 运行 `cargo run` 后的终端输出截图
   - 建议截取完整的输出结果

2. **test_result.png** - 测试结果截图
   - 运行 `cargo test` 后的测试结果截图
   - 显示所有测试通过的状态

## 截图建议

- 使用高清截图
- 确保文字清晰可读
- 建议使用PNG格式
- 文件名必须与README.md中引用的名称一致

## 如何截图

### Windows系统
- 使用 `Win + Shift + S` 进行区域截图
- 或使用 `Snipping Tool` 工具

### 保存位置
将截图保存到当前文件夹（`line_drawing/images/`）
