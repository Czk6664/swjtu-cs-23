## 本层内容介绍

这里是“计算机图形学与人机交互”课程下的“images”目录，主要用于整理图像、插图或配套素材。

**阅读建议：**先在对应报告、课件或页面中查看这些素材的上下文，需要查图或复现时再打开原文件。

### 本层有哪些内容

本目录及子目录共收录 **37 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **图片与图形（37 份）**：[bc1.png](bc1.png)、[bc2.png](bc2.png)等；完整列表见本页导航。
