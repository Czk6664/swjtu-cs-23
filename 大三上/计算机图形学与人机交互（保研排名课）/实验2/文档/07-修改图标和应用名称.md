# 修改图标和应用名称教程

## 一、修改应用名称

### 方法1：修改资源文件（推荐）

#### 步骤1：找到资源文件

在 Visual Studio 中：
1. 打开 **解决方案资源管理器**
2. 找到 **Resource Files** 文件夹
3. 双击打开 **WindowsProject2.rc** 文件

#### 步骤2：修改字符串资源

在资源编辑器中：
1. 展开 **String Table**
2. 双击打开字符串表
3. 找到以下两个字符串：

```
IDS_APP_TITLE          "WindowsProject2"
IDC_WINDOWSPROJECT2    "WINDOWSPROJECT2"
```

4. 修改为你想要的名称，例如：

```
IDS_APP_TITLE          "简易绘图软件"
IDC_WINDOWSPROJECT2    "DrawingSoftware"
```

#### 步骤3：保存并重新编译

1. 按 `Ctrl+S` 保存
2. 按 `F5` 重新编译运行
3. 窗口标题栏会显示新名称

### 方法2：直接修改代码

如果找不到资源文件，可以直接在代码中修改：

#### 找到 WindowsProject2.cpp 文件

```cpp
BOOL InitInstance(HINSTANCE hInstance, int nCmdShow)
{
   hInst = hInstance;

   // 修改这里的窗口标题
   HWND hWnd = CreateWindowW(
       szWindowClass,           // 窗口类名
       L"简易绘图软件",          // ← 直接修改这里！
       WS_OVERLAPPEDWINDOW,
       CW_USEDEFAULT, 0, CW_USEDEFAULT, 0,
       nullptr, nullptr, hInstance, nullptr
   );

   if (!hWnd)
   {
      return FALSE;
   }

   ShowWindow(hWnd, nCmdShow);
   UpdateWindow(hWnd);

   return TRUE;
}
```

**注意**：
- `L"简易绘图软件"` 中的 `L` 表示宽字符（Unicode）
- 可以使用中文、英文或任何 Unicode 字符

## 二、修改应用图标

### 准备工作：准备图标文件

#### 图标要求
- 格式：`.ico` 文件
- 推荐尺寸：包含多个尺寸（16x16, 32x32, 48x48, 256x256）
- 可以使用在线工具转换：
  - https://www.icoconverter.com/
  - https://convertio.co/zh/png-ico/

#### 获取图标的方法

**方法1：自己设计**
- 使用 Photoshop、GIMP 等工具设计
- 导出为 PNG，然后转换为 ICO

**方法2：下载免费图标**
- https://www.iconfinder.com/
- https://www.flaticon.com/
- https://icons8.com/

**方法3：使用在线图标生成器**
- https://favicon.io/
- https://www.favicon-generator.org/

### 方法1：使用 Visual Studio 资源编辑器（推荐）

#### 步骤1：打开资源视图

1. 在 Visual Studio 中，按 `Ctrl+Shift+E` 打开资源视图
2. 或者：菜单栏 → 视图 → 其他窗口 → 资源视图

#### 步骤2：找到图标资源

1. 展开你的项目
2. 展开 **Icon** 文件夹
3. 你会看到：
   - `IDI_WINDOWSPROJECT2` - 应用程序图标
   - `IDI_SMALL` - 小图标

#### 步骤3：替换图标

**方法A：直接编辑**
1. 双击 `IDI_WINDOWSPROJECT2`
2. 在图标编辑器中绘制你的图标
3. 保存

**方法B：导入现有图标**
1. 右键点击 `IDI_WINDOWSPROJECT2`
2. 选择 **导入**
3. 浏览并选择你的 `.ico` 文件
4. 点击 **打开**

#### 步骤4：同样替换小图标

1. 双击 `IDI_SMALL`
2. 重复上述步骤

#### 步骤5：重新编译

1. 按 `Ctrl+Shift+B` 重新编译
2. 运行程序，查看新图标

### 方法2：手动替换图标文件

#### 步骤1：找到图标文件位置

在项目文件夹中找到：
```
WindowsProject2/
├── WindowsProject2.ico      ← 主图标
├── small.ico                 ← 小图标
└── WindowsProject2.rc        ← 资源文件
```

#### 步骤2：替换图标文件

1. 备份原图标文件
2. 将你的新图标文件重命名为 `WindowsProject2.ico` 和 `small.ico`
3. 覆盖原文件

#### 步骤3：重新编译

1. 在 Visual Studio 中，右键点击项目
2. 选择 **清理**
3. 然后选择 **重新生成**

### 方法3：修改资源文件（高级）

#### 打开 WindowsProject2.rc 文件

用文本编辑器打开，找到：

```rc
/////////////////////////////////////////////////////////////////////////////
//
// Icon
//

// Icon with lowest ID value placed first to ensure application icon
// remains consistent on all systems.
IDI_WINDOWSPROJECT2     ICON                    "WindowsProject2.ico"
IDI_SMALL               ICON                    "small.ico"
```

#### 修改图标路径

如果你的图标在其他位置，可以修改路径：

```rc
IDI_WINDOWSPROJECT2     ICON                    "res/my_icon.ico"
IDI_SMALL               ICON                    "res/my_small_icon.ico"
```

## 三、修改任务栏图标

任务栏图标会自动使用应用程序图标，但你也可以动态修改：

```cpp
// 在 InitInstance 函数中
HWND hWnd = CreateWindowW(...);

// 设置大图标
HICON hIcon = LoadIcon(hInstance, MAKEINTRESOURCE(IDI_WINDOWSPROJECT2));
SendMessage(hWnd, WM_SETICON, ICON_BIG, (LPARAM)hIcon);

// 设置小图标
HICON hIconSmall = LoadIcon(hInstance, MAKEINTRESOURCE(IDI_SMALL));
SendMessage(hWnd, WM_SETICON, ICON_SMALL, (LPARAM)hIconSmall);
```

## 四、修改可执行文件属性

### 修改文件描述、版本号等信息

#### 步骤1：打开版本资源

1. 在资源视图中，展开 **Version**
2. 双击 **VS_VERSION_INFO**

#### 步骤2：修改信息

你可以修改以下信息：

```
CompanyName          公司名称
FileDescription      文件描述（显示在任务管理器中）
FileVersion          文件版本
InternalName         内部名称
LegalCopyright       版权信息
OriginalFilename     原始文件名
ProductName          产品名称
ProductVersion       产品版本
```

#### 示例修改

```
CompanyName          "你的名字"
FileDescription      "简易绘图软件 - 计算机图形学实验"
FileVersion          "1.0.0.0"
ProductName          "DrawingSoftware"
ProductVersion       "1.0.0.0"
LegalCopyright       "Copyright (C) 2024"
```

## 五、完整示例：从头到尾修改

### 示例：将应用改名为"我的画板"

#### 1. 修改窗口标题

**在 WindowsProject2.rc 中**：
```
IDS_APP_TITLE          "我的画板"
```

或**在 WindowsProject2.cpp 中**：
```cpp
HWND hWnd = CreateWindowW(szWindowClass, L"我的画板", ...);
```

#### 2. 准备图标

- 下载或设计一个画板图标
- 转换为 `.ico` 格式
- 命名为 `MyDrawingBoard.ico`

#### 3. 替换图标

- 将 `MyDrawingBoard.ico` 复制到项目文件夹
- 在资源视图中，右键 `IDI_WINDOWSPROJECT2` → 导入
- 选择 `MyDrawingBoard.ico`

#### 4. 修改版本信息

在资源视图中，修改 **Version** 信息：
```
FileDescription      "我的画板 - 简易绘图工具"
ProductName          "我的画板"
```

#### 5. 重新编译

- 按 `Ctrl+Shift+B` 重新生成
- 按 `F5` 运行

## 六、常见问题

### Q1: 修改后图标没有变化？

**解决方案**：
1. 清理项目：**生成** → **清理解决方案**
2. 重新生成：**生成** → **重新生成解决方案**
3. 删除 `Debug` 或 `Release` 文件夹
4. 重启 Visual Studio

### Q2: 图标显示模糊或失真？

**解决方案**：
- 确保 `.ico` 文件包含多个尺寸（16x16, 32x32, 48x48, 256x256）
- 使用专业工具创建图标，如：
  - IcoFX
  - Greenfish Icon Editor Pro
  - 在线工具：https://www.icoconverter.com/

### Q3: 中文标题显示乱码？

**解决方案**：
```cpp
// 确保使用宽字符（L前缀）
CreateWindowW(szWindowClass, L"我的画板", ...);

// 不要用这个：
CreateWindowA(szWindowClass, "我的画板", ...);  // 错误！
```

### Q4: 如何在运行时动态修改标题？

```cpp
// 在任何地方都可以调用
SetWindowText(hWnd, L"新标题");

// 示例：根据文件名修改标题
std::wstring title = L"我的画板 - " + fileName;
SetWindowText(hWnd, title.c_str());
```

### Q5: 资源文件找不到？

**解决方案**：
1. 在解决方案资源管理器中，点击 **显示所有文件** 按钮
2. 找到 `.rc` 文件，右键选择 **包括在项目中**
3. 如果还是找不到，创建新的资源文件：
   - 右键项目 → 添加 → 资源
   - 选择 Icon → 新建
