## ❓ 常见问题

**Q: 为什么要用多态？**
A: 代码更简洁，易于扩展。详见 [05-实战案例与图解.md](05-%E5%AE%9E%E6%88%98%E6%A1%88%E4%BE%8B%E4%B8%8E%E5%9B%BE%E8%A7%A3.md) 案例1

**Q: 工厂模式有什么用？**
A: 集中管理对象创建，降低耦合。详见 [04-工厂模式与消息机制详解.md](04-%E5%B7%A5%E5%8E%82%E6%A8%A1%E5%BC%8F%E4%B8%8E%E6%B6%88%E6%81%AF%E6%9C%BA%E5%88%B6%E8%AF%A6%E8%A7%A3.md) 第二章

**Q: 消息循环是什么？**
A: Windows程序的心跳，处理所有用户交互。详见 [04-工厂模式与消息机制详解.md](04-%E5%B7%A5%E5%8E%82%E6%A8%A1%E5%BC%8F%E4%B8%8E%E6%B6%88%E6%81%AF%E6%9C%BA%E5%88%B6%E8%AF%A6%E8%A7%A3.md) 第三章
