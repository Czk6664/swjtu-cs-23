# 简易绘图软件 - 项目概述

## 项目简介

这是一个基于 Windows Direct2D 的简易绘图软件，实现了多种几何图形的绘制、编辑和几何计算功能。

## 主要功能

### 1. 图形绘制
- **直线 (Line)**：点击两个点绘制
- **圆形 (Circle)**：点击圆心，拖动确定半径
- **矩形 (Rectangle)**：点击并拖动绘制
- **三角形 (Triangle)**：依次点击三个顶点
- **菱形 (Diamond)**：点击并拖动绘制
- **平行四边形 (Parallelogram)**：依次点击三个顶点
- **曲线 (Curve)**：依次点击控制点，右键完成（贝塞尔曲线）
- **折线 (Polyline)**：依次点击顶点，右键完成

### 2. 图形编辑
- **选择**：点击图形进行选择（选中后显示为红色虚线）
- **移动**：选中图形后，按住鼠标左键拖动
- **旋转**：选中图形后，滚动鼠标滚轮调整角度，左键确认，右键取消
- **缩放**：选中图形后，滚动鼠标滚轮调整大小，左键确认，右键取消
- **删除**：删除选中的图形

### 3. 几何计算
- **求交点**：计算两个图形的交点并标记
- **绘制垂线**：从点到直线绘制垂线
- **显示圆心**：显示圆形的圆心坐标
- **绘制切线**：从外部点到圆绘制切线

### 4. 文件操作
- **新建**：清空画布
- **保存**：保存为 `.drw` 格式文件
- **打开**：加载 `.drw` 格式文件

### 5. 撤销/重做
- **撤销 (Ctrl+Z)**：最多支持 50 步撤销
- **重做 (Ctrl+Y)**：重做已撤销的操作

## 技术栈

### 图形渲染
- **Direct2D**：微软的硬件加速 2D 图形 API
- **DirectWrite**：高质量文本渲染引擎

### 编程语言
- **C++11/14**：使用现代 C++ 特性
  - 智能指针 (`std::shared_ptr`)
  - Lambda 表达式
  - 类型推断 (`auto`)
  - 范围 for 循环

### Windows API
- **Win32 API**：窗口管理、消息处理
- **COM (Component Object Model)**：Direct2D 基于 COM

## 核心设计思想

### 1. 面向对象设计
- 使用继承和多态实现不同图形的统一管理
- `Shape` 基类定义通用接口
- 各具体图形类实现自己的绘制和交互逻辑

### 2. 智能指针管理
- 使用 `std::shared_ptr<Shape>` 自动管理内存
- 避免内存泄漏和悬空指针问题

### 3. 状态机模式
- 通过全局状态变量控制程序行为
- `g_currentTool` - 当前工具
- `g_isDrawing`, `g_isMoving`, `g_isRotating`, `g_isScaling` - 操作状态

### 4. 命令模式（撤销/重做）
- 保存完整的图形列表快照
- 使用栈结构实现撤销和重做

### 5. 序列化/反序列化
- 每个图形类实现 `Serialize()` 和 `Deserialize()`
- 支持文件保存和加载

## 用户交互流程

### 绘制图形
1. 从菜单选择工具（如"绘制直线"）
2. 在画布上点击/拖动鼠标
3. 完成绘制（根据工具类型：释放鼠标/右键结束）
4. 图形添加到画布

### 编辑图形
1. 切换到选择模式
2. 点击图形进行选择
3. 执行编辑操作：
   - 移动：拖动鼠标
   - 旋转/缩放：滚轮调整 → 左键确认 / 右键取消
   - 删除：菜单选择"删除"

### 几何计算
1. 从菜单选择计算功能（如"求交点"）
2. 依次选择需要计算的图形
3. 程序自动计算并显示结果

## 性能特点

- **硬件加速**：Direct2D 使用 GPU 加速渲染
- **即时模式渲染**：每次重绘都重新绘制所有图形
- **高效的碰撞检测**：使用点到线段距离算法
- **平滑的交互体验**：实时更新和反馈

## 扩展性

- 新的图形类型（继承 `Shape` 类）
