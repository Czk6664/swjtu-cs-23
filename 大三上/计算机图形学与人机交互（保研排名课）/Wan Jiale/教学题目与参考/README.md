## 本层内容介绍

这里是“计算机图形学与人机交互”课程下的“教学题目与参考”目录，主要用于整理教学题目、思考题或配套参考材料。

**阅读建议：**先独立分析题目，再对照已有参考材料检查思路；是否含解答以具体文件为准。

### 本层有哪些内容

本目录及子目录共收录 **6 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（6 份）**：[2023年计算机图形学期中考试试卷.docx](2023%E5%B9%B4%E8%AE%A1%E7%AE%97%E6%9C%BA%E5%9B%BE%E5%BD%A2%E5%AD%A6%E6%9C%9F%E4%B8%AD%E8%80%83%E8%AF%95%E8%AF%95%E5%8D%B7.docx)、[2023年计算机图形学期期末试试卷-A卷.docx](2023%E5%B9%B4%E8%AE%A1%E7%AE%97%E6%9C%BA%E5%9B%BE%E5%BD%A2%E5%AD%A6%E6%9C%9F%E6%9C%9F%E6%9C%AB%E8%AF%95%E8%AF%95%E5%8D%B7-A%E5%8D%B7.docx)等；完整列表见本页导航。
