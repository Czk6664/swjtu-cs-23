## 本层内容介绍

这里是“计算机图形学与人机交互”课程下的“WindowsProject1”目录，主要用于整理此模块的源码及配套文件。

**阅读建议：**从上级项目说明确认模块职责，再结合文件名查找实现；具体入口和运行方法以源码及原说明为准。

### 本层有哪些内容

本目录及子目录共收录 **13 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **配置及其他配套文件（6 份）**：[CppProperties.json](CppProperties.json)、[WindowsProject1.rc](WindowsProject1.rc)等；完整列表见本页导航。
- **代码与脚本（5 份）**：[Resource.h](Resource.h)、[WindowsProject1.cpp](WindowsProject1.cpp)等；完整列表见本页导航。
- **图片与图形（2 份）**：[WindowsProject1.ico](WindowsProject1.ico)、[small.ico](small.ico)。
