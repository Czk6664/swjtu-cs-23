## 算法原理

栅栏填充（Scanline Fill）用于**多边形区域填充**，通过计算扫描线与多边形边的交点，填充交点之间的区域。

**本实现的特点：**
- 使用 Direct2D 的 **PathGeometry** 和 **FillGeometry**
- 不是传统的扫描线转换算法
- 利用 GPU 硬件加速实现高效填充
- 支持多边形、粗线、粗圆等多种图形

**适用场景：**
- 填充已知顶点的多边形
- 绘制粗线（宽度>1的线段）
- 绘制环形（粗圆）
- 任何需要填充几何图形的场景

## 主要功能

### 功能1：填充多边形（FillPolygon）

#### 代码实现

```cpp
void FillPolygon(ID2D1HwndRenderTarget* pRT, 
                 ID2D1SolidColorBrush* pBrush,
                 D2D1_POINT_2F* vertices, 
                 int count, 
                 D2D1_COLOR_F color) 
{
    if (count < 3) return;  // 至少需要3个顶点
    
    // 1. 获取Direct2D工厂
    ID2D1Factory* pFactory = nullptr;
    pRT->GetFactory(&pFactory);
    
    // 2. 创建路径几何对象
    ID2D1PathGeometry* pPathGeometry = nullptr;
    pFactory->CreatePathGeometry(&pPathGeometry);
    
    // 3. 打开几何Sink
    ID2D1GeometrySink* pSink = nullptr;
    pPathGeometry->Open(&pSink);
    
    // 4. 构建多边形路径
    pSink->BeginFigure(vertices[0], D2D1_FIGURE_BEGIN_FILLED);
    for (int i = 1; i < count; i++) {
        pSink->AddLine(vertices[i]);
    }
    pSink->EndFigure(D2D1_FIGURE_END_CLOSED);  // 封闭路径
    pSink->Close();
    
    // 5. 填充几何对象
    pBrush->SetColor(color);
    pRT->FillGeometry(pPathGeometry, pBrush);
    
    // 6. 清理资源
    pSink->Release();
    pPathGeometry->Release();
    pFactory->Release();
}
```

#### 使用示例

```cpp
// 绘制三角形
D2D1_POINT_2F triangle[3] = {
    D2D1::Point2F(100, 50),   // 顶点
    D2D1::Point2F(50, 150),   // 左下
    D2D1::Point2F(150, 150)   // 右下
};
FillPolygon(pRT, pBrush, triangle, 3, D2D1::ColorF(Red));

// 绘制五角星
D2D1_POINT_2F star[5] = {
    Point2F(100, 20),   // 上
    Point2F(120, 80),   // 右上
    Point2F(40, 50),    // 左
    Point2F(160, 50),   // 右
    Point2F(80, 80)     // 左下
};
FillPolygon(pRT, pBrush, star, 5, D2D1::ColorF(Yellow));
```

### 功能2：绘制粗线（DrawThickLine）

#### 算法原理

将粗线转换为**矩形多边形**进行填充。

**数学原理：**

```
给定线段：A(x1,y1) → B(x2,y2)，线宽 width

1. 计算方向向量
   V = B - A = (dx, dy)
   len = √(dx² + dy²)

2. 计算单位方向向量
   V̂ = (dx/len, dy/len)

3. 计算垂直向量（逆时针旋转90°）
   V⊥ = (-dy, dx)

4. 计算单位垂直向量
   V̂⊥ = (-dy/len, dx/len)

5. 计算偏移向量（线宽的一半）
   offset = V̂⊥ × (width/2)
          = (-dy/len × width/2, dx/len × width/2)

6. 计算矩形4个顶点
   v0 = A + offset   (左上)
   v1 = A - offset   (左下)
   v2 = B - offset   (右下)
   v3 = B + offset   (右上)
```

#### 代码实现

```cpp
void DrawThickLine(pRT, pBrush, x1, y1, x2, y2, width, color) 
{
    if (width <= 1.0f) {
        // 细线直接用 DrawLine
        pRT->DrawLine(Point2F(x1,y1), Point2F(x2,y2), pBrush, 1.0f);
        return;
    }
    
    // 计算线段的方向向量
    float dx = x2 - x1;
    float dy = y2 - y1;
    float len = sqrt(dx*dx + dy*dy);
    
    if (len < 0.001f) return;  // 长度太小，跳过
    
    // 计算垂直方向向量（单位向量 × width/2）
    float perpX = -dy / len * (width / 2.0f);
    float perpY = dx / len * (width / 2.0f);
    
    // 计算矩形4个顶点
    D2D1_POINT_2F vertices[4];
    vertices[0] = Point2F(x1 + perpX, y1 + perpY);  // 左上
    vertices[1] = Point2F(x1 - perpX, y1 - perpY);  // 左下
    vertices[2] = Point2F(x2 - perpX, y2 - perpY);  // 右下
    vertices[3] = Point2F(x2 + perpX, y2 + perpY);  // 右上
    
    // 填充矩形
    FillPolygon(pRT, pBrush, vertices, 4, color);
}
```

#### 图解说明

```
原始细线：
    A ───────────────── B

粗线（width=10）：

        v0 ───────────── v3
        │                │
    A   │                │   B  (原始线在中心)
        │                │
        v1 ───────────── v2

坐标计算示例：
A = (100, 100), B = (200, 150), width = 20

dx = 200-100 = 100
dy = 150-100 = 50
len = √(100²+50²) = 111.8

perpX = -50/111.8 × 10 = -4.47
perpY = 100/111.8 × 10 = 8.94

v0 = (100-4.47, 100+8.94) = (95.53, 108.94)
v1 = (100+4.47, 100-8.94) = (104.47, 91.06)
v2 = (200+4.47, 150-8.94) = (204.47, 141.06)
v3 = (200-4.47, 150+8.94) = (195.53, 158.94)
```

#### 优势

```
传统方法：
- 逐像素绘制 → 慢
- 需要复杂的边缘处理

Direct2D方法：
- 转为多边形填充 → 快（GPU加速）
- 自动处理抗锯齿
- 支持任意线宽
```

### 功能3：绘制粗圆（DrawThickCircle）

#### 算法原理

绘制**环形**（外圆减去内圆）。

**参数计算：**
```
给定：圆心(cx, cy)，半径 radius，线宽 width

计算：
outerRadius = radius + width/2
innerRadius = radius - width/2

如果 innerRadius < 0，设为 0
```

#### 代码实现

```cpp
void DrawThickCircle(pRT, pBrush, cx, cy, radius, width, color) 
{
    if (width <= 1.0f) {
        // 细线圆直接用 DrawEllipse
        pRT->DrawEllipse(Ellipse(cx,cy,radius,radius), pBrush, 1.0f);
        return;
    }
    
    // 计算内外半径
    float outerRadius = radius + width / 2.0f;
    float innerRadius = radius - width / 2.0f;
    if (innerRadius < 0) innerRadius = 0;
    
    // 创建路径几何对象
    ID2D1Factory* pFactory = nullptr;
    pRT->GetFactory(&pFactory);
    
    ID2D1PathGeometry* pPathGeometry = nullptr;
    pFactory->CreatePathGeometry(&pPathGeometry);
    
    ID2D1GeometrySink* pSink = nullptr;
    pPathGeometry->Open(&pSink);
    
    // === 绘制外圆（顺时针） ===
    pSink->BeginFigure(Point2F(cx + outerRadius, cy), 
                       D2D1_FIGURE_BEGIN_FILLED);
    
    D2D1_ARC_SEGMENT arc;
    arc.size = SizeF(outerRadius, outerRadius);
    arc.rotationAngle = 0.0f;
    arc.sweepDirection = D2D1_SWEEP_DIRECTION_CLOCKWISE;
    arc.arcSize = D2D1_ARC_SIZE_SMALL;
    
    // 上半圆：右 → 左
    arc.point = Point2F(cx - outerRadius, cy);
    pSink->AddArc(arc);
    
    // 下半圆：左 → 右
    arc.point = Point2F(cx + outerRadius, cy);
    pSink->AddArc(arc);
    
    pSink->EndFigure(D2D1_FIGURE_END_CLOSED);
    
    // === 绘制内圆（逆时针，形成空洞） ===
    if (innerRadius > 0) {
        pSink->BeginFigure(Point2F(cx + innerRadius, cy), 
                           D2D1_FIGURE_BEGIN_FILLED);
        
        arc.size = SizeF(innerRadius, innerRadius);
        arc.sweepDirection = D2D1_SWEEP_DIRECTION_COUNTER_CLOCKWISE;
        
        // 下半圆：右 → 左（反向）
        arc.point = Point2F(cx - innerRadius, cy);
        pSink->AddArc(arc);
        
        // 上半圆：左 → 右（反向）
        arc.point = Point2F(cx + innerRadius, cy);
        pSink->AddArc(arc);
        
        pSink->EndFigure(D2D1_FIGURE_END_CLOSED);
    }
    
    pSink->Close();
    
    // 填充环形
    pBrush->SetColor(color);
    pRT->FillGeometry(pPathGeometry, pBrush);
    
    // 清理
    pSink->Release();
    pPathGeometry->Release();
    pFactory->Release();
}
```

#### 图解说明

```
普通圆（width=1）：
      ┌───────┐
     ╱         ╲
    │           │
     ╲         ╱
      └───────┘

粗圆（width=10）：
    ┌─────────────┐
   ╱   ┌───────┐   ╲
  │   ╱         ╲   │
  │  │           │  │  ← 环形区域
  │   ╲         ╱   │
   ╲   └───────┘   ╱
    └─────────────┘
    
    外圆（顺时针）
    内圆（逆时针）

参数示例：
radius = 50, width = 10

outerRadius = 50 + 10/2 = 55
innerRadius = 50 - 10/2 = 45

结果：环形 = 外圆(r=55) - 内圆(r=45)
```

#### 关键技术：内外圆方向

```cpp
外圆：顺时针绘制
起点 (cx+r, cy) 
  → 左侧 (cx-r, cy)  [上半圆]
  → 终点 (cx+r, cy)  [下半圆]
  
内圆：逆时针绘制（反向！）
起点 (cx+r, cy)
  → 左侧 (cx-r, cy)  [下半圆，反向]
  → 终点 (cx+r, cy)  [上半圆，反向]

原理：
✓ 顺时针路径 = 填充区域
✓ 逆时针路径 = 挖空区域
✓ 组合 = 环形效果
```

## Direct2D几何体系

### 对象层次结构

```
ID2D1Factory (工厂对象)
    │
    ├─ CreatePathGeometry()
    │       │
    │       └─ ID2D1PathGeometry (路径几何对象)
    │               │
    │               └─ Open() 
    │                       │
    │                       └─ ID2D1GeometrySink (几何Sink)
    │                               │
    │                               ├─ BeginFigure()    开始图形
    │                               ├─ AddLine()        添加直线
    │                               ├─ AddArc()         添加圆弧
    │                               ├─ AddBezier()      添加贝塞尔曲线
    │                               ├─ EndFigure()      结束图形
    │                               └─ Close()          关闭Sink
    │
    └─ CreateXxx() (其他几何对象)

渲染：
ID2D1RenderTarget
    ├─ FillGeometry(path, brush)    填充几何对象
    └─ DrawGeometry(path, brush)    绘制轮廓
```

### 标准使用流程

```cpp
// 步骤1：获取工厂
ID2D1Factory* pFactory;
pRT->GetFactory(&pFactory);

// 步骤2：创建路径几何对象
ID2D1PathGeometry* pPath;
pFactory->CreatePathGeometry(&pPath);

// 步骤3：打开Sink并构建路径
ID2D1GeometrySink* pSink;
pPath->Open(&pSink);
{
    pSink->BeginFigure(startPoint, D2D1_FIGURE_BEGIN_FILLED);
    pSink->AddLine(point1);
    pSink->AddLine(point2);
    pSink->AddArc(arcSegment);
    // ...
    pSink->EndFigure(D2D1_FIGURE_END_CLOSED);
}
pSink->Close();

// 步骤4：使用几何对象渲染
pBrush->SetColor(color);
pRT->FillGeometry(pPath, pBrush);      // 填充
// 或
pRT->DrawGeometry(pPath, pBrush, 2.0f); // 描边

// 步骤5：清理资源
pSink->Release();
pPath->Release();
pFactory->Release();
```


## 传统算法对比

### 传统扫描线填充算法

虽然本实现使用Direct2D API，但了解传统算法有助于理解原理。

#### 算法步骤

```
1. 建立边表（ET - Edge Table）
   对每条多边形边：
   - 记录 ymin, ymax（边的最低和最高y坐标）
   - 记录 x（ymin对应的x坐标）
   - 记录 1/m（斜率的倒数，用于快速计算）
   
2. 建立活性边表（AET - Active Edge Table）
   存储当前扫描线相交的边
   
3. 扫描线填充
   for y = ymin to ymax:
       a. 更新AET（移除 y > ymax 的边）
       b. 从ET中添加 ymin=y 的边到AET
       c. 计算AET中各边与扫描线的交点 x
       d. 对交点x排序
       e. 两两配对填充：(x₁,x₂), (x₃,x₄), ...
       f. 更新AET中各边的x值：x ← x + 1/m
```

#### 示例

```
多边形：菱形
    
      (2,1)
       /\
      /  \
     /    \
  (0,4)    (4,4)
     \    /
      \  /
       \/
      (2,6)

边表（ET）：
y=1: [(2,1)→(0,4), m=-2/3]  [(2,1)→(4,4), m=2/3]
y=4: [(0,4)→(2,6), m=1]     [(4,4)→(2,6), m=-1]

扫描过程：

y=1: x=2,2 → 填充[2,2]
y=2: x=1.33, 2.67 → 填充[1.33, 2.67]
y=3: x=0.67, 3.33 → 填充[0.67, 3.33]
y=4: x=0, 4 → 填充[0, 4]
y=5: x=1, 3 → 填充[1, 3]
y=6: x=2, 2 → 填充[2, 2]
```

### Direct2D的优势

| 特性 | 传统算法 | Direct2D方法 |
|------|---------|-------------|
| **实现复杂度** | 高（需要ET/AET） | 低（API封装） |
| **性能** | CPU计算 | GPU加速 |
| **抗锯齿** | 需手动处理 | 自动支持 |
| **代码量** | 200+ 行 | 20行 |
| **适用性** | 仅多边形 | 任意几何 |
| **维护性** | 难 | 易 |

## 实际应用

### 应用1：绘制填充图形

```cpp
// 三角形
class Triangle : public Shape {
    void Draw(pRT, pBrush) override {
        if (filled) {
            // 填充
            D2D1_POINT_2F vertices[3] = {p1, p2, p3};
            ScanlineFillD2D::FillPolygon(pRT, pBrush, vertices, 3, fillColor);
        }
        
        // 边框
        pBrush->SetColor(color);
        pRT->DrawLine(p1, p2, pBrush);
        pRT->DrawLine(p2, p3, pBrush);
        pRT->DrawLine(p3, p1, pBrush);
    }
};
```

## 总结

### 栅栏填充的优势

✅ **性能优异**：GPU硬件加速
✅ **代码简洁**：Direct2D API封装
✅ **功能强大**：支持多种几何图形
✅ **质量高**：自动抗锯齿
✅ **易维护**：标准化API

### 关键技术点

1. **PathGeometry体系**：理解Direct2D几何对象层次
2. **顺逆时针规则**：掌握填充和挖空的原理
3. **向量运算**：理解垂直向量的计算
4. **API封装**：善用Direct2D提供的功能

### 适用场景

- ✅ 已知顶点的多边形填充
- ✅ 粗线、粗圆等图形绘制
- ✅ 需要高性能的图形渲染
- ✅ 需要高质量抗锯齿效果

### 与种子填充对比

| 特性 | 种子填充 | 栅栏填充 |
|------|---------|---------|
| 输入 | 种子点 | 顶点/参数 |
| 原理 | 扩散算法 | 几何填充 |
| 性能 | 较慢 | 快 |
| 适用 | 不规则区域 | 规则图形 |
