## 本层内容介绍

这里是“计算机图形学与人机交互”课程下的“shiyan4”目录，主要用于整理该项课程实践的相关材料，具体内容见下方文件与子目录。

**阅读建议：**先读任务或报告了解目标，再看代码、数据和结果；借鉴方法后独立完成自己的任务。

### 本层有哪些内容

本目录及子目录共收录 **20 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **代码与脚本（13 份）**：[Algorithms.h](Algorithms.h)、[ClipAlgorithms.h](ClipAlgorithms.h)等；完整列表见本页导航。
- **图片与图形（2 份）**：[shiyan4.ico](shiyan4.ico)、[small.ico](small.ico)。
- **配置及其他配套文件（5 份）**：[shiyan4.rc](shiyan4.rc)、[shiyan4.slnx](shiyan4.slnx)等；完整列表见本页导航。
