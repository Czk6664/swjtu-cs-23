## 本层内容介绍

这里是“计算机图形学与人机交互”课程下的“课件”目录，主要用于整理课堂讲授、章节讲义或复习课件。

**阅读建议：**按课堂章节顺序阅读，记录核心概念与例题；复习时回到不熟悉的章节查漏补缺。

### 本层有哪些内容

本目录及子目录共收录 **12 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（4 份）**：[2023年计算机图形学期中考试试卷.docx](2023%E5%B9%B4%E8%AE%A1%E7%AE%97%E6%9C%BA%E5%9B%BE%E5%BD%A2%E5%AD%A6%E6%9C%9F%E4%B8%AD%E8%80%83%E8%AF%95%E8%AF%95%E5%8D%B7.docx)、[2024年计算机图形学期中考试试卷 -部分参考答案.docx](2024%E5%B9%B4%E8%AE%A1%E7%AE%97%E6%9C%BA%E5%9B%BE%E5%BD%A2%E5%AD%A6%E6%9C%9F%E4%B8%AD%E8%80%83%E8%AF%95%E8%AF%95%E5%8D%B7%20-%E9%83%A8%E5%88%86%E5%8F%82%E8%80%83%E7%AD%94%E6%A1%88.docx)等；完整列表见本页导航。
