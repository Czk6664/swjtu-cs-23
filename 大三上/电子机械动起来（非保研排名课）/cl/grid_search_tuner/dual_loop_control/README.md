## 原有项目说明

# 双环控制系统

## 系统架构

这是一个简化的双环控制系统，专为自平衡小车设计。

### 控制环路

1. **角度环**（5ms更新）
   - 仅使用Kp和Kd参数
   - 控制公式：`输出 = Kp × 误差 - Kd × 角速度`
   - 无积分项，避免累积误差

2. **速度环**（10ms更新）
   - 仅使用Kp和Ki参数
   - 标准PI控制
   - 积分限幅防止饱和

3. **最终输出**
   - `电机输出 = 角度环输出 - 速度环输出`

## 硬件配置

### MPU6050陀螺仪
- I2C地址：0x68
- 用于测量角度和角速度

### 编码器
- 引脚A：2（中断）
- 引脚B：3
- 用于测量速度

### 电机驱动（L298N）
- IN1: 12, IN2: 13（电机A方向）
- IN3: 7, IN4: 6（电机B方向）
- PWM_A: 9（电机A速度）
- PWM_B: 10（电机B速度）

## 默认参数

### 角度环
- Kp = 25.0
- Kd = 0.15

### 速度环
- Kp = 1.5
- Ki = 0.1

### 保护设置
- 倾角保护：25度
- 平衡角度：-0.2度

## 使用方法

1. 在Arduino IDE中打开 `dual_loop_control.ino`
2. 确保已安装 `MsTimer2` 库
3. 上传到Arduino
4. 将小车放置在直立位置
5. 等待3秒后自动开始运行

## 参数调整

在 `control.h` 文件中修改参数：

```cpp
// 角度环参数
float kp_angle = 25.0;  // 比例系数
float kd_angle = 0.15;  // 微分系数

// 速度环参数
float kp_speed = 1.5;   // 比例系数
float ki_speed = 0.1;   // 积分系数
```

## 调参建议

### 角度环调参
1. 先设置Kd=0，调整Kp使小车能够直立
2. 如果震荡，增加Kd提供阻尼
3. Kp通常在20-40之间
4. Kd通常在0.1-0.3之间

### 速度环调参
1. 先设置Ki=0，调整Kp
2. 如果有稳态误差，增加Ki
3. Kp通常在1-3之间
4. Ki通常在0.05-0.2之间

## 串口输出

每秒输出一次状态信息：
- 角度（度）
- 角速度（度/秒）
- 速度（编码器计数）
- 角度环输出
- 速度环输出
- 最终电机输出

## 注意事项

1. 确保小车有足够的活动空间
2. 倾角超过25度会自动停止电机
3. 速度环积分有限幅保护
4. 定时器精确控制更新频率
5. 角度环使用互补滤波融合加速度计和陀螺仪数据

## 控制原理

### 角度环
使用PD控制，公式为：
```
输出 = Kp × (设定角度 - 当前角度) - Kd × 角速度
```
- Kp：根据角度误差产生恢复力
- Kd：根据角速度提供阻尼，防止震荡

### 速度环
使用PI控制，公式为：
```
输出 = Kp × (设定速度 - 当前速度) + Ki × 积分
```
- Kp：快速响应速度误差
- Ki：消除稳态误差

### 输出组合
```
电机输出 = 角度环输出 - 速度环输出
```
速度环输出作为角度环的补偿，实现速度控制的同时保持平衡。
