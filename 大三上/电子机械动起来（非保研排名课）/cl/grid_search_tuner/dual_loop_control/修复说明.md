# 双环控制系统修复说明

## 修复的问题

### 1. 定时器启动时机问题
**问题**: 定时器在传感器稳定之前就启动,导致控制不稳定
**修复**: 将定时器启动移到最后,在用户准备好小车之后再启动

### 2. PID参数不匹配
**问题**: 使用的PID参数与grid_search_tuner中经过测试的最佳参数不一致
**修复**: 
- 角度环 Kp: 40.0 → 25.0
- 角度环 Kd: 3.0 → 0.15
- 速度环 Kp: 1.0 → 1.5
- 速度环 Ki: 0.05 → 0.1

### 3. 平衡角度设定不正确
**问题**: ANGLE_SETPOINT = -1.2 (过大)
**修复**: ANGLE_SETPOINT = -0.2 (与grid_search_tuner一致)

### 4. 互补滤波器时间常数错误
**问题**: 使用0.005s (5ms),但实际更新周期不匹配
**修复**: 使用0.01s (10ms),与grid_search_tuner一致

### 5. 速度环积分时间常数和限幅值
**问题**: 
- 积分时间常数 0.005s → 0.01s
- 积分限幅 ±100 → ±200
- 输出限幅 ±50 → ±100
**修复**: 使用grid_search_tuner中验证过的值

## 启动顺序
1. 初始化串口
2. 初始化MPU6050
3. 测试MPU6050通信
4. 初始化编码器
5. 初始化电机引脚
6. 等待传感器稳定(1秒)
7. 显示初始角度
8. 等待用户准备(3秒)
9. **启动定时器** ← 移到最后
10. 开始控制循环

## 使用说明
1. 上传程序到Arduino
2. 打开串口监视器(9600波特率)
3. 观察初始化过程
4. 在"3秒后开始运行"提示后,将小车放置在直立位置
5. 程序自动启动控制

## 调试输出
程序会显示详细的初始化步骤和实时状态:
- 初始化各个模块的状态
- 传感器读数
- 角度、角速度、速度
- 角度环和速度环的输出
- 最终电机输出

## 注意事项
- 确保小车在直立位置启动
- 初始角度应该接近-0.2度
- 如果倾倒角度超过25度,电机会自动停止保护
