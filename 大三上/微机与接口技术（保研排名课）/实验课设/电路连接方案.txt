================================================================================
                      十一、蜂鸣器驱动电路
================================================================================

【电路图】

8253 OUT0
    |
   [1K电阻]
    |
    +----[2N2222基极(B)]
              |
         [集电极(C)]----[蜂鸣器+]
              |              |
         [发射极(E)]    [蜂鸣器-]
              |              |
             GND           +5V


【接线说明】
1. 8253的OUT0输出方波信号
2. 经1K电阻限流后接到三极管基极
3. 三极管集电极接蜂鸣器正极
4. 蜂鸣器负极接+5V
5. 三极管发射极接GND
6. 当OUT0为高电平时，三极管导通，蜂鸣器发声

【Proteus中可以简化】
直接用 SOUNDER 元件，OUT0 接正极，GND 接负极

================================================================================
                        十二、复位电路
================================================================================

【RC复位电路】

        +5V
         |
       [10K电阻]
         |
         +---------> 8086 RESET
         |           8255 RESET
         |           (所有需要复位的芯片)
       [10uF电容]
         |
        GND
         |
    [复位按键]-------+5V (可选，手动复位)


【工作原理】
- 上电时电容充电，RESET保持高电平一段时间
- 充电完成后RESET变低，系统开始运行
- 按下复位按键可手动复位

================================================================================
                      十三、时钟电路
================================================================================

【方案A：使用8284A时钟发生器】

晶振(14.318MHz)
    |
    +----> 8284A X1
    |
    +----> 8284A X2
           
8284A CLK ----> 8086 CLK (4.77MHz)
8284A PCLK ---> 8253 CLK0 (2.38MHz)
8284A RESET --> 8086 RESET

【方案B：Proteus简化方案】

直接使用时钟源元件:
- DCLOCK 设置为 5MHz 接 8086 CLK
- DCLOCK 设置为 1.193182MHz 接 8253 CLK0

================================================================================
                      十五、Proteus仿真注意事项
================================================================================

1. 8086最小模式：MN/MX# 必须接 +5V
2. 时钟频率：不要设太高，5MHz左右即可
3. ROM加载：右键ROM元件 -> Edit Properties -> Program File 选择HEX文件
4. 仿真速度：如果太慢，降低时钟频率
5. 调试：使用Proteus的虚拟终端和示波器观察信号

================================================================================
                      详细操作步骤
================================================================================

【步骤1: 放置8086 CPU】
1. 按 "P" 键打开元件库
2. 在 Keywords 框输入: 8086
3. 双击 "8086" 添加到器件列表
4. 关闭窗口，在左侧 DEVICES 列表点击 8086
5. 在原理图空白处点击放置

【步骤2: 放置8255A】
1. 按 "P" 键
2. 搜索: 8255
3. 选择 "8255A" 双击添加
4. 放置到原理图

【步骤3: 放置8253】
1. 按 "P" 键
2. 搜索: 8253

【步骤7: 放置74LS04 反相器】
1. 按 "P" 键
2. 搜索: 74LS04
3. 双击添加，放置

【步骤8: 放置ROM (27C256)】
1. 按 "P" 键
2. 搜索: 27C256
3. 双击添加，放置
4. 双击元件 -> Program File -> 选择编译好的HEX文件

【步骤9: 放置RAM (62256)】
1. 按 "P" 键
2. 搜索: 62256
3. 双击添加，放置

【步骤10: 放置4位数码管】
1. 按 "P" 键
2. 搜索: 7SEG-MPX4
3. 选择 "7SEG-MPX4-CC" (共阴极) 或 "7SEG-MPX4-CA" (共阳极)
4. 双击添加，放置
   注意: 代码是按共阴极写的，选CC

【步骤11: 放置蜂鸣器】
1. 按 "P" 键
2. 搜索: SOUNDER
3. 双击添加，放置
   或者搜索 SPEAKER 用扬声器

【步骤12: 放置按键 (需要28个)】
1. 按 "P" 键
2. 搜索: BUTTON
3. 双击添加
4. 连续点击放置28个 (25琴键 + 3功能键)

【步骤13: 放置电阻】
1. 按 "P" 键
2. 搜索: RES
3. 双击添加
4. 放置后双击修改阻值:
   - 上拉电阻: 10k
   - 限流电阻: 220
   - 基极电阻: 1k

【步骤14: 放置电容】
1. 按 "P" 键
2. 搜索: CAP (普通电容) 或 CAP-ELEC (电解电容)
3. 双击添加
4. 放置后双击修改容值:
   - 去耦电容: 100n (0.1uF)
   - 复位电容: 10u

【步骤15: 放置三极管】
1. 按 "P" 键
2. 搜索: 2N2222 或 NPN
3. 双击添加，放置

【步骤16: 放置电源和地】
1. 按 "P" 键
2. 搜索: POWER -> 放置 +5V 电源
3. 搜索: GROUND -> 放置 GND

【步骤17: 放置时钟源】
1. 按 "P" 键
2. 搜索: DCLOCK
3. 双击添加，放置
4. 双击修改频率:
   - CPU时钟: 5M (5MHz)
   - 8253时钟: 1.193182M

================================================================================
                        连线操作
================================================================================

【画线连接】
1. 点击左侧工具栏的画线工具 (或直接点击引脚)
2. 点击起始引脚
3. 点击终点引脚
4. 自动连线

【使用网络标签 (推荐，避免线太乱)】
1. 点击左侧 "LBL" 工具 (Place Wire Label)
2. 在导线上点击
3. 输入标签名，如 "D0", "A0", "RD#"
4. 相同标签名的导线自动连接

【总线连接】
1. 点击总线工具
2. 画一条粗线作为总线
3. 用细线从引脚连到总线
4. 给每条细线加标签 D0, D1, D2...

================================================================================
                      常用快捷键
================================================================================

P       打开元件库

ESC     取消当前操作
R       旋转元件
X       水平翻转
Y       垂直翻转

Ctrl+Z  撤销

F8      开始仿真
空格    暂停仿真

================================================================================
                    元件属性修改
================================================================================

【修改电阻值】
1. 双击电阻元件
2. 在 Resistance 框输入: 10k, 220, 1k 等
3. 点击 OK

【修改电容值】
1. 双击电容元件
2. 在 Capacitance 框输入: 100n, 10u 等
3. 点击 OK

【修改时钟频率】
1. 双击 DCLOCK 元件
2. 在 Frequency 框输入: 5M, 1.193182M 等
3. 点击 OK

【加载ROM程序】
1. 双击 27C256 元件
2. 点击 Program File 右边的文件夹图标
3. 选择编译好的 .HEX 文件
4. 点击 OK

================================================================================
                    如果找不到元件
================================================================================

1. 检查拼写是否正确
2. 尝试不同的搜索词:
   - 8255 找不到? 试试 8255A
   - 数码管找不到? 试试 7SEG 或 DISPLAY
   
3. 检查Proteus版本，旧版本可能没有某些元件

4. 替代方案:
   - 没有8086? 用8088代替 (代码兼容)
   - 没有27C256? 用27256或其他EPROM
   - 没有62256? 用6264 (8KB) 或其他SRAM
