================================================================================
                      地址译码电路详细设计
================================================================================

【设计目标】
使用74LS138实现I/O端口和存储器的地址译码

================================================================================
                    一、I/O端口地址译码
================================================================================

【I/O地址分配表】

设备        基地址    地址范围        二进制地址 (A9-A0)
--------------------------------------------------------------
8255A       0200H     0200H-0207H     01 0000 0XXX
8253        0208H     0208H-020FH     01 0000 1XXX  
8259A       0210H     0210H-0213H     01 0001 00XX
数码管数据  0220H     0220H-0221H     01 0010 000X
数码管位选  0222H     0222H-0223H     01 0010 001X

【74LS138 (U1) - I/O译码器接法】

                    74LS138
                   +-------+
            A5 --->| A   Y0|---> CS_8255# (Active Low)
            A6 --->| B   Y1|---> CS_8253#
            A7 --->| C   Y2|---> CS_8259#
                   |     Y3|---> (未用)
            A8 --->| G1  Y4|---> CS_LED#
           A9# --->| G2A Y5|---> (未用)
        M/IO# --->| G2B Y6|---> (未用)
                   |     Y7|---> (未用)
                   +-------+

【使能条件】
- G1 = 1 (A8 = 1)
- G2A = 0 (A9 = 0, 即A9# = 0)
- G2B = 0 (M/IO# = 0, I/O操作)

当地址为 01XXXXXXXX (A9=0, A8=1) 且为I/O操作时，译码器工作

【输出选择】
Y0# = 0 当 A7A6A5 = 000, 即地址 0200H-021FH 中的 0200H-0207H
Y1# = 0 当 A7A6A5 = 001, 即地址 0208H-020FH
Y2# = 0 当 A7A6A5 = 010, 即地址 0210H-0217H
Y4# = 0 当 A7A6A5 = 100, 即地址 0220H-0227H

================================================================================
                    二、存储器地址译码
================================================================================

【存储器地址分配】

设备        地址范围            大小
----------------------------------------
ROM         00000H - 0FFFFH     64KB
RAM         10000H - 1FFFFH     64KB

【74LS138 (U2) - 存储器译码器接法】

                    74LS138
                   +-------+
           A16 --->| A   Y0|---> CS_ROM# 
           A17 --->| B   Y1|---> CS_RAM#
           A18 --->| C   Y2|---> (未用)
                   |     Y3|---> (未用)
           +5V --->| G1  Y4|---> (未用)
           GND --->| G2A Y5|---> (未用)
       M/IO#' --->| G2B Y6|---> (未用)
                   |     Y7|---> (未用)
                   +-------+

注: M/IO#' 是 M/IO# 取反后的信号，存储器操作时 M/IO# = 1

【使能条件】
- G1 = 1 (固定)
- G2A = 0 (固定)
- G2B = 0 (M/IO#' = 0, 即 M/IO# = 1, 存储器操作)

【输出选择】
Y0# = 0 当 A18A17A16 = 000, 即地址 00000H-0FFFFH (ROM)
Y1# = 0 当 A18A17A16 = 001, 即地址 10000H-1FFFFH (RAM)

================================================================================
                    五、8255A内部地址译码
================================================================================

8255A有2根地址线A0、A1，选择4个内部寄存器:

A1  A0    选择的寄存器      对应端口地址
-----------------------------------------
0   0     端口A             0200H
0   1     端口B             0202H (注意8086是16位，A0不用)
1   0     端口C             0204H
1   1     控制寄存器        0206H

实际连接:
- 8255A的A0 ← 8086的A1
- 8255A的A1 ← 8086的A2

================================================================================
                    六、8253内部地址译码
================================================================================

8253有2根地址线A0、A1:

A1  A0    选择的寄存器      对应端口地址
-----------------------------------------
0   0     计数器0           0208H
0   1     计数器1           020AH
1   0     计数器2           020CH
1   1     控制寄存器        020EH

实际连接:
- 8253的A0 ← 8086的A1
- 8253的A1 ← 8086的A2

================================================================================
                    七、简化方案 (如果Proteus仿真)
================================================================================

在Proteus仿真中，可以使用更简单的译码方式:

【方案A: 使用74LS139 (双2-4译码器)】

一片74LS139可以替代部分74LS138功能:
- 第一个2-4译码器用于I/O设备选择
- 第二个2-4译码器用于存储器选择

【方案B: 直接使用门电路】

CS_8255# = NOT(A8 AND NOT(A9) AND NOT(M/IO#) AND NOT(A7) AND NOT(A6) AND NOT(A5))

用与非门和反相器组合实现

================================================================================
                    八、注意事项
================================================================================

1. 所有未使用的输入引脚要接固定电平，不能悬空
2. 译码器输出是低电平有效，直接连接到各芯片的CS#引脚
3. 8086的A0用于字节选择，I/O芯片地址从A1开始
4. 确保时序满足要求，必要时加入等待状态
5. 地址锁存器74LS373的OE#接GND，始终输出
