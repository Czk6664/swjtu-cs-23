## 本层内容介绍

这里是“微机与接口技术”课程下的“教学通知与要求”目录，主要用于整理教学任务、通知或提交要求的参考材料。

**阅读建议：**先读任务范围和提交形式，再安排学习；历史通知中的日期与具体规则不直接适用于当前学期。

### 本层有哪些内容

本层暂无独立资料文件；如原有说明列有复用链接，可沿链接查看其他目录中的同一份资料。
