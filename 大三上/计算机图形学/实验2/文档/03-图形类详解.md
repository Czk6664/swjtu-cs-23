# 图形类详解

## Shape 基类设计

### 类定义

```cpp
class Shape {
public:
    ShapeType type;                    // 图形类型枚举
    D2D1_COLOR_F color;                // 颜色
    bool selected;                     // 是否选中
    std::vector<D2D1_POINT_2F> points; // 关键点集合
    
    Shape(ShapeType t) : type(t), selected(false) {
        color = D2D1::ColorF(D2D1::ColorF::Black);
    }
    
    virtual ~Shape() = default;
    
    // 纯虚函数 - 必须由子类实现
    virtual void Draw(ID2D1HwndRenderTarget* pRT, ID2D1SolidColorBrush* pBrush) = 0;
    virtual bool HitTest(D2D1_POINT_2F point) = 0;
    virtual void Move(float dx, float dy) = 0;
    virtual void Rotate(D2D1_POINT_2F center, float angle) = 0;
    virtual void Scale(D2D1_POINT_2F center, float factor) = 0;
    virtual D2D1_POINT_2F GetCenter() = 0;
    virtual std::string Serialize() = 0;
    virtual void Deserialize(const std::string& data) = 0;
    
protected:
    // 辅助函数
    void DrawDashed(ID2D1HwndRenderTarget* pRT, ID2D1SolidColorBrush* pBrush, 
                    std::function<void(ID2D1StrokeStyle*)> drawFunc);
    float PointToLineDistance(D2D1_POINT_2F point, D2D1_POINT_2F lineStart, D2D1_POINT_2F lineEnd);
    D2D1_POINT_2F RotatePoint(D2D1_POINT_2F point, D2D1_POINT_2F center, float angle);
    D2D1_POINT_2F ScalePoint(D2D1_POINT_2F point, D2D1_POINT_2F center, float factor);
};
```

### 辅助函数实现

#### DrawDashed - 绘制虚线

```cpp
void DrawDashed(ID2D1HwndRenderTarget* pRT, ID2D1SolidColorBrush* pBrush, 
                std::function<void(ID2D1StrokeStyle*)> drawFunc)
{
    ID2D1Factory* pFactory = nullptr;
    pRT->GetFactory(&pFactory);
    
    // 创建虚线样式
    ID2D1StrokeStyle* pStrokeStyle = nullptr;
    float dashes[] = { 5.0f, 2.0f };  // 5像素实线，2像素空白
    pFactory->CreateStrokeStyle(
        D2D1::StrokeStyleProperties(
            D2D1_CAP_STYLE_FLAT,
            D2D1_CAP_STYLE_FLAT,
            D2D1_CAP_STYLE_FLAT,
            D2D1_LINE_JOIN_MITER,
            10.0f,
            D2D1_DASH_STYLE_CUSTOM,
            0.0f
        ),
        dashes, 2, &pStrokeStyle
    );
    
    // 使用 lambda 回调绘制
    drawFunc(pStrokeStyle);
    
    pStrokeStyle->Release();
    pFactory->Release();
}
```

## 具体图形类

### 1. Line（直线）

```cpp
class Line : public Shape {
public:
    D2D1_POINT_2F start, end;  // 起点和终点
    
    Line() : Shape(ShapeType::LINE) {}
    Line(D2D1_POINT_2F s, D2D1_POINT_2F e) : Shape(ShapeType::LINE), start(s), end(e) {
        points.push_back(s);
        points.push_back(e);
    }
    
    void Draw(ID2D1HwndRenderTarget* pRT, ID2D1SolidColorBrush* pBrush) override {
        pBrush->SetColor(selected ? D2D1::ColorF(D2D1::ColorF::Red) : color);
        if (selected) {
            DrawDashed(pRT, pBrush, [&](ID2D1StrokeStyle* style) {
                pRT->DrawLine(start, end, pBrush, 2.0f, style);
            });
        } else {
            pRT->DrawLine(start, end, pBrush, 1.0f);
        }
    }
    
    bool HitTest(D2D1_POINT_2F point) override {
        return PointToLineDistance(point, start, end) < 5.0f;
    }
    
    void Move(float dx, float dy) override {
        start.x += dx; start.y += dy;
        end.x += dx; end.y += dy;
        points.clear();
        points.push_back(start);
        points.push_back(end);
    }
    
    D2D1_POINT_2F GetCenter() override {
        return D2D1::Point2F((start.x + end.x) / 2, (start.y + end.y) / 2);
    }
    
    std::string Serialize() override {
        std::stringstream ss;
        ss << "LINE " << start.x << " " << start.y << " " << end.x << " " << end.y;
        return ss.str();
    }
    
    void Deserialize(const std::string& data) override {
        std::stringstream ss(data);
        std::string type;
        ss >> type >> start.x >> start.y >> end.x >> end.y;
        points = {start, end};
    }
};
```

### 2. Circle（圆形）

```cpp
class Circle : public Shape {
public:
    D2D1_POINT_2F center;
    float radius;
    
    Circle() : Shape(ShapeType::CIRCLE), radius(0) {}
    Circle(D2D1_POINT_2F c, float r) : Shape(ShapeType::CIRCLE), center(c), radius(r) {
        points.push_back(c);
    }
    
    void Draw(ID2D1HwndRenderTarget* pRT, ID2D1SolidColorBrush* pBrush) override {
        pBrush->SetColor(selected ? D2D1::ColorF(D2D1::ColorF::Red) : color);
        D2D1_ELLIPSE ellipse = D2D1::Ellipse(center, radius, radius);
        if (selected) {
            DrawDashed(pRT, pBrush, [&](ID2D1StrokeStyle* style) {
                pRT->DrawEllipse(ellipse, pBrush, 2.0f, style);
            });
        } else {
            pRT->DrawEllipse(ellipse, pBrush, 1.0f);
        }
    }
    
    bool HitTest(D2D1_POINT_2F point) override {
        float dx = point.x - center.x;
        float dy = point.y - center.y;
        float dist = sqrt(dx * dx + dy * dy);
        return fabs(dist - radius) < 5.0f;  // 点击圆周附近
    }
    
    void Scale(D2D1_POINT_2F scaleCenter, float factor) override {
        center = ScalePoint(center, scaleCenter, factor);
        radius *= factor;  // 半径也要缩放
        points.clear();
        points.push_back(center);
    }
};
```

### 3. RectangleShape（矩形）

```cpp
class RectangleShape : public Shape {
public:
    D2D1_POINT_2F p1, p2, p3, p4;  // 四个顶点
    
    void Draw(ID2D1HwndRenderTarget* pRT, ID2D1SolidColorBrush* pBrush) override {
        pBrush->SetColor(selected ? D2D1::ColorF(D2D1::ColorF::Red) : color);
        
        // 使用 PathGeometry 绘制任意四边形
        ID2D1Factory* pFactory = nullptr;
        pRT->GetFactory(&pFactory);
        ID2D1PathGeometry* pPath = nullptr;
        pFactory->CreatePathGeometry(&pPath);
        ID2D1GeometrySink* pSink = nullptr;
        pPath->Open(&pSink);
        
        pSink->BeginFigure(p1, D2D1_FIGURE_BEGIN_HOLLOW);
        pSink->AddLine(p2);
        pSink->AddLine(p3);
        pSink->AddLine(p4);
        pSink->EndFigure(D2D1_FIGURE_END_CLOSED);
        pSink->Close();
        
        if (selected) {
            DrawDashed(pRT, pBrush, [&](ID2D1StrokeStyle* style) {
                pRT->DrawGeometry(pPath, pBrush, 2.0f, style);
            });
        } else {
            pRT->DrawGeometry(pPath, pBrush, 1.0f);
        }
        
        pSink->Release();
        pPath->Release();
        pFactory->Release();
    }
    
    bool HitTest(D2D1_POINT_2F point) override {
        // 检查点是否在任意一条边附近
        return PointToLineDistance(point, p1, p2) < 5.0f ||
               PointToLineDistance(point, p2, p3) < 5.0f ||
               PointToLineDistance(point, p3, p4) < 5.0f ||
               PointToLineDistance(point, p4, p1) < 5.0f;
    }
};
```

### 4. Curve（贝塞尔曲线）

```cpp
class Curve : public Shape {
public:
    std::vector<D2D1_POINT_2F> curvePoints;  // 控制点
    
    void AddPoint(D2D1_POINT_2F p) {
        curvePoints.push_back(p);
        points.push_back(p);
    }
    
    void Draw(ID2D1HwndRenderTarget* pRT, ID2D1SolidColorBrush* pBrush) override {
        if (curvePoints.empty()) return;
        
        pBrush->SetColor(selected ? D2D1::ColorF(D2D1::ColorF::Red) : color);
        
        // 单点：绘制小圆
        if (curvePoints.size() == 1) {
            D2D1_ELLIPSE ellipse = D2D1::Ellipse(curvePoints[0], 2.0f, 2.0f);
            pRT->FillEllipse(ellipse, pBrush);
            return;
        }
        
        ID2D1Factory* pFactory = nullptr;
        pRT->GetFactory(&pFactory);
        ID2D1PathGeometry* pPath = nullptr;
        pFactory->CreatePathGeometry(&pPath);
        ID2D1GeometrySink* pSink = nullptr;
        pPath->Open(&pSink);
        
        pSink->BeginFigure(curvePoints[0], D2D1_FIGURE_BEGIN_HOLLOW);
        
        if (curvePoints.size() == 2) {
            // 两点：直线
            pSink->AddLine(curvePoints[1]);
        } else {
            // 三点及以上：二次贝塞尔曲线
            for (size_t i = 0; i < curvePoints.size() - 1; i++) {
                D2D1_QUADRATIC_BEZIER_SEGMENT seg;
                seg.point1 = curvePoints[i + 1];  // 控制点
                
                if (i == curvePoints.size() - 2) {
                    // 最后一段：端点是最后一个控制点
                    seg.point2 = curvePoints[i + 1];
                } else {
                    // 中间段：端点是两个控制点的中点
                    seg.point2 = D2D1::Point2F(
                        (curvePoints[i + 1].x + curvePoints[i + 2].x) / 2,
                        (curvePoints[i + 1].y + curvePoints[i + 2].y) / 2
                    );
                }
                pSink->AddQuadraticBezier(seg);
            }
        }
        
        pSink->EndFigure(D2D1_FIGURE_END_OPEN);
        pSink->Close();
        
        if (selected) {
            DrawDashed(pRT, pBrush, [&](ID2D1StrokeStyle* style) {
                pRT->DrawGeometry(pPath, pBrush, 2.0f, style);
            });
        } else {
            pRT->DrawGeometry(pPath, pBrush, 1.0f);
        }
        
        pSink->Release();
        pPath->Release();
        pFactory->Release();
    }
    
    // 采样贝塞尔曲线用于交点计算
    std::vector<D2D1_POINT_2F> GetSampledPoints(int samplesPerSegment = 10) const {
        std::vector<D2D1_POINT_2F> sampledPoints;
        if (curvePoints.size() < 2) return sampledPoints;
        
        D2D1_POINT_2F currentPoint = curvePoints[0];
        sampledPoints.push_back(currentPoint);
        
        for (size_t i = 0; i < curvePoints.size() - 1; i++) {
            D2D1_POINT_2F p0 = currentPoint;
            D2D1_POINT_2F p1 = curvePoints[i + 1];
            D2D1_POINT_2F p2;
            
            if (i == curvePoints.size() - 2) {
                p2 = curvePoints[i + 1];
            } else {
                p2 = D2D1::Point2F(
                    (curvePoints[i + 1].x + curvePoints[i + 2].x) / 2,
                    (curvePoints[i + 1].y + curvePoints[i + 2].y) / 2
                );
            }
            
            // 二次贝塞尔公式：P(t) = (1-t)²P0 + 2(1-t)tP1 + t²P2
            for (int j = 1; j <= samplesPerSegment; j++) {
                float t = (float)j / samplesPerSegment;
                float u = 1.0f - t;
                D2D1_POINT_2F pt;
                pt.x = u * u * p0.x + 2 * u * t * p1.x + t * t * p2.x;
                pt.y = u * u * p0.y + 2 * u * t * p1.y + t * t * p2.y;
                sampledPoints.push_back(pt);
            }
            
            currentPoint = p2;
        }
        
        return sampledPoints;
    }
};

## 图形类设计模式

### 1. 继承与多态

所有图形类都继承自`Shape`基类，这是面向对象编程的核心概念。

#### 继承的作用
```cpp
// 基类定义统一接口
class Shape {
public:
    virtual void Draw(...) = 0;  // 纯虚函数
    virtual bool HitTest(...) = 0;
};

// 子类实现具体功能
class Line : public Shape {
public:
    void Draw(...) override {
        // Line特有的绘制逻辑
    }
};

class Circle : public Shape {
public:
    void Draw(...) override {
        // Circle特有的绘制逻辑
    }
};
```

#### 多态的威力
```cpp
// 存储不同类型的图形，但都用基类指针
std::vector<std::shared_ptr<Shape>> g_shapes;

// 添加不同类型
g_shapes.push_back(std::make_shared<Line>(...));
g_shapes.push_back(std::make_shared<Circle>(...));

// 多态调用：自动调用正确的子类方法
for (auto& shape : g_shapes) {
    shape->Draw(g_pRenderTarget, g_pBrush);  // 多态！
    // Line对象调用Line::Draw
    // Circle对象调用Circle::Draw
}
```

**多态的好处**：
- 统一的调用方式
- 不需要知道具体类型
- 易于扩展新图形类型

### 2. 模板方法模式

`DrawDashed` 使用模板方法模式，将虚线样式创建和具体绘制分离：

```cpp
DrawDashed(pRT, pBrush, [&](ID2D1StrokeStyle* style) {
    // 具体的绘制逻辑由调用者提供
    pRT->DrawLine(start, end, pBrush, 2.0f, style);
});
```

### 3. 策略模式

不同图形类实现不同的绘制策略，通过多态调用：

```cpp
for (auto& shape : g_shapes) {
    shape->Draw(g_pRenderTarget, g_pBrush);  // 多态调用
}
```

### 4. 序列化模式

每个图形类实现自己的序列化格式：

```cpp
// Line: "LINE x1 y1 x2 y2"
// Circle: "CIRCLE cx cy radius"
// Rectangle: "RECTANGLE x1 y1 x2 y2 x3 y3 x4 y4"
// Triangle: "TRIANGLE x1 y1 x2 y2 x3 y3"
```

## 关键点集合 (points)

每个图形维护一个 `points` 向量，存储关键点：

- **Line**: 起点和终点
- **Circle**: 圆心
- **Rectangle**: 四个顶点
- **Triangle**: 三个顶点
- **Curve**: 所有控制点

**用途**：
- 用于变换操作（移动、旋转、缩放）
- 用于序列化
- 用于几何计算

## 碰撞检测策略

### 线性图形（直线、多边形）
检查点到每条边的距离：
```cpp
return PointToLineDistance(point, p1, p2) < 5.0f;
```

### 圆形
检查点到圆心的距离是否接近半径：
```cpp
float dist = sqrt((point.x - center.x)² + (point.y - center.y)²);
return fabs(dist - radius) < 5.0f;
```

### 曲线
1. 检查是否靠近控制点
2. 采样曲线，检查是否靠近采样点连成的线段

## 变换操作

### 旋转
所有点绕中心旋转：
```cpp
void Rotate(D2D1_POINT_2F center, float angle) override {
    p1 = RotatePoint(p1, center, angle);
    p2 = RotatePoint(p2, center, angle);
    // ... 其他点
}
```

### 缩放
所有点相对中心缩放：
```cpp
void Scale(D2D1_POINT_2F center, float factor) override {
    p1 = ScalePoint(p1, center, factor);
    p2 = ScalePoint(p2, center, factor);
    // ... 其他点
}
```

### 移动
所有点平移：
```cpp
void Move(float dx, float dy) override {
    p1.x += dx; p1.y += dy;
    p2.x += dx; p2.y += dy;
    // ... 其他点
}
```

## 序列化格式

每个图形的序列化格式：

```
LINE x1 y1 x2 y2
CIRCLE cx cy radius
RECTANGLE x1 y1 x2 y2 x3 y3 x4 y4
TRIANGLE x1 y1 x2 y2 x3 y3
DIAMOND cx cy width height
PARALLELOGRAM x1 y1 x2 y2 x3 y3 x4 y4
CURVE count x1 y1 x2 y2 ... xn yn
POLYLINE count x1 y1 x2 y2 ... xn yn
```

**设计原则**：
- 第一个字段是类型标识
- 后续字段是图形数据
- 使用空格分隔
- 一行一个图形
