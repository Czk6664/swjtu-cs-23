# 实战案例与图解

## 一、继承与多态实战案例

### 案例1：绘制所有图形

#### 问题
如何用统一的方式绘制不同类型的图形（直线、圆形、三角形等）？

#### 不使用多态的做法（❌ 不推荐）

```cpp
void DrawAllShapes() {
    for (auto& shape : g_shapes) {
        // 需要判断每个图形的类型
        if (shape->type == ShapeType::LINE) {
            Line* line = static_cast<Line*>(shape.get());
            // 绘制直线的代码
            g_pRenderTarget->DrawLine(line->start, line->end, g_pBrush, 1.0f);
        }
        else if (shape->type == ShapeType::CIRCLE) {
            Circle* circle = static_cast<Circle*>(shape.get());
            // 绘制圆形的代码
            D2D1_ELLIPSE ellipse = D2D1::Ellipse(circle->center, circle->radius, circle->radius);
            g_pRenderTarget->DrawEllipse(ellipse, g_pBrush, 1.0f);
        }
        else if (shape->type == ShapeType::TRIANGLE) {
            // 绘制三角形的代码...
        }
        // ... 更多类型判断
    }
}
```

**问题**：
- 代码冗长，难以维护
- 添加新图形需要修改这个函数
- 违反开闭原则（对扩展开放，对修改关闭）

#### 使用多态的做法（✅ 推荐）

```cpp
void DrawAllShapes() {
    // 一行代码搞定！
    for (auto& shape : g_shapes) {
        shape->Draw(g_pRenderTarget, g_pBrush);  // 多态调用
    }
}
```

**优势**：
- 代码简洁
- 添加新图形不需要修改这个函数
- 符合开闭原则

#### 多态的工作原理

```
调用 shape->Draw(...)
    ↓
检查 shape 指向的实际对象类型
    ↓
如果是 Line 对象 → 调用 Line::Draw
如果是 Circle 对象 → 调用 Circle::Draw
如果是 Triangle 对象 → 调用 Triangle::Draw
```

### 案例2：点击检测

#### 场景
用户点击画布，需要找出点击了哪个图形。

```cpp
void OnLButtonDown(HWND hWnd, D2D1_POINT_2F mousePos) {
    // 遍历所有图形
    for (auto& shape : g_shapes) {
        // 多态调用HitTest
        // Line::HitTest检查点到线段的距离
        // Circle::HitTest检查点到圆心的距离
        // Triangle::HitTest检查点是否在三角形内
        if (shape->HitTest(mousePos)) {
            // 找到了！
            g_selectedShape = shape.get();
            shape->selected = true;
            InvalidateRect(hWnd, nullptr, FALSE);
            return;
        }
    }
}
```

#### 各图形的HitTest实现

```cpp
// Line的HitTest：检查点到线段的距离
bool Line::HitTest(D2D1_POINT_2F point) {
    float distance = PointToLineDistance(point, start, end);
    return distance < 5.0f;  // 5像素容差
}

// Circle的HitTest：检查点到圆心的距离
bool Circle::HitTest(D2D1_POINT_2F point) {
    float dx = point.x - center.x;
    float dy = point.y - center.y;
    float distToCenter = sqrt(dx * dx + dy * dy);
    return fabs(distToCenter - radius) < 5.0f;  // 点击圆周附近
}

// Triangle的HitTest：检查点到三条边的距离
bool Triangle::HitTest(D2D1_POINT_2F point) {
    return PointToLineDistance(point, p1, p2) < 5.0f ||
           PointToLineDistance(point, p2, p3) < 5.0f ||
           PointToLineDistance(point, p3, p1) < 5.0f;
}
```

**多态的好处**：
- 调用方不需要知道具体的检测算法
- 每个图形可以有自己最优的检测方法
- 统一的调用接口

#### 使用工厂模式（✅ 推荐）

```cpp
// 1. 定义工厂函数
std::shared_ptr<Shape> CreateShape(ShapeType type) {
    switch (type) {
        case ShapeType::LINE:      return std::make_shared<Line>();
        case ShapeType::CIRCLE:    return std::make_shared<Circle>();
        case ShapeType::TRIANGLE:  return std::make_shared<Triangle>();
        case ShapeType::RECTANGLE: return std::make_shared<RectangleShape>();
        default:                   return nullptr;
    }
}

// 2. 字符串转枚举
ShapeType StringToShapeType(const std::string& str) {
    if (str == "LINE")      return ShapeType::LINE;
    if (str == "CIRCLE")    return ShapeType::CIRCLE;
    if (str == "TRIANGLE")  return ShapeType::TRIANGLE;
    if (str == "RECTANGLE") return ShapeType::RECTANGLE;
    return ShapeType::NONE;
}

// 3. 简洁的加载代码
void LoadFromFile(const char* filename) {
    std::ifstream file(filename);
    std::string line;
    
    while (std::getline(file, line)) {
        std::stringstream ss(line);
        std::string typeStr;
        ss >> typeStr;
        
        // 使用工厂创建对象
        ShapeType type = StringToShapeType(typeStr);
        auto shape = CreateShape(type);
        
        if (shape) {
            // 使用序列化机制加载数据
            shape->Deserialize(line);
            g_shapes.push_back(shape);
        }
    }
}
```

### 案例3：撤销功能的深拷贝

#### 问题
撤销功能需要保存图形的历史状态，但不能直接保存指针（会被修改）。

```cpp
void SaveStateToUndoStack() {
    std::vector<std::shared_ptr<Shape>> stateCopy;
    
    for (const auto& shape : g_shapes) {
        // 1. 序列化当前图形
        std::string data = shape->Serialize();
        
        // 2. 使用工厂创建新对象（深拷贝）
        auto newShape = CreateShape(shape->type);
        
        // 3. 反序列化数据到新对象
        newShape->Deserialize(data);
        
        // 4. 保存新对象
        stateCopy.push_back(newShape);
    }
    
    // 5. 添加到撤销栈
    g_undoStack.push_back(stateCopy);
    
    // 6. 限制栈大小
    if (g_undoStack.size() > MAX_UNDO_STEPS) {
        g_undoStack.erase(g_undoStack.begin());
    }
}
```

**工厂模式的作用**：
- 不需要知道具体类名就能创建对象
- 统一的创建接口
- 便于实现深拷贝

## 三、消息机制实战案例

### 案例1：完整的绘制流程

#### 流程图

```
用户点击"绘制直线"菜单
    ↓
WM_COMMAND消息
    ↓
设置 g_currentTool = ShapeType::LINE
    ↓
用户点击画布
    ↓
WM_LBUTTONDOWN消息
    ↓
CreateShape(ShapeType::LINE) 创建Line对象
    ↓
设置 g_isDrawing = true
    ↓
用户移动鼠标
    ↓
WM_MOUSEMOVE消息（多次）
    ↓
更新 line->end = mousePos
    ↓
InvalidateRect() 触发重绘
    ↓
WM_PAINT消息
    ↓
调用 line->Draw() 绘制
    ↓
用户释放鼠标
    ↓
WM_LBUTTONUP消息
    ↓
g_shapes.push_back(line)
    ↓
SaveStateToUndoStack()
    ↓
完成绘制
```

#### 代码实现

```cpp
// 步骤1：用户点击菜单
case WM_COMMAND:
    if (wmId == IDM_DRAW_LINE) {
        g_currentTool = ShapeType::LINE;
        g_statusText = L"直线工具：点击两个点绘制直线";
        InvalidateRect(hWnd, nullptr, FALSE);
    }
    break;

// 步骤2：用户点击画布
case WM_LBUTTONDOWN:
    if (g_currentTool == ShapeType::LINE && !g_isDrawing) {
        // 工厂模式创建对象
        g_currentShape = CreateShape(ShapeType::LINE);
        auto line = std::dynamic_pointer_cast<Line>(g_currentShape);
        
        // 初始化
        line->start = mousePos;
        line->end = mousePos;
        g_isDrawing = true;
        
        InvalidateRect(hWnd, nullptr, FALSE);
    }
    break;

// 步骤3：用户移动鼠标
case WM_MOUSEMOVE:
    if (g_isDrawing && g_currentShape) {
        auto line = std::dynamic_pointer_cast<Line>(g_currentShape);
        line->end = mousePos;  // 更新终点
        
        // 触发重绘
        InvalidateRect(hWnd, nullptr, FALSE);
    }
    break;

// 步骤4：系统重绘窗口
case WM_PAINT:
    BeginPaint(hWnd, &ps);
    
    g_pRenderTarget->BeginDraw();
    g_pRenderTarget->Clear(D2D1::ColorF(D2D1::ColorF::White));
    
    // 绘制所有已完成的图形
    for (auto& shape : g_shapes) {
        shape->Draw(g_pRenderTarget, g_pBrush);  // 多态
    }
    
    // 绘制正在创建的图形
    if (g_currentShape) {
        g_currentShape->Draw(g_pRenderTarget, g_pBrush);  // 多态
    }
    
    g_pRenderTarget->EndDraw();
    EndPaint(hWnd, &ps);
    break;

// 步骤5：用户释放鼠标
case WM_LBUTTONUP:
    if (g_isDrawing) {
        // 保存到撤销栈
        SaveStateToUndoStack();
        
        // 添加到图形列表
        g_shapes.push_back(g_currentShape);
        
        // 清理状态
        g_currentShape = nullptr;
        g_isDrawing = false;
        g_statusText = L"直线绘制完成";
        
        InvalidateRect(hWnd, nullptr, FALSE);
    }
    break;
```

### 案例2：缩放功能

#### 交互流程

```
用户选中一个图形
    ↓
用户点击"缩放"菜单
    ↓
WM_COMMAND消息
    ↓
备份图形数据
设置 g_isScaling = true
    ↓
用户滚动鼠标滚轮
    ↓
WM_MOUSEWHEEL消息（多次）
    ↓
计算缩放因子
应用缩放变换
更新状态文本
InvalidateRect()
    ↓
WM_PAINT消息
    ↓
绘制缩放后的图形
    ↓
用户左键确认 或 右键取消
    ↓
WM_LBUTTONDOWN 或 WM_RBUTTONDOWN
    ↓
确认：保存到撤销栈
取消：恢复备份数据
```

#### 代码实现

```cpp
// 步骤1：用户点击"缩放"菜单
case IDM_SCALE:
    if (g_selectedShape) {
        // 备份原始数据
        g_backupShapeData = g_selectedShape->Serialize();
        g_currentScaleFactor = 1.0f;
        g_isScaling = true;
        g_statusText = L"缩放模式：滚动鼠标滚轮调整大小，左键确认，右键取消";
    } else {
        g_statusText = L"请先选择一个图形";
    }
    InvalidateRect(hWnd, nullptr, FALSE);
    break;

// 步骤2：用户滚动鼠标滚轮
case WM_MOUSEWHEEL:
    if (g_isScaling && g_selectedShape) {
        // 获取滚轮滚动量
        int delta = GET_WHEEL_DELTA_WPARAM(wParam);
        
        // 计算缩放因子（每次10%）
        float scaleDelta = (delta > 0) ? 1.1f : 0.9f;
        g_currentScaleFactor *= scaleDelta;
        
        // 应用缩放（多态调用）
        D2D1_POINT_2F center = g_selectedShape->GetCenter();
        g_selectedShape->Scale(center, scaleDelta);
        
        // 更新状态文本
        wchar_t buffer[100];
        swprintf_s(buffer, L"缩放倍数: %.2f (左键确认，右键取消)", 
                   g_currentScaleFactor);
        g_statusText = buffer;
        
        // 触发重绘
        InvalidateRect(hWnd, nullptr, FALSE);
    }
    break;

// 步骤3：用户左键确认
case WM_LBUTTONDOWN:
    if (g_isScaling) {
        // 保存到撤销栈
        SaveStateToUndoStack();
        
        // 退出缩放模式
        g_isScaling = false;
        g_statusText = L"缩放已确认";
        InvalidateRect(hWnd, nullptr, FALSE);
        return;  // 优先处理，不执行其他逻辑
    }
    break;

// 步骤4：用户右键取消
case WM_RBUTTONDOWN:
    if (g_isScaling) {
        // 恢复备份数据
        g_selectedShape->Deserialize(g_backupShapeData);
        
        // 退出缩放模式
        g_isScaling = false;
        g_statusText = L"缩放已取消";
        InvalidateRect(hWnd, nullptr, FALSE);
    }
    break;
```

### 案例3：消息优先级处理

#### 问题
同一个鼠标点击，可能有多种含义：
- 确认缩放
- 选择图形
- 开始绘制

如何确定优先级？

#### 解决方案

```cpp
void OnLButtonDown(HWND hWnd, D2D1_POINT_2F point) {
    // 优先级1：缩放/旋转确认（最高优先级）
    if (g_isScaling || g_isRotating) {
        SaveStateToUndoStack();
        g_isScaling = false;
        g_isRotating = false;
        g_statusText = L"操作已确认";
        InvalidateRect(hWnd, nullptr, FALSE);
        return;  // 立即返回，不处理其他逻辑
    }
    
    // 优先级2：几何计算模式
    if (g_calcMode != CalcMode::NONE) {
        HandleGeometryCalculation(point);
        return;
    }
    
    // 优先级3：选择模式
    if (g_currentTool == ShapeType::NONE) {
        // 查找点击的图形
        for (auto& shape : g_shapes) {
            if (shape->HitTest(point)) {  // 多态调用
                // 取消之前的选择
                if (g_selectedShape) {
                    g_selectedShape->selected = false;
                }
                // 选中新图形
                g_selectedShape = shape.get();
                g_selectedShape->selected = true;
                g_statusText = L"已选中图形";
                InvalidateRect(hWnd, nullptr, FALSE);
                return;
            }
        }
        
        // 没有点击到任何图形，取消选择
        if (g_selectedShape) {
            g_selectedShape->selected = false;
            g_selectedShape = nullptr;
            g_statusText = L"已取消选择";
            InvalidateRect(hWnd, nullptr, FALSE);
        }
        return;
    }
    
    // 优先级4：绘制模式（最低优先级）
    if (g_currentTool != ShapeType::NONE && !g_isDrawing) {
        // 使用工厂创建新图形
        g_currentShape = CreateShape(g_currentTool);
        
        if (g_currentShape) {
            g_isDrawing = true;
            // ... 初始化图形 ...
        }
    }
}
```

**优先级设计原则**：
1. 确认/取消操作优先级最高（避免误操作）
2. 特殊模式（几何计算）次之
3. 选择操作再次之
4. 绘制操作优先级最低

```cpp
// SaveToFile函数
void SaveToFile(HWND hWnd) {
    // 打开文件对话框
    OPENFILENAME ofn = { sizeof(ofn) };
    WCHAR szFile[260] = { 0 };
    ofn.hwndOwner = hWnd;
    ofn.lpstrFile = szFile;
    ofn.nMaxFile = sizeof(szFile);
    ofn.lpstrFilter = L"Text Files\0*.TXT\0All Files\0*.*\0";
    ofn.Flags = OFN_OVERWRITEPROMPT;
    
    if (GetSaveFileName(&ofn)) {
        std::ofstream file(szFile);
        
        if (file.is_open()) {
            // 【多态】序列化所有图形
            for (const auto& shape : g_shapes) {
                file << shape->Serialize() << std::endl;
            }
            
            file.close();
            g_statusText = L"文件保存成功";
        } else {
            g_statusText = L"文件保存失败";
        }
        
        InvalidateRect(hWnd, nullptr, FALSE);
    }
}

// ========== 第7步：用户点击"打开"菜单 ==========

// LoadFromFile函数

    ofn.hwndOwner = hWnd;

    ofn.nMaxFile = sizeof(szFile);
    ofn.lpstrFilter = L"Text Files\0*.TXT\0All Files\0*.*\0";
    ofn.Flags = OFN_FILEMUSTEXIST;
    
    if (GetOpenFileName(&ofn)) {
        std::ifstream file(szFile);
        
        if (file.is_open()) {
            // 清空当前图形
            g_shapes.clear();
            g_selectedShape = nullptr;
            
            std::string line;
            while (std::getline(file, line)) {
                std::stringstream ss(line);
                std::string typeStr;
                ss >> typeStr;
                
                // 【工厂模式】根据类型创建对象
                ShapeType type = StringToShapeType(typeStr);
                auto shape = CreateShape(type);
                
                if (shape) {
                    // 【多态】反序列化
                    shape->Deserialize(line);
                    g_shapes.push_back(shape);
                }
            }
            
            file.close();
            g_statusText = L"文件加载成功";
            InvalidateRect(hWnd, nullptr, FALSE);
        } else {
            g_statusText = L"文件加载失败";
        }
    }
}
```

## 五、关键概念总结

### 继承与多态
- **作用**：统一接口，不同实现
- **使用场景**：Draw、HitTest、Move等所有图形操作
- **好处**：代码简洁，易于扩展

### 工厂模式
- **作用**：集中管理对象创建
- **使用场景**：创建图形、加载文件、撤销功能
- **好处**：降低耦合，便于维护

### 消息机制
- **作用**：响应用户操作
- **使用场景**：所有用户交互
- **好处**：事件驱动，解耦界面和逻辑

### 三者关系
```
消息机制 → 触发操作
    ↓
工厂模式 → 创建对象
    ↓
多态机制 → 调用方法
```

这三个机制共同构成了程序的核心架构，使得代码结构清晰、易于扩展、便于维护。
