# 快速参考卡

## 一、核心概念一句话总结

| 概念 | 一句话解释 | 关键字 |
|------|-----------|--------|
| **继承** | 子类自动获得父类的属性和方法 | `class Line : public Shape` |
| **多态** | 用父类指针调用子类方法 | `virtual`、`override` |
| **工厂模式** | 统一的对象创建接口 | `CreateShape(type)` |
| **消息机制** | 事件驱动的编程模型 | `WndProc`、`GetMessage` |
| **虚函数** | 可以被子类重写的函数 | `virtual void Draw() = 0` |
| **序列化** | 对象转字符串 | `Serialize()`、`Deserialize()` |

### 2. 工厂函数

```cpp
std::shared_ptr<Shape> CreateShape(ShapeType type) {
    switch (type) {
        case ShapeType::LINE:      return std::make_shared<Line>();
        case ShapeType::CIRCLE:    return std::make_shared<Circle>();
        case ShapeType::MYSHAPE:   return std::make_shared<MyShape>();
        default:                   return nullptr;
    }
}
```

### 5. 保存和加载

```cpp
// 保存
void SaveToFile(const char* filename) {
    std::ofstream file(filename);
    for (const auto& shape : g_shapes) {
        file << shape->Serialize() << std::endl;
    }
    file.close();
}

// 加载
void LoadFromFile(const char* filename) {
    std::ifstream file(filename);
    std::string line;
    
    g_shapes.clear();
    
    while (std::getline(file, line)) {
        std::stringstream ss(line);
        std::string typeStr;
        ss >> typeStr;
        
        ShapeType type = StringToShapeType(typeStr);
        auto shape = CreateShape(type);
        
        if (shape) {
            shape->Deserialize(line);
            g_shapes.push_back(shape);
        }
    }
    
    file.close();
}
```

### 6. 撤销/重做

```cpp
// 保存状态
void SaveStateToUndoStack() {
    std::vector<std::shared_ptr<Shape>> stateCopy;
    
    for (const auto& shape : g_shapes) {
        std::string data = shape->Serialize();
        auto newShape = CreateShape(shape->type);
        newShape->Deserialize(data);
        stateCopy.push_back(newShape);
    }
    
    g_undoStack.push_back(stateCopy);
    
    if (g_undoStack.size() > MAX_UNDO_STEPS) {
        g_undoStack.erase(g_undoStack.begin());
    }
}

// 撤销
void Undo() {
    if (!g_undoStack.empty()) {
        g_redoStack.push_back(g_shapes);
        g_shapes = g_undoStack.back();
        g_undoStack.pop_back();
    }
}

// 重做
void Redo() {
    if (!g_redoStack.empty()) {
        g_undoStack.push_back(g_shapes);
        g_shapes = g_redoStack.back();
        g_redoStack.pop_back();
    }
}
```

## 四、Direct2D常用API

### 初始化

```cpp
// 创建工厂
D2D1CreateFactory(D2D1_FACTORY_TYPE_SINGLE_THREADED, &g_pD2DFactory);

// 创建渲染目标

    D2D1::HwndRenderTargetProperties(hWnd, D2D1::SizeU(width, height)),
```

```cpp
// 开始绘制

g_pRenderTarget->DrawLine(start, end, pBrush, 1.0f);
```

## 五、常见错误及解决方案

### 错误1：忘记调用InvalidateRect

**症状**：修改了图形，但窗口没有更新

**解决**：
```cpp
// 修改图形后调用
InvalidateRect(hWnd, nullptr, FALSE);
```

### 错误2：忘记实现虚函数

**症状**：编译错误"cannot instantiate abstract class"

**解决**：确保实现了所有纯虚函数
```cpp
virtual void Draw(...) = 0;      // 必须实现
virtual bool HitTest(...) = 0;   // 必须实现
// ... 其他纯虚函数
```

### 错误3：内存泄漏

**症状**：程序运行一段时间后变慢

**解决**：
```cpp
// 使用智能指针
std::shared_ptr<Shape> shape = std::make_shared<Line>();

// 释放COM对象
if (pBrush) {
    pBrush->Release();
    pBrush = nullptr;
}
```

### 错误4：设备丢失

**症状**：EndDraw返回D2DERR_RECREATE_TARGET

**解决**：
```cpp
HRESULT hr = g_pRenderTarget->EndDraw();
if (hr == D2DERR_RECREATE_TARGET) {
    DiscardDeviceResources();  // 重建设备资源
}
```

### 错误5：坐标提取错误

**症状**：鼠标点击位置不准确

**解决**：
```cpp
// 正确的提取方式
int x = LOWORD(lParam);  // 低16位是X
int y = HIWORD(lParam);  // 高16位是Y

// 错误的方式
int x = (int)lParam;  // 错误！
```
