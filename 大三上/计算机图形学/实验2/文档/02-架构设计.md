# 架构设计

## 程序入口与初始化

### wWinMain 函数流程

```cpp
int APIENTRY wWinMain(_In_ HINSTANCE hInstance, ...)
{
    // 1. 初始化 COM
    CoInitialize(nullptr);
    
    // 2. 创建 Direct2D 工厂（单线程）
    D2D1CreateFactory(D2D1_FACTORY_TYPE_SINGLE_THREADED, &g_pD2DFactory);
    
    // 3. 创建 DirectWrite 工厂
    DWriteCreateFactory(DWRITE_FACTORY_TYPE_SHARED, 
                        __uuidof(IDWriteFactory),
                        reinterpret_cast<IUnknown**>(&g_pDWriteFactory));
    
    // 4. 加载字符串资源
    LoadStringW(hInstance, IDS_APP_TITLE, szTitle, MAX_LOADSTRING);
    LoadStringW(hInstance, IDC_WINDOWSPROJECT2, szWindowClass, MAX_LOADSTRING);
    
    // 5. 注册窗口类
    MyRegisterClass(hInstance);
    
    // 6. 创建主窗口
    if (!InitInstance(hInstance, nCmdShow)) {
        return FALSE;
    }
    
    // 7. 加载快捷键表
    HACCEL hAccelTable = LoadAccelerators(hInstance, MAKEINTRESOURCE(IDC_WINDOWSPROJECT2));
    
    // 8. 消息循环
    MSG msg;
    while (GetMessage(&msg, nullptr, 0, 0)) {
        if (!TranslateAccelerator(msg.hwnd, hAccelTable, &msg)) {
            TranslateMessage(&msg);
            DispatchMessage(&msg);
        }
    }
    
    // 9. 清理资源
    DiscardDeviceResources();
    if (g_pD2DFactory) g_pD2DFactory->Release();
    if (g_pDWriteFactory) g_pDWriteFactory->Release();
    CoUninitialize();
    
    return (int)msg.wParam;
}
```

### 关键点说明

#### COM 初始化
```cpp
CoInitialize(nullptr);  // 初始化 COM 库
```
- Direct2D 基于 COM（组件对象模型）
- 必须在使用 Direct2D 之前初始化
- 程序结束时调用 `CoUninitialize()` 清理

#### Direct2D 工厂类型
```cpp
D2D1_FACTORY_TYPE_SINGLE_THREADED  // 单线程工厂
```
- **单线程**：性能更好，但只能在创建它的线程中使用
- **多线程**：线程安全，但性能稍差

#### 消息循环
```cpp
while (GetMessage(&msg, nullptr, 0, 0)) {
    TranslateMessage(&msg);    // 转换键盘消息
    DispatchMessage(&msg);     // 分发到 WndProc
}
```
- Windows 应用程序的核心
- 不断获取和处理消息
- 直到收到 `WM_QUIT` 消息

## 窗口消息处理架构

### 消息机制概述

Windows使用**消息驱动**的编程模型。所有的用户交互（鼠标、键盘、菜单）都通过消息传递。

#### 消息的流转过程

```
用户操作（点击鼠标）
    ↓
操作系统捕获事件
    ↓
创建消息对象（WM_LBUTTONDOWN）
    ↓
消息放入应用程序的消息队列
    ↓
GetMessage从队列中取出消息
    ↓
TranslateMessage转换消息
    ↓
DispatchMessage分发到WndProc
    ↓
WndProc处理消息
    ↓
返回处理结果
```

### WndProc 消息分发

WndProc是消息处理的中心，所有消息都会路由到这里。

```cpp
LRESULT CALLBACK WndProc(HWND hWnd, UINT message, WPARAM wParam, LPARAM lParam)
{
    // 参数说明：
    // hWnd: 窗口句柄，标识哪个窗口收到消息
    // message: 消息类型（如WM_PAINT, WM_LBUTTONDOWN等）
    // wParam: 消息的附加信息（如按键代码、菜单ID）
    // lParam: 消息的附加信息（如鼠标坐标）
    
    switch (message)
    {
    case WM_COMMAND:      // 菜单命令
        // wParam的低16位是菜单项ID
        HandleMenuCommand(LOWORD(wParam));
        break;
        
    case WM_PAINT:        // 绘制窗口
        OnPaint(hWnd);
        break;
        
    case WM_LBUTTONDOWN:  // 左键按下
        // lParam包含鼠标坐标：低16位是X，高16位是Y
        OnLButtonDown(hWnd, lParam);
        break;
        
    case WM_LBUTTONUP:    // 左键释放
        OnLButtonUp(hWnd, lParam);
        break;
        
    case WM_MOUSEMOVE:    // 鼠标移动
        OnMouseMove(hWnd, lParam);
        break;
        
    case WM_RBUTTONDOWN:  // 右键按下
        OnRButtonDown(hWnd);
        break;
        
    case WM_MOUSEWHEEL:   // 鼠标滚轮
        // wParam包含滚轮滚动量
        HandleMouseWheel(hWnd, wParam);
        break;
        
    case WM_SIZE:         // 窗口大小改变
        ResizeRenderTarget();
        break;
        
    case WM_DESTROY:      // 窗口销毁
        PostQuitMessage(0);  // 发送WM_QUIT消息，退出消息循环
        break;
        
    default:
        // 默认处理：交给系统处理
        return DefWindowProc(hWnd, message, wParam, lParam);
    }
    return 0;
}
```

### 常用消息详解

#### WM_COMMAND - 菜单和按钮消息

```cpp
case WM_COMMAND:
{
    int wmId = LOWORD(wParam);  // 提取命令ID
    
    switch (wmId)
    {
    case IDM_DRAW_LINE:
        // 用户点击了"绘制直线"菜单
        g_currentTool = ShapeType::LINE;
        g_statusText = L"直线工具已激活";
        InvalidateRect(hWnd, nullptr, FALSE);  // 触发重绘
        break;
        
    case IDM_SAVE:
        // 用户点击了"保存"菜单
        SaveToFile(hWnd);
        break;
    }
    break;
}
```

#### WM_LBUTTONDOWN - 鼠标左键按下

```cpp
case WM_LBUTTONDOWN:
{
    // 从lParam中提取鼠标坐标
    int x = LOWORD(lParam);  // X坐标（屏幕坐标）
    int y = HIWORD(lParam);  // Y坐标（屏幕坐标）
    
    D2D1_POINT_2F point = D2D1::Point2F(
        static_cast<float>(x),
        static_cast<float>(y)
    );
    
    // 处理点击事件
    OnLButtonDown(hWnd, point);
    break;
}
```

#### WM_PAINT - 窗口重绘

```cpp
case WM_PAINT:
{
    PAINTSTRUCT ps;
    BeginPaint(hWnd, &ps);  // 必须调用，标记开始绘制
    
    // 绘制内容
    OnPaint(hWnd);
    
    EndPaint(hWnd, &ps);    // 必须调用，标记结束绘制
    break;
}
```

**触发WM_PAINT的方式**：
```cpp
// 方法1：标记窗口无效区域
InvalidateRect(hWnd, nullptr, FALSE);

// 方法2：立即重绘（不推荐，会阻塞）
UpdateWindow(hWnd);
```

### 消息处理优先级

1. **缩放/旋转确认/取消**（最高优先级）
2. **几何计算模式**
3. **选择模式**
4. **绘制模式**

这种优先级设计确保用户操作的逻辑性和一致性。

## Direct2D 渲染架构

### 设备资源创建

```cpp
HRESULT CreateDeviceResources(HWND hWnd)
{
    // 如果已存在，直接返回
    if (g_pRenderTarget) return S_OK;
    
    // 获取窗口客户区大小
    RECT rc;
    GetClientRect(hWnd, &rc);
    
    // 创建渲染目标
    HRESULT hr = g_pD2DFactory->CreateHwndRenderTarget(
        D2D1::RenderTargetProperties(),
        D2D1::HwndRenderTargetProperties(
            hWnd, 
            D2D1::SizeU(rc.right - rc.left, rc.bottom - rc.top)
        ),
        &g_pRenderTarget
    );
    
    // 创建画刷
    if (SUCCEEDED(hr)) {
        hr = g_pRenderTarget->CreateSolidColorBrush(
            D2D1::ColorF(D2D1::ColorF::Black), 
            &g_pBrush
        );
    }
    
    // 创建文本格式
    if (SUCCEEDED(hr) && g_pDWriteFactory) {
        hr = g_pDWriteFactory->CreateTextFormat(
            L"Arial",                    // 字体名称
            nullptr,                     // 字体集合
            DWRITE_FONT_WEIGHT_NORMAL,   // 字重
            DWRITE_FONT_STYLE_NORMAL,    // 字体样式
            DWRITE_FONT_STRETCH_NORMAL,  // 字体拉伸
            14.0f,                       // 字号
            L"zh-cn",                    // 区域设置
            &g_pTextFormat
        );
    }
    
    return hr;
}
```

**延迟创建的原因**：
- 窗口创建时可能还没有有效的 HWND
- 设备可能丢失，需要重建
- 节省资源，按需创建

### 设备资源释放

```cpp
void DiscardDeviceResources()
{
    if (g_pBrush) { 
        g_pBrush->Release(); 
        g_pBrush = nullptr; 
    }
    if (g_pRenderTarget) { 
        g_pRenderTarget->Release(); 
        g_pRenderTarget = nullptr; 
    }
    if (g_pTextFormat) { 
        g_pTextFormat->Release(); 
        g_pTextFormat = nullptr; 
    }
}
```

**何时调用**：
- 检测到设备丢失（`D2DERR_RECREATE_TARGET`）
- 程序退出时

### 渲染流程

```cpp
void OnPaint(HWND hWnd)
{
    PAINTSTRUCT ps;
    BeginPaint(hWnd, &ps);
    
    // 1. 创建或获取设备资源
    CreateDeviceResources(hWnd);
    
    if (g_pRenderTarget) {
        // 2. 开始绘制
        g_pRenderTarget->BeginDraw();
        
        // 3. 清空背景
        g_pRenderTarget->Clear(D2D1::ColorF(D2D1::ColorF::White));
        
        // 4. 绘制所有已完成的图形
        for (auto& shape : g_shapes) {
            shape->Draw(g_pRenderTarget, g_pBrush);
        }
        
        // 5. 绘制正在创建的图形
        if (g_currentShape) {
            g_currentShape->Draw(g_pRenderTarget, g_pBrush);
        }
        
        // 6. 显示状态文本
        if (!g_statusText.empty() && g_pTextFormat) {
            g_pBrush->SetColor(D2D1::ColorF(D2D1::ColorF::Blue));
            D2D1_RECT_F textRect = D2D1::RectF(10, 10, 800, 50);
            g_pRenderTarget->DrawText(
                g_statusText.c_str(), 
                g_statusText.length(),
                g_pTextFormat, 
                textRect, 
                g_pBrush
            );
        }
        
        // 7. 结束绘制
        HRESULT hr = g_pRenderTarget->EndDraw();
        
        // 8. 检查设备丢失
        if (hr == D2DERR_RECREATE_TARGET) {
            DiscardDeviceResources();
        }
    }
    
    EndPaint(hWnd, &ps);
}
```

**Direct2D 渲染特点**：
- **即时模式**：每次都重新绘制所有内容
- **硬件加速**：使用 GPU 加速
- **双缓冲**：自动处理，无闪烁

## 内存管理策略

### 智能指针使用

```cpp
// 拥有所有权
std::vector<std::shared_ptr<Shape>> g_shapes;
std::shared_ptr<Shape> g_currentShape;

// 不拥有所有权（观察者）
Shape* g_selectedShape;
```

**原则**：
- 容器中的图形使用 `shared_ptr`
- 临时引用使用原始指针
- 避免循环引用

### 撤销栈的深拷贝

```cpp
void SaveStateToUndoStack()
{
    std::vector<std::shared_ptr<Shape>> stateCopy;
    
    // 深拷贝每个图形
    for (const auto& shape : g_shapes) {
        std::string data = shape->Serialize();
        std::shared_ptr<Shape> newShape = CreateShape(shape->type);
        newShape->Deserialize(data);
        stateCopy.push_back(newShape);
    }
    
    g_undoStack.push_back(stateCopy);
}
```

**为什么需要深拷贝**：
- 图形对象可能被修改
- 撤销时需要完整的历史状态
- 使用序列化/反序列化实现深拷贝

## 性能优化

### 1. 延迟创建资源
- 第一次绘制时才创建 Direct2D 资源
- 减少启动时间

### 2. 最小化重绘
- 只在需要时调用 `InvalidateRect`
- 使用 `FALSE` 参数避免擦除背景

### 3. 高效的碰撞检测
- 使用点到线段距离算法
- 避免复杂的几何计算

### 4. 智能指针
- 自动内存管理
- 避免内存泄漏
