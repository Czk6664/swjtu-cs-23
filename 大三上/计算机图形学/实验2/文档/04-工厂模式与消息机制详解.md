# 工厂模式与消息机制详解

## 一、继承与多态基础

### 1.1 什么是继承？

继承是面向对象编程的核心概念，允许一个类（子类）继承另一个类（基类）的属性和方法。

#### 基本语法
```cpp
// 基类（父类）
class Shape {
public:
    ShapeType type;
    D2D1_COLOR_F color;
    bool selected;
    
    // 构造函数
    Shape(ShapeType t) : type(t), selected(false) {
        color = D2D1::ColorF(D2D1::ColorF::Black);
    }
    
    // 纯虚函数 - 必须由子类实现
    virtual void Draw(ID2D1HwndRenderTarget* pRT, ID2D1SolidColorBrush* pBrush) = 0;
    virtual bool HitTest(D2D1_POINT_2F point) = 0;
};

// 子类（派生类）
class Line : public Shape {
public:
    D2D1_POINT_2F start, end;  // 子类特有的属性
    
    // 调用基类构造函数
    Line() : Shape(ShapeType::LINE) {}
    
    // 实现基类的纯虚函数
    void Draw(ID2D1HwndRenderTarget* pRT, ID2D1SolidColorBrush* pBrush) override {
        pBrush->SetColor(selected ? D2D1::ColorF(D2D1::ColorF::Red) : color);
        pRT->DrawLine(start, end, pBrush, 1.0f);
    }
    
    bool HitTest(D2D1_POINT_2F point) override {
        return PointToLineDistance(point, start, end) < 5.0f;
    }
};
```

#### 继承的好处
- **代码复用**：子类自动拥有基类的所有成员
- **统一接口**：所有图形都有相同的操作接口（Draw、HitTest等）
- **扩展性**：添加新图形类型只需继承Shape类

### 1.2 什么是多态？

多态允许使用基类指针或引用来调用子类的方法，实现"一个接口，多种实现"。

#### 多态的实现机制

```cpp
// 存储不同类型的图形，但都用基类指针
std::vector<std::shared_ptr<Shape>> g_shapes;

// 添加不同类型的图形
g_shapes.push_back(std::make_shared<Line>(...));      // 直线
g_shapes.push_back(std::make_shared<Circle>(...));    // 圆形
g_shapes.push_back(std::make_shared<Triangle>(...));  // 三角形

// 多态调用：虽然都是Shape*指针，但会调用各自的Draw方法
for (auto& shape : g_shapes) {
    shape->Draw(g_pRenderTarget, g_pBrush);  // 自动调用正确的子类方法
}
```

#### 多态的关键要素

1. **虚函数（virtual）**：基类中声明为virtual的函数
2. **override关键字**：子类明确表示重写基类方法
3. **基类指针/引用**：通过基类指针调用子类方法

#### 多态的实际效果

```cpp
// 示例：点击检测
Shape* clickedShape = nullptr;
D2D1_POINT_2F mousePos = {100, 200};

for (auto& shape : g_shapes) {
    // 每个图形有自己的HitTest实现
    // Line检查点到线段的距离
    // Circle检查点到圆心的距离
    // 但调用方式完全相同！
    if (shape->HitTest(mousePos)) {
        clickedShape = shape.get();
        break;
    }
}
```

### 1.3 虚函数表（VTable）原理

C++通过虚函数表实现多态：

```
内存布局示例：

Shape对象：
+------------------+
| vptr (虚函数表指针) |  ← 指向Shape的虚函数表
+------------------+
| type             |
| color            |
| selected         |
+------------------+

Line对象：
+------------------+
| vptr             |  ← 指向Line的虚函数表
+------------------+
| type             |
| color            |
| selected         |
+------------------+
| start            |  ← Line特有的成员
| end              |
+------------------+

虚函数表：
Line的VTable:
+------------------+
| &Line::Draw      |  ← 指向Line::Draw的地址
| &Line::HitTest   |
| &Line::Move      |
| ...              |
+------------------+

Circle的VTable:
+------------------+
| &Circle::Draw    |  ← 指向Circle::Draw的地址
| &Circle::HitTest |
| &Circle::Move    |
| ...              |
+------------------+
```

**调用过程**：
1. 通过对象的vptr找到虚函数表
2. 在虚函数表中查找函数地址
3. 调用对应的函数

## 二、工厂模式详解

### 2.1 什么是工厂模式？

工厂模式是一种创建型设计模式，用于创建对象而不暴露创建逻辑。在本项目中，我们需要根据不同的类型创建不同的图形对象。

### 2.2 为什么需要工厂模式？

**问题场景**：
```cpp
// 不使用工厂模式的代码（不好的做法）
void LoadFromFile(HWND hWnd) {
    std::ifstream file("drawing.txt");
    std::string line;
    
    while (std::getline(file, line)) {
        std::stringstream ss(line);
        std::string type;
        ss >> type;
        
        // 大量的if-else判断，代码重复且难以维护
        if (type == "LINE") {
            auto shape = std::make_shared<Line>();
            shape->Deserialize(line);
            g_shapes.push_back(shape);
        } else if (type == "CIRCLE") {
            auto shape = std::make_shared<Circle>();
            shape->Deserialize(line);
            g_shapes.push_back(shape);
        } else if (type == "RECTANGLE") {
            auto shape = std::make_shared<RectangleShape>();
            shape->Deserialize(line);
            g_shapes.push_back(shape);
        }
        // ... 更多类型
    }
}
```

### 2.3 工厂模式实现

#### 简单工厂函数

```cpp
// 工厂函数：根据类型创建对应的图形对象
std::shared_ptr<Shape> CreateShape(ShapeType type) {
    switch (type) {
        case ShapeType::LINE:
            return std::make_shared<Line>();
        case ShapeType::CIRCLE:
            return std::make_shared<Circle>();
        case ShapeType::RECTANGLE:
            return std::make_shared<RectangleShape>();
        case ShapeType::TRIANGLE:
            return std::make_shared<Triangle>();
        case ShapeType::DIAMOND:
            return std::make_shared<Diamond>();
        case ShapeType::PARALLELOGRAM:
            return std::make_shared<Parallelogram>();
        case ShapeType::CURVE:
            return std::make_shared<Curve>();
        case ShapeType::POLYLINE:
            return std::make_shared<Polyline>();
        default:
            return nullptr;
    }
}
```

#### 使用工厂模式的好处

```cpp
// 使用工厂模式后的代码（清晰简洁）
void LoadFromFile(HWND hWnd) {
    std::ifstream file("drawing.txt");
    std::string line;
    
    while (std::getline(file, line)) {
        std::stringstream ss(line);
        std::string typeStr;
        ss >> typeStr;
        
        // 将字符串转换为枚举类型
        ShapeType type = StringToShapeType(typeStr);
        
        // 使用工厂创建对象
        auto shape = CreateShape(type);
        if (shape) {
            shape->Deserialize(line);
            g_shapes.push_back(shape);
        }
    }
}
```

### 2.4 工厂模式的实际应用

#### 应用场景1：鼠标点击创建图形

```cpp
void OnLButtonDown(HWND hWnd, LPARAM lParam) {
    D2D1_POINT_2F point = D2D1::Point2F(
        static_cast<float>(LOWORD(lParam)),
        static_cast<float>(HIWORD(lParam))
    );
    
    // 根据当前工具类型创建图形
    if (g_currentTool != ShapeType::NONE && !g_isDrawing) {
        // 使用工厂创建新图形
        g_currentShape = CreateShape(g_currentTool);
        
        if (g_currentShape) {
            g_isDrawing = true;
            g_startPoint = point;
            
            // 根据不同类型进行初始化
            switch (g_currentTool) {
                case ShapeType::LINE: {
                    auto line = std::dynamic_pointer_cast<Line>(g_currentShape);
                    line->start = point;
                    line->end = point;
                    break;
                }
                case ShapeType::CIRCLE: {
                    auto circle = std::dynamic_pointer_cast<Circle>(g_currentShape);
                    circle->center = point;
                    circle->radius = 0;
                    break;
                }
                // ... 其他类型
            }
        }
    }
}
```

#### 应用场景2：撤销/重做功能

```cpp
void SaveStateToUndoStack() {
    std::vector<std::shared_ptr<Shape>> stateCopy;
    
    // 深拷贝所有图形
    for (const auto& shape : g_shapes) {
        // 序列化当前图形
        std::string data = shape->Serialize();
        
        // 使用工厂创建新对象
        auto newShape = CreateShape(shape->type);
        
        // 反序列化数据
        newShape->Deserialize(data);
        
        stateCopy.push_back(newShape);
    }
    
    g_undoStack.push_back(stateCopy);
}
```

### 2.5 工厂模式的优势

1. **集中管理对象创建**：所有创建逻辑在一个地方
2. **易于扩展**：添加新图形只需修改工厂函数
3. **降低耦合**：使用者不需要知道具体类的名称
4. **统一接口**：所有对象通过相同方式创建

## 三、Windows消息机制详解

### 3.1 什么是消息机制？

Windows是事件驱动的操作系统，所有的用户交互（鼠标点击、键盘输入、窗口操作等）都通过消息传递。

### 3.2 消息循环

#### 主消息循环

```cpp
int APIENTRY wWinMain(...) {
    // ... 初始化代码 ...
    
    MSG msg;
    
    // 消息循环：程序的心跳
    while (GetMessage(&msg, nullptr, 0, 0)) {
        // 1. 转换键盘消息（如将按键转换为字符）
        TranslateMessage(&msg);
        
        // 2. 分发消息到窗口过程函数（WndProc）
        DispatchMessage(&msg);
    }
    
    // 收到WM_QUIT消息后退出循环
    return (int)msg.wParam;
}
```

#### 消息的生命周期

```
用户操作（点击鼠标）
    ↓
操作系统捕获事件
    ↓
创建消息（WM_LBUTTONDOWN）
    ↓
消息放入消息队列
    ↓
GetMessage获取消息
    ↓
TranslateMessage转换
    ↓
DispatchMessage分发
    ↓
WndProc处理消息
    ↓
返回结果
```

### 3.3 窗口过程函数（WndProc）

WndProc是消息的处理中心，所有消息都会被路由到这里。

```cpp
LRESULT CALLBACK WndProc(HWND hWnd, UINT message, WPARAM wParam, LPARAM lParam)
{
    // message: 消息类型（如WM_PAINT, WM_LBUTTONDOWN等）
    // wParam: 消息的附加信息（如按键代码、菜单ID）
    // lParam: 消息的附加信息（如鼠标坐标）
    
    switch (message)
    {
    case WM_COMMAND:      // 菜单命令消息
        HandleMenuCommand(LOWORD(wParam));
        break;
        
    case WM_PAINT:        // 绘制窗口消息
        OnPaint(hWnd);
        break;
        
    case WM_LBUTTONDOWN:  // 鼠标左键按下
        OnLButtonDown(hWnd, lParam);
        break;
        
    case WM_MOUSEMOVE:    // 鼠标移动
        OnMouseMove(hWnd, lParam);
        break;
        
    default:
        // 默认处理
        return DefWindowProc(hWnd, message, wParam, lParam);
    }
    return 0;
}
```

### 3.4 常用消息类型详解

#### WM_COMMAND - 菜单命令消息

```cpp
case WM_COMMAND:
{
    int wmId = LOWORD(wParam);  // 提取菜单ID
    
    switch (wmId)
    {
    case IDM_DRAW_LINE:

        break;
        
    case IDM_SAVE:
        // 用户点击了"保存"菜单

        break;
    }
    
    // 触发重绘

```

**消息参数解析**：
- `wParam`的低16位（LOWORD）：菜单项ID
- `wParam`的高16位（HIWORD）：通知代码

#### WM_LBUTTONDOWN - 鼠标左键按下

#### WM_MOUSEMOVE - 鼠标移动

```cpp
case WM_MOUSEMOVE:
{
    int x = LOWORD(lParam);
    int y = HIWORD(lParam);
    
    D2D1_POINT_2F point = D2D1::Point2F(
        static_cast<float>(x),
        static_cast<float>(y)
    );
    
    // 如果正在绘制，更新图形
    if (g_isDrawing && g_currentShape) {
        switch (g_currentTool) {
            case ShapeType::LINE: {
                auto line = std::dynamic_pointer_cast<Line>(g_currentShape);
                line->end = point;  // 更新终点
                break;
            }
            case ShapeType::CIRCLE: {
                auto circle = std::dynamic_pointer_cast<Circle>(g_currentShape);
                float dx = point.x - circle->center.x;
                float dy = point.y - circle->center.y;
                circle->radius = sqrt(dx * dx + dy * dy);  // 更新半径
                break;
            }
        }
        
        // 触发重绘
        InvalidateRect(hWnd, nullptr, FALSE);
    }
    break;
}
```

#### WM_PAINT - 窗口绘制

```cpp
case WM_PAINT:
{
    PAINTSTRUCT ps;
    BeginPaint(hWnd, &ps);  // 开始绘制
    
    // 创建Direct2D资源
    CreateDeviceResources(hWnd);
    
    if (g_pRenderTarget) {
        g_pRenderTarget->BeginDraw();
        g_pRenderTarget->Clear(D2D1::ColorF(D2D1::ColorF::White));
        
        // 绘制所有图形
        for (auto& shape : g_shapes) {
            shape->Draw(g_pRenderTarget, g_pBrush);
        }
        
        // 绘制正在创建的图形
        if (g_currentShape) {
            g_currentShape->Draw(g_pRenderTarget, g_pBrush);
        }
        
        g_pRenderTarget->EndDraw();
    }
    
    EndPaint(hWnd, &ps);  // 结束绘制
    break;
}
```

#### WM_MOUSEWHEEL - 鼠标滚轮

```cpp
case WM_MOUSEWHEEL:
{
    // 获取滚轮滚动量
    int delta = GET_WHEEL_DELTA_WPARAM(wParam);
    
    // 缩放模式
    if (g_isScaling && g_selectedShape) {
        // 每次滚动改变10%
        float scaleDelta = (delta > 0) ? 1.1f : 0.9f;
        g_currentScaleFactor *= scaleDelta;
        
        // 应用缩放
        D2D1_POINT_2F center = g_selectedShape->GetCenter();
        g_selectedShape->Scale(center, scaleDelta);
        
        // 更新状态文本
        wchar_t buffer[100];
        swprintf_s(buffer, L"缩放倍数: %.2f (左键确认，右键取消)", g_currentScaleFactor);
        g_statusText = buffer;
        
        InvalidateRect(hWnd, nullptr, FALSE);
    }
    
    // 旋转模式
    if (g_isRotating && g_selectedShape) {
        // 每次滚动旋转5度
        float angleDelta = (delta > 0) ? 5.0f : -5.0f;
        float angleRad = angleDelta * 3.14159f / 180.0f;
        g_currentRotationAngle += angleRad;
        
        // 应用旋转
        D2D1_POINT_2F center = g_selectedShape->GetCenter();
        g_selectedShape->Rotate(center, angleRad);
        
        // 更新状态文本
        float angleDeg = g_currentRotationAngle * 180.0f / 3.14159f;
        wchar_t buffer[100];
        swprintf_s(buffer, L"旋转角度: %.1f° (左键确认，右键取消)", angleDeg);
        g_statusText = buffer;
        
        InvalidateRect(hWnd, nullptr, FALSE);
    }
    break;
}
```

### 3.6 消息处理的优先级设计

在本项目中，消息处理有明确的优先级：

```cpp
void OnLButtonDown(HWND hWnd, D2D1_POINT_2F point) {
    // 优先级1：缩放/旋转确认
    if (g_isScaling || g_isRotating) {
        // 左键确认操作
        SaveStateToUndoStack();
        g_isScaling = false;
        g_isRotating = false;
        g_statusText = L"操作已确认";
        InvalidateRect(hWnd, nullptr, FALSE);
        return;  // 立即返回，不处理其他逻辑
    }
    
    // 优先级2：几何计算模式
    if (g_calcMode != CalcMode::NONE) {
        // 处理几何计算
        HandleGeometryCalculation(point);
        return;
    }
    
    // 优先级3：选择模式
    if (g_currentTool == ShapeType::NONE) {
        // 查找点击的图形
        for (auto& shape : g_shapes) {
            if (shape->HitTest(point)) {
                // 取消之前的选择
                if (g_selectedShape) {
                    g_selectedShape->selected = false;
                }
                // 选中新图形
                g_selectedShape = shape.get();
                g_selectedShape->selected = true;
                g_statusText = L"已选中图形";
                InvalidateRect(hWnd, nullptr, FALSE);
                return;
            }
        }
    }
    
    // 优先级4：绘制模式
    if (g_currentTool != ShapeType::NONE) {
        // 创建新图形
        g_currentShape = CreateShape(g_currentTool);
        g_isDrawing = true;
        // ... 初始化图形 ...
    }
}
```

### 4.1 完整的绘制流程

```cpp
// 1. 用户点击菜单"绘制直线"
// → 触发WM_COMMAND消息
case WM_COMMAND:
    if (wmId == IDM_DRAW_LINE) {

    }
    break;

// 2. 用户在画布上点击

case WM_LBUTTONDOWN:

        InvalidateRect(hWnd, nullptr, FALSE);  // 触发重绘
    }
    break;

// 4. 系统处理重绘请求
// → 触发WM_PAINT消息
case WM_PAINT:
    g_pRenderTarget->BeginDraw();
    // 多态调用：Line::Draw
    g_currentShape->Draw(g_pRenderTarget, g_pBrush);
    g_pRenderTarget->EndDraw();
    break;

// 5. 用户释放鼠标
// → 触发WM_LBUTTONUP消息
case WM_LBUTTONUP:
    if (g_isDrawing) {
        SaveStateToUndoStack();  // 保存到撤销栈
        g_shapes.push_back(g_currentShape);  // 添加到图形列表
        g_currentShape = nullptr;
        g_isDrawing = false;
    }
    break;
```

### 4.2 撤销功能的实现

```cpp
// 撤销功能结合了工厂模式和消息机制
case IDM_UNDO:
    if (!g_undoStack.empty()) {
        // 1. 保存当前状态到重做栈
        g_redoStack.push_back(g_shapes);
        
        // 2. 恢复之前的状态
        g_shapes = g_undoStack.back();
        g_undoStack.pop_back();
        
        // 3. 触发重绘
        InvalidateRect(hWnd, nullptr, FALSE);
    }
    break;

// 保存状态时使用工厂模式进行深拷贝
void SaveStateToUndoStack() {
    std::vector<std::shared_ptr<Shape>> stateCopy;
    
    for (const auto& shape : g_shapes) {
        // 序列化
        std::string data = shape->Serialize();
        
        // 使用工厂创建新对象（多态）
        auto newShape = CreateShape(shape->type);
        
        // 反序列化
        newShape->Deserialize(data);
        
        stateCopy.push_back(newShape);
    }
    
    g_undoStack.push_back(stateCopy);
}
```

## 五、设计模式总结

### 5.1 继承与多态的价值

- **统一接口**：所有图形都有相同的操作方法
- **代码复用**：共同的功能在基类中实现
- **灵活扩展**：添加新图形不影响现有代码

### 5.2 工厂模式的价值

- **封装创建逻辑**：对象创建集中管理
- **降低耦合度**：使用者不需要知道具体类
- **易于维护**：修改创建逻辑只需改工厂

### 5.3 消息机制的价值

- **事件驱动**：响应用户操作
- **解耦合**：界面和逻辑分离
- **灵活处理**：可以在任何时候响应任何事件

### 5.4 三者的协同工作

```
用户点击菜单
    ↓
消息机制（WM_COMMAND）
    ↓
设置当前工具类型
    ↓
用户点击画布
    ↓
消息机制（WM_LBUTTONDOWN）
    ↓
工厂模式创建图形对象
    ↓
多态调用图形方法
    ↓
消息机制触发重绘（WM_PAINT）
    ↓
多态调用Draw方法
```

这种设计使得程序结构清晰、易于扩展、便于维护。
