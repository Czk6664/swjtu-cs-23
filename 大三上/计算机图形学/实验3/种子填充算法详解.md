## 算法原理

种子填充（Seed Fill / Flood Fill）是一种**区域填充算法**，从一个种子点开始，向四周扩散填充所有颜色相同的连通区域。

**核心思想：**
- 从种子点出发，查找所有与种子点颜色相同的相邻像素
- 使用**扫描线**优化，一次填充整行连续的像素
- 使用**队列**管理待处理的扫描线段

**适用场景：**
- 填充不规则封闭区域（如用户绘制的图形内部）
- Paint工具的油漆桶功能
- 图像分割和区域标记

## 算法步骤

### 完整流程（SeedFillD2D.h）

```
步骤1：准备工作（内存重绘）
├─ 创建WIC位图（内存位图）
├─ 创建WIC渲染目标
├─ 在内存中重新绘制所有图形（白色背景+黑色边界）
└─ 确保读取到纯净的边界数据

步骤2：锁定像素数据
├─ 锁定WIC位图获取像素数组指针
├─ 获取pitch（每行字节数）
└─ 准备直接操作像素

步骤3：颜色检查
├─ 获取种子点的目标颜色
├─ 判断目标颜色和填充颜色是否太接近
└─ 如果太接近则停止（避免无意义填充）

步骤4：扫描线填充（核心算法）
└─ 调用 FloodFillScanline 执行填充

步骤5：转换回D2D位图
├─ 将填充后的WIC位图转为D2D1Bitmap
└─ 返回给调用者显示
```

## 扫描线填充详解

### 核心数据结构

```cpp
struct Span {
    int x1, x2;  // 扫描线段的左右边界
    int y;       // 所在行
    int dy;      // 扫描方向（+1向上，-1向下）
};
```

### 算法流程

```
FloodFillScanline(pixels, seedX, seedY, targetColor, newColor) {
    
    1. 填充种子扫描线
       ├─ 从种子点向左扫描，找到边界 left
       ├─ 从种子点向右扫描，找到边界 right
       └─ 填充整条扫描线 [left, right]
       
    2. 将相邻行加入队列
       ├─ queue.push({left, right, seedY, +1})  // 向上扫描
       └─ queue.push({left, right, seedY, -1})  // 向下扫描
       
    3. BFS处理队列
       while (队列不空) {
           取出一个 Span(x1, x2, y, dy)
           在 y+dy 行中扫描：
           
           ├─ 跳过不匹配的像素
           ├─ 找到匹配的连续区域
           ├─ 向左右扩展找到完整边界 [spanLeft, spanRight]
           ├─ 填充这个区域
           ├─ queue.push({spanLeft, spanRight, y, dy})   // 同向继续
           └─ queue.push({spanLeft, spanRight, y, -dy})  // 反向检查
       }
}
```

### 伪代码

```cpp
void FloodFillScanline(pixels, seedX, seedY, targetColor, newColor) {
    Queue<Span> queue;
    
    // === 第1步：填充种子行 ===
    left = seedX;
    while (left > 0 && pixels[left-1] == targetColor) 
        left--;
    
    right = seedX;
    while (right < width-1 && pixels[right+1] == targetColor) 
        right++;
    
    for (x = left to right) 
        pixels[x] = newColor;
    
    // === 第2步：添加相邻行到队列 ===
    queue.push(Span{left, right, seedY, +1});  // 向上
    queue.push(Span{left, right, seedY, -1});  // 向下
    
    // === 第3步：BFS扫描 ===
    while (!queue.empty()) {
        span = queue.pop();
        y = span.y + span.dy;
        
        if (y < 0 || y >= height) continue;
        
        // 在新行中查找连续的目标色区域
        x = span.x1;
        while (x <= span.x2) {
            // 跳过非目标色
            while (x <= span.x2 && pixels[x,y] != targetColor) 
                x++;
            
            if (x > span.x2) break;
            
            // 找到一段，向左右扩展
            spanLeft = x;
            while (spanLeft > 0 && pixels[spanLeft-1,y] == targetColor) 
                spanLeft--;
            
            spanRight = x;
            while (spanRight < width-1 && pixels[spanRight+1,y] == targetColor) 
                spanRight++;
            
            // 填充这段
            for (i = spanLeft to spanRight) 
                pixels[i,y] = newColor;
            
            // 继续扫描
            queue.push(Span{spanLeft, spanRight, y, span.dy});   // 同向
            queue.push(Span{spanLeft, spanRight, y, -span.dy});  // 反向
            
            x = spanRight + 1;
        }
    }
}
```

## 关键技术点

### 1. 颜色匹配

```cpp
bool ColorsMatch(UINT32 c1, UINT32 c2) {
    // BGRA格式：0xAARRGGBB
    int b1 = (c1) & 0xFF;
    int g1 = (c1 >> 8) & 0xFF;
    int r1 = (c1 >> 16) & 0xFF;
    
    int b2 = (c2) & 0xFF;
    int g2 = (c2 >> 8) & 0xFF;
    int r2 = (c2 >> 16) & 0xFF;
    
    const int TOLERANCE = 5;  // 容差
    return abs(r1-r2)<=TOLERANCE && 
           abs(g1-g2)<=TOLERANCE && 
           abs(b1-b2)<=TOLERANCE;
}
```

**为什么需要容差？**
- Direct2D绘制的图形边缘有**抗锯齿**
- 边缘像素是背景色和边界色的混合
- 容差=0：填充会穿透边缘
- 容差=5：平衡抗锯齿和防止泄漏

### 2. 像素格式（BGRA）

```
内存布局（小端序）：
地址   +0   +1   +2   +3
     ┌────┬────┬────┬────┐
     │ B  │ G  │ R  │ A  │
     └────┴────┴────┴────┘

UINT32: 0xAARRGGBB

提取分量：
B = (color) & 0xFF
G = (color >> 8) & 0xFF
R = (color >> 16) & 0xFF
A = (color >> 24) & 0xFF
```

### 3. 像素访问

```cpp
// 获取像素颜色
UINT32 GetPixelColor(BYTE* pixels, UINT32 pitch, int x, int y) {
    BYTE* pixel = pixels + y * pitch + x * 4;
    return *(UINT32*)pixel;
}

// 设置像素颜色
void SetPixelColor(BYTE* pixels, UINT32 pitch, int x, int y, UINT32 color) {
    BYTE* pixel = pixels + y * pitch + x * 4;
    *(UINT32*)pixel = color;
}
```

**Pitch的作用：**
- pitch = 每行字节数
- 可能 > width×4（内存对齐）
- 必须使用pitch而不是width×4

## 复杂度分析

### 时间复杂度：O(n)
- n = 填充区域的像素数
- 每个像素最多访问常数次
- 队列操作：O(扫描线段数)

### 空间复杂度：O(w)
- w = 图像宽度
- 队列最多存储O(w)个扫描线段
- 不需要额外标记数组

### 优化对比

| 方法 | 栈/队列深度 | 操作次数 | 优缺点 |
|------|------------|----------|--------|
| 递归版本 | O(h×w) | O(n) | 可能栈溢出 |
| 队列版本 | O(h×w) | O(n) | 空间大 |
| **扫描线版本** | **O(w)** | **O(n/w行)** | **最优** |

## 总结

种子填充算法的**核心优势**：
- ✅ 可填充任意形状的封闭区域
- ✅ 不需要预知区域边界
- ✅ 扫描线优化性能高效

**关键技术**：
- 内存重绘确保边界清晰
- 颜色容差处理抗锯齿
- BFS+扫描线优化算法
