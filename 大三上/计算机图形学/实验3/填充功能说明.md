# 填充功能说明

## 支持填充的封闭图形

所有封闭图形现在都支持**栅栏填充**和**种子填充**两种填充方式:

### 1. 圆形 (Circle)
- ✅ 支持栅栏填充
- ✅ 支持种子填充
- 使用 `FillEllipse` 进行填充

### 2. 矩形 (Rectangle)
- ✅ 支持栅栏填充
- ✅ 支持种子填充
- 使用 `FillGeometry` 进行填充

### 3. 三角形 (Triangle)
- ✅ 支持栅栏填充
- ✅ 支持种子填充
- 使用 `FillGeometry` 进行填充

### 4. 菱形 (Diamond)
- ✅ 支持栅栏填充
- ✅ 支持种子填充
- 使用 `FillGeometry` 进行填充

### 5. 平行四边形 (Parallelogram)
- ✅ 支持栅栏填充
- ✅ 支持种子填充
- 使用 `FillGeometry` 进行填充

### 6. 多边形 (Polyline - 封闭时)
- ✅ 支持栅栏填充
- ✅ 支持种子填充
- 使用 `FillGeometry` 进行填充

## 实现细节

### Shape基类添加的功能

```cpp
class Shape {
    bool filled;              // 是否填充
    D2D1_COLOR_F fillColor;   // 填充颜色
    
    // 填充方法
    virtual void Fill(D2D1_COLOR_F color);
    
    // 判断是否可填充
    virtual bool CanFill() const;
};
```

### 填充逻辑

每个封闭图形的 `Draw` 方法现在包含:

1. **绘制填充** (如果 `filled == true`)
   ```cpp
   if (filled) {
       pBrush->SetColor(fillColor);
       pRT->FillGeometry(pPath, pBrush);  // 或 FillEllipse
   }
   ```

2. **绘制轮廓**
   ```cpp
   pBrush->SetColor(selected ? Red : color);
   pRT->DrawGeometry(pPath, pBrush, width);
   ```

## 使用方法

### 方法1: 栅栏填充 (扫描线填充)

1. 绘制任意封闭图形(圆形、矩形、三角形、菱形、平行四边形、多边形)
2. 选择菜单: **填充 → 栅栏填充**
3. 点击要填充的图形
4. 图形将使用扫描线算法填充

### 方法2: 种子填充

1. 绘制任意封闭图形
2. 选择菜单: **填充 → 种子填充**
3. 点击封闭图形**内部**任意一点
4. 图形将使用种子填充算法(四连通)填充

### 方法3: 多边形直接填充

1. 选择菜单: **绘图工具 → 多边形(用于填充)**
2. 依次点击多边形顶点
3. 右键完成
4. 多边形自动填充

## 填充颜色

- 默认填充颜色: 半透明黄色 `D2D1::ColorF(Yellow, 0.5f)`
- 可以通过修改 `fillColor` 属性自定义颜色
- 填充颜色支持透明度,可以看到下层图形

## 技术特点

1. **Direct2D 硬件加速**: 使用 Direct2D 的原生填充功能,性能优异
2. **抗锯齿**: 自动支持抗锯齿,边缘平滑
3. **透明度支持**: 填充颜色支持 alpha 通道
4. **保留轮廓**: 填充后仍保留图形轮廓线
5. **选中高亮**: 选中的图形轮廓显示为红色

## 示例代码

### 填充圆形
```cpp
Circle* circle = new Circle(center, radius);
circle->Fill(D2D1::ColorF(D2D1::ColorF::Blue, 0.3f));
circle->Draw(pRT, pBrush);
```

### 填充矩形
```cpp
RectangleShape* rect = new RectangleShape(topLeft, bottomRight);
rect->Fill(D2D1::ColorF(D2D1::ColorF::Green, 0.5f));
rect->Draw(pRT, pBrush);
```

### 填充多边形
```cpp
PolylineShape* poly = new PolylineShape();
poly->AddPoint(p1);
poly->AddPoint(p2);
poly->AddPoint(p3);
poly->Fill(D2D1::ColorF(D2D1::ColorF::Red, 0.4f));
poly->Draw(pRT, pBrush);
```

## 注意事项

1. **封闭性**: 种子填充要求图形必须完全封闭,否则可能填充整个画布
2. **点击位置**: 种子填充时必须点击图形内部,点击外部无效
3. **性能**: Direct2D 填充性能优异,即使复杂多边形也能流畅渲染
4. **兼容性**: 所有填充功能兼容 Windows 7 及以上系统
