## 一、栅栏填充 (三种使用方式)

### 方式1: 直接绘制填充多边形 ⭐推荐

**步骤**:
1. 菜单: **绘图工具 → 多边形(用于填充)**
2. 在画布上依次点击顶点(至少3个)
3. **右键**完成绘制
4. 多边形自动填充

**示例**:
```
绘制三角形:
1. 菜单: 绘图工具 → 多边形
2. 点击(100, 100)
3. 点击(200, 100)
4. 点击(150, 200)
5. 右键完成
→ 显示填充的三角形
```

### 方式2: 点击已有图形进行填充 ⭐新增

**步骤**:
1. 先绘制封闭图形(圆形、矩形、三角形、菱形、平行四边形、多边形)
2. 菜单: **填充 → 栅栏填充**
3. 点击要填充的图形
4. 图形被填充

**支持的图形**:
- ✅ 圆形
- ✅ 矩形
- ✅ 三角形
- ✅ 菱形
- ✅ 平行四边形
- ✅ 多边形
- ❌ 直线(不封闭)
- ❌ Bezier曲线(不封闭)

**示例**:
```
填充矩形:
1. 绘制矩形
2. 菜单: 填充 → 栅栏填充
3. 点击矩形
→ 矩形被填充(黄色半透明)
```

### 方式3: 选中图形后填充 (通过Shape的Fill方法)

**步骤**:
1. 绘制封闭图形
2. 选中图形
3. 使用栅栏填充点击
4. 图形被填充

## 二、种子填充

### 使用方法

**步骤**:
1. 先绘制封闭图形
2. 菜单: **填充 → 种子填充**
3. 点击图形**内部**
4. 区域被填充

**重要提示**:
- ⚠️ 必须点击图形内部
- ⚠️ 图形必须完全封闭
- ⚠️ 如果有缝隙,可能填充整个画布

**示例**:
```
填充圆形:
1. 绘制圆形
2. 菜单: 填充 → 种子填充
3. 点击圆形内部
→ 圆形被填充
```

- **保留边框**: 填充不影响图形边框
- **可撤销**: 填充操作可以撤销(Ctrl+Z)

## 五、常见问题解答

### Q1: 点击图形没有反应?

**可能原因**:
1. 没有先选择"填充 → 栅栏填充"菜单
2. 点击的图形不支持填充(如直线)
3. 点击位置不准确

**解决方法**:
1. 先点击菜单"填充 → 栅栏填充"
2. 确保图形是封闭的
3. 点击图形边界或内部

### Q2: 状态栏显示"未点击到可填充的图形"?

**原因**: 点击位置没有图形,或图形不支持填充

**解决方法**:
- 确保点击在图形上
- 检查图形类型是否支持填充

### Q3: 圆形无法填充?

**已修复**: 现在圆形支持栅栏填充

**使用方法**:
1. 绘制圆形
2. 菜单: 填充 → 栅栏填充
3. 点击圆形
4. 圆形被填充

### Q4: 如何取消填充?

**方法**:
1. 撤销: 编辑 → 撤销 (Ctrl+Z)
2. 删除图形: 选中 → 删除

### Q5: 填充后边框消失了?

**不会**: 填充只填充内部,边框保留

## 七、实现原理

### 栅栏填充点击图形

```cpp
// 在OnLButtonDown中
if (g_fillMode == FillMode::FENCE && g_currentTool == ShapeType::NONE) {
    // 查找点击的图形
    for (auto& shape : g_shapes) {
        if (shape->HitTest(point) && shape->CanFill()) {
            SaveStateToUndoStack();
            D2D1_COLOR_F fillColor = D2D1::ColorF(D2D1::ColorF::Yellow, 0.5f);
            shape->Fill(fillColor);  // 调用图形的Fill方法
            g_statusText = L"图形已填充";
            g_fillMode = FillMode::NONE;
            InvalidateRect(hWnd, nullptr, FALSE);
            return;
        }
    }
    g_statusText = L"未点击到可填充的图形";
}
```

### Shape的Fill方法

```cpp
class Shape {
    bool filled;
    D2D1_COLOR_F fillColor;
    
    virtual void Fill(D2D1_COLOR_F color) {
        filled = true;
        fillColor = color;
    }
    
    virtual bool CanFill() const {
        return type == ShapeType::CIRCLE || 
               type == ShapeType::RECTANGLE || 
               type == ShapeType::TRIANGLE ||
               type == ShapeType::DIAMOND ||
               type == ShapeType::PARALLELOGRAM ||
               type == ShapeType::POLYLINE;
    }
};
```

### 绘制时的填充

```cpp
void Circle::Draw(ID2D1HwndRenderTarget* pRT, ID2D1SolidColorBrush* pBrush) {
    D2D1_ELLIPSE ellipse = D2D1::Ellipse(center, radius, radius);
    
    // 如果已填充,先绘制填充
    if (filled) {
        pBrush->SetColor(fillColor);
        pRT->FillEllipse(ellipse, pBrush);
    }
    
    // 然后绘制边框
    pBrush->SetColor(selected ? Red : color);
    pRT->DrawEllipse(ellipse, pBrush, width);
}
```
