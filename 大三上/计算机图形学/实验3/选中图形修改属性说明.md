# 选中图形修改线型和线宽功能说明

## 功能概述

现在可以选中直线或圆形后,通过菜单点击来修改它们的线型和线宽属性。

## 使用方法

### 1. 选中图形

**步骤**:
1. 点击菜单: **编辑 → 选择**
2. 点击画布上的直线或圆形
3. 被选中的图形会以**红色**高亮显示

### 2. 修改线宽

**适用图形**: 直线、圆形

**步骤**:
1. 选中一条直线或圆形(显示为红色)
2. 点击菜单: **线宽 → 选择线宽**
   - 1像素
   - 3像素
   - 5像素
   - 10像素(扫描线填充)
3. 选中图形的线宽立即改变

**效果**:
- 状态栏显示: "选中直线的线宽已设置为X像素" 或 "选中圆形的线宽已设置为X像素"
- 图形立即重绘,显示新的线宽

### 3. 修改线型

**适用图形**: 直线

**步骤**:
1. 选中一条直线(显示为红色)
2. 点击菜单: **线型 → 选择线型**
   - 实线
   - 虚线
   - 点线
   - 点划线
3. 选中直线的线型立即改变

**效果**:
- 状态栏显示: "选中直线的线型已设置为XX"
- 直线立即重绘,显示新的线型

## 实现原理

### 菜单处理逻辑

```cpp
case IDM_LINEWIDTH_5:
    g_lineWidth = 5;  // 设置全局默认线宽
    
    // 检查是否有选中的图形
    if (g_selectedShape) {
        if (g_selectedShape->type == ShapeType::LINE) {
            // 修改选中直线的线宽
            static_cast<Line*>(g_selectedShape)->lineWidth = 5;
            g_statusText = L"选中直线的线宽已设置为5像素";
        } else if (g_selectedShape->type == ShapeType::CIRCLE) {
            // 修改选中圆形的线宽
            static_cast<Circle*>(g_selectedShape)->lineWidth = 5;
            g_statusText = L"选中圆形的线宽已设置为5像素";
        } else {
            g_statusText = L"线宽设置为5像素（仅对新绘制的直线和圆有效）";
        }
        InvalidateRect(hWnd, nullptr, FALSE);  // 重绘窗口
    } else {
        g_statusText = L"线宽设置为5像素";
    }
    break;
```

### 线型处理逻辑

```cpp
case IDM_LINESTYLE_DASH:
    g_lineStyle = LineStyleType::DASH;  // 设置全局默认线型
    
    // 检查是否有选中的直线
    if (g_selectedShape && g_selectedShape->type == ShapeType::LINE) {
        // 修改选中直线的线型
        static_cast<Line*>(g_selectedShape)->lineStyle = LineStyleType::DASH;
        g_statusText = L"选中直线的线型已设置为虚线";
        InvalidateRect(hWnd, nullptr, FALSE);  // 重绘窗口
    } else {
        g_statusText = L"线型设置为虚线";
    }
    break;
```

## 功能特点

### 1. 双重功能
- **有选中图形**: 修改选中图形的属性
- **无选中图形**: 设置新绘制图形的默认属性

### 2. 即时反馈
- 修改后立即重绘(`InvalidateRect`)
- 状态栏显示操作结果
- 选中状态保持(红色高亮)

### 3. 类型检查
- 线宽: 适用于直线和圆形
- 线型: 仅适用于直线
- 其他图形: 显示提示信息

### 4. 智能提示
根据不同情况显示不同的状态栏消息:
- 成功修改: "选中XX的XX已设置为XX"
- 图形不支持: "XX设置为XX（仅对新绘制的XX有效）"
- 无选中: "XX设置为XX"

## 扩展其他图形

如果要为其他图形添加线宽/线型修改功能,只需:

1. **确保图形类有对应属性**:
```cpp
class RectangleShape : public Shape {
    int lineWidth;  // 添加线宽属性
    LineStyleType lineStyle;  // 添加线型属性
};
```

2. **在菜单处理中添加判断**:
```cpp
case IDM_LINEWIDTH_5:
    g_lineWidth = 5;
    if (g_selectedShape) {
        // ... 现有的LINE和CIRCLE判断 ...
        else if (g_selectedShape->type == ShapeType::RECTANGLE) {
            static_cast<RectangleShape*>(g_selectedShape)->lineWidth = 5;
            g_statusText = L"选中矩形的线宽已设置为5像素";
        }
        InvalidateRect(hWnd, nullptr, FALSE);
    }
    break;
```

## 注意事项

1. **选中状态**: 必须先选中图形才能修改属性
2. **图形类型**: 确保图形类型支持该属性
3. **重绘**: 修改后会自动重绘窗口
4. **持久化**: 修改的属性会保持,直到再次修改
5. **撤销/重做**: 属性修改不会自动添加到撤销栈(可以扩展)

- `Ctrl+Shift+D`: 虚线
- `Ctrl+Shift+O`: 点线
- `Ctrl+Shift+A`: 点划线
