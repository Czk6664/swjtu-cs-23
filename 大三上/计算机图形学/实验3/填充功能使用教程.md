# 种子填充与栅栏填充使用教程

## 概述

本程序提供两种填充方法:
1. **栅栏填充** (扫描线填充) - 用于填充多边形
2. **种子填充** (区域填充) - 用于填充任意封闭区域

两种方法都使用Direct2D实现,支持硬件加速和抗锯齿。

---

## 一、栅栏填充 (多边形填充)

### 功能说明
栅栏填充使用扫描线算法填充多边形。适合填充规则或不规则的多边形。

### 使用方法

#### 方法1: 直接绘制填充多边形

**步骤**:
1. 点击菜单: **绘图工具 → 多边形(用于填充)**
2. 在画布上依次点击多边形的顶点
   - 每次点击会显示一个绿色圆点
   - 状态栏显示: "已添加第X个顶点,右键完成并填充"
3. 至少点击3个顶点
4. **右键点击**完成绘制
5. 多边形自动填充并显示

**效果**:
- 多边形内部填充半透明颜色
- 保留多边形边框
- 填充颜色默认为浅蓝色半透明

**示例**:
```
操作: 绘制三角形
1. 菜单: 绘图工具 → 多边形
2. 点击点1 (100, 100)
3. 点击点2 (200, 100)
4. 点击点3 (150, 200)
5. 右键完成
结果: 显示填充的三角形
```

#### 方法2: 先绘制后填充

**步骤**:
1. 先绘制一个封闭的多边形(使用多边形工具)
2. 点击菜单: **填充 → 栅栏填充**
3. 点击要填充的多边形
4. 多边形被填充

**注意**: 此方法需要多边形是封闭的。

### 栅栏填充原理

```
扫描线算法:
1. 找到多边形的最小和最大Y坐标
2. 对每条扫描线(Y坐标):
   a. 找到与多边形边的所有交点
   b. 交点按X坐标排序
   c. 交点两两配对,填充之间的像素
3. 使用Direct2D的FillGeometry填充
```

### 支持的多边形类型

- ✅ 三角形
- ✅ 四边形
- ✅ 五边形
- ✅ 任意多边形
- ✅ 凸多边形
- ✅ 凹多边形
- ✅ 不规则多边形

## 二、种子填充 (区域填充)

### 功能说明
种子填充从一个种子点开始,填充整个封闭区域。适合填充任意形状的封闭图形。

### 使用方法

**步骤**:
1. 先绘制一个**封闭图形**(圆形、矩形、三角形、多边形等)
2. 点击菜单: **填充 → 种子填充**
3. 点击封闭图形的**内部**任意一点
4. 整个封闭区域被填充

**重要**: 
- ⚠️ 必须点击图形内部,点击外部无效
- ⚠️ 图形必须完全封闭,否则可能填充整个画布

### 种子填充示例

#### 示例1: 填充圆形

```
步骤:
1. 绘制一个圆形
   - 菜单: 绘图工具 → 圆形
   - 拖动绘制圆形
2. 点击菜单: 填充 → 种子填充
3. 点击圆形内部
4. 圆形被填充

结果: 圆形内部填充颜色,边框保留
```

#### 示例2: 填充矩形

```
步骤:
1. 绘制一个矩形
   - 菜单: 绘图工具 → 矩形
   - 拖动绘制矩形
2. 点击菜单: 填充 → 种子填充
3. 点击矩形内部
4. 矩形被填充

结果: 矩形内部填充颜色
```

#### 示例3: 填充三角形

```
步骤:
1. 绘制一个三角形
   - 菜单: 绘图工具 → 三角形
   - 拖动绘制三角形
2. 点击菜单: 填充 → 种子填充
3. 点击三角形内部
4. 三角形被填充

结果: 三角形内部填充颜色
```

#### 示例4: 填充多边形

```
步骤:
1. 绘制一个多边形
   - 菜单: 绘图工具 → 多边形
   - 点击顶点,右键完成
2. 点击菜单: 填充 → 种子填充
3. 点击多边形内部
4. 多边形被填充

结果: 多边形内部填充颜色
```

### 种子填充原理

```
四连通区域填充算法:
1. 从种子点开始
2. 获取种子点的颜色(目标颜色)
3. 使用队列进行广度优先搜索:
   a. 将种子点入队
   b. 出队一个点,填充为新颜色
   c. 检查上下左右四个邻居
   d. 如果邻居是目标颜色,入队
   e. 重复直到队列为空
4. 使用Direct2D重绘填充后的图形
```

### 支持的图形类型

种子填充支持所有封闭图形:
- ✅ 圆形
- ✅ 矩形
- ✅ 三角形
- ✅ 菱形
- ✅ 平行四边形
- ✅ 多边形
- ✅ 任意封闭曲线

## 三、两种填充方法对比

| 特性 | 栅栏填充 | 种子填充 |
|------|---------|---------|
| **适用图形** | 多边形 | 任意封闭图形 |
| **使用方式** | 绘制多边形时自动填充 | 点击图形内部填充 |
| **算法** | 扫描线算法 | 四连通区域填充 |
| **优点** | 快速,适合多边形 | 通用,适合任意形状 |
| **缺点** | 仅限多边形 | 需要点击内部 |
| **性能** | 高 | 中等 |
| **封闭性要求** | 自动封闭 | 必须完全封闭 |

## 四、填充颜色设置

### 默认填充颜色

- **多边形填充**: 浅蓝色半透明 `D2D1::ColorF(0.8f, 0.9f, 1.0f, 0.5f)`
- **种子填充**: 黄色半透明 `D2D1::ColorF(Yellow, 0.5f)`

### 修改填充颜色

在代码中修改全局变量:

```cpp
// 修改多边形填充颜色
D2D1_COLOR_F g_fillColor = D2D1::ColorF(D2D1::ColorF::Red, 0.3f);

// 修改种子填充颜色
D2D1_COLOR_F fillColor = D2D1::ColorF(D2D1::ColorF::Green, 0.4f);
```

## 五、常见问题

### Q1: 种子填充后整个画布都被填充了?
**原因**: 图形不是完全封闭的,有缝隙
**解决**: 
- 确保图形完全封闭
- 检查图形边界是否连续
- 使用更粗的线宽绘制边界

### Q2: 点击图形内部没有反应?
**原因**: 
- 点击位置不在图形内部
- 图形颜色与填充颜色相同
**解决**:
- 确保点击在图形内部
- 使用不同的填充颜色

### Q3: 多边形填充不完整?
**原因**: 多边形顶点太少或顺序错误
**解决**:
- 至少需要3个顶点
- 按顺序点击顶点
- 右键完成绘制

### Q4: 填充颜色看不清?
**原因**: 透明度太高
**解决**:
- 降低alpha值(增加不透明度)
- 例如: `D2D1::ColorF(Red, 0.8f)` (更不透明)

### Q5: 如何取消填充?
**方法**:
- 使用撤销功能: 编辑 → 撤销 (Ctrl+Z)
- 或者删除填充的图形: 选中 → 删除
