# 使用扫描线填充法修改直线和圆的线宽

## 功能说明

现在可以选中直线或圆形,使用**扫描线填充法**来修改它们的线宽,而不是使用Direct2D的默认绘制方法。

## 实现原理

### 1. 直线的扫描线填充

对于直线,扫描线填充法的原理是:
1. 计算直线的垂直方向向量
2. 根据线宽,在直线两侧各偏移 `width/2` 的距离
3. 形成一个平行四边形(矩形)
4. 使用扫描线算法填充这个矩形

**代码实现**:
```cpp
void Line::DrawWithScanlineFill(HDC hdc, COLORREF drawColor) {
    int width = selected ? lineWidth + 1 : lineWidth;
    ScanlineFill::DrawThickLine(hdc, (int)start.x, (int)start.y, 
                                (int)end.x, (int)end.y, width, drawColor);
}
```

**扫描线填充算法**:
```cpp
static void DrawThickLine(HDC hdc, int x1, int y1, int x2, int y2, int width, COLORREF color) {
    // 计算线段的垂直方向
    float dx = x2 - x1;
    float dy = y2 - y1;
    float len = sqrt(dx * dx + dy * dy);
    
    float perpX = -dy / len * (width / 2.0f);
    float perpY = dx / len * (width / 2.0f);
    
    // 计算粗线的四个顶点
    POINT poly[4];
    poly[0] = {(LONG)(x1 + perpX), (LONG)(y1 + perpY)};
    poly[1] = {(LONG)(x1 - perpX), (LONG)(y1 - perpY)};
    poly[2] = {(LONG)(x2 - perpX), (LONG)(y2 - perpY)};
    poly[3] = {(LONG)(x2 + perpX), (LONG)(y2 + perpY)};
    
    // 使用扫描线填充多边形
    FillPolygonScanline(hdc, poly, 4, color);
}
```

### 2. 圆的扫描线填充

对于圆形,扫描线填充法的原理是:
1. 计算外圆半径 = `radius + width/2`
2. 计算内圆半径 = `radius - width/2`
3. 填充两个圆之间的环形区域
4. 对每个像素判断其到圆心的距离是否在内外半径之间

**代码实现**:
```cpp
void Circle::DrawWithScanlineFill(HDC hdc, COLORREF drawColor) {
    int width = selected ? lineWidth + 1 : lineWidth;
    
    if (width <= 1) {
        // 细线圆,使用中点法或Bresenham法
        std::vector<POINT> pixels;
        if (circleAlgorithm == CircleAlgorithm::MIDPOINT) {
            pixels = MidpointCircle::DrawCircle((int)center.x, (int)center.y, (int)radius);
        } else {
            pixels = BresenhamCircle::DrawCircle((int)center.x, (int)center.y, (int)radius);
        }
        for (const auto& p : pixels) {
            SetPixel(hdc, p.x, p.y, drawColor);
        }
    } else {
        // 粗线圆,绘制环形区域
        int outerRadius = (int)(radius + width / 2.0f);
        int innerRadius = (int)(radius - width / 2.0f);
        
        for (int y = cy - outerRadius; y <= cy + outerRadius; y++) {
            for (int x = cx - outerRadius; x <= cx + outerRadius; x++) {
                int dx = x - cx;
                int dy = y - cy;
                int distSq = dx * dx + dy * dy;
                
                // 判断是否在环形区域内
                if (distSq <= outerRadius² && distSq >= innerRadius²) {
                    SetPixel(hdc, x, y, drawColor);
                }
            }
        }
    }
}
```

## 使用方法

### 方法1: 在代码中调用

```cpp
// 获取HDC
HDC hdc = GetDC(hwnd);

// 选中直线
Line* line = selectedLine;
COLORREF color = RGB(255, 0, 0);  // 红色
line->DrawWithScanlineFill(hdc, color);

// 选中圆形
Circle* circle = selectedCircle;
circle->DrawWithScanlineFill(hdc, color);

// 释放HDC
ReleaseDC(hwnd, hdc);
```

### 方法2: 集成到绘图流程

在主绘图函数中,可以添加一个选项来决定是否使用扫描线填充:

```cpp
bool useScanlineFill = true;  // 全局变量

void OnPaint(HWND hwnd) {
    if (useScanlineFill) {
        // 使用GDI和扫描线填充
        HDC hdc = GetDC(hwnd);
        for (auto& shape : shapes) {
            if (shape->type == ShapeType::LINE) {
                Line* line = static_cast<Line*>(shape);
                line->DrawWithScanlineFill(hdc, ColorToRGB(line->color));
            } else if (shape->type == ShapeType::CIRCLE) {
                Circle* circle = static_cast<Circle*>(shape);
                circle->DrawWithScanlineFill(hdc, ColorToRGB(circle->color));
            }
        }
        ReleaseDC(hwnd, hdc);
    } else {
        // 使用Direct2D绘制
        // ... Direct2D代码 ...
    }
}
```

## 优势和特点

### 扫描线填充法的优势

1. **精确控制**: 完全控制每个像素的绘制
2. **算法理解**: 直观展示扫描线填充算法的工作原理
3. **教学价值**: 适合计算机图形学课程演示
4. **无依赖**: 只使用GDI,不依赖Direct2D

### Direct2D的优势

1. **硬件加速**: GPU加速,性能更好
2. **抗锯齿**: 自动抗锯齿,边缘更平滑
3. **高质量**: 更好的视觉效果
4. **功能丰富**: 支持更多高级特性

## 线宽效果对比

| 线宽 | 扫描线填充效果 | Direct2D效果 |
|------|---------------|--------------|
| 1像素 | 单像素线条,锯齿明显 | 抗锯齿,边缘平滑 |
| 3像素 | 填充矩形/环形,边缘锯齿 | 平滑粗线 |
| 5像素 | 填充矩形/环形,边缘锯齿 | 平滑粗线 |
| 10像素 | 填充矩形/环形,边缘锯齿 | 平滑粗线 |

## 注意事项

1. **坐标转换**: Direct2D使用浮点坐标,GDI使用整数坐标,需要转换
2. **颜色格式**: Direct2D使用`D2D1_COLOR_F`,GDI使用`COLORREF`,需要转换
3. **性能**: 扫描线填充是软件渲染,大量图形时性能较低
4. **锯齿**: 扫描线填充没有抗锯齿,边缘会有锯齿
5. **HDC管理**: 使用完HDC后要及时释放

## 颜色转换工具函数

```cpp
// D2D1_COLOR_F 转 COLORREF
COLORREF ColorToRGB(D2D1_COLOR_F color) {
    return RGB((BYTE)(color.r * 255), 
               (BYTE)(color.g * 255), 
               (BYTE)(color.b * 255));
}

// COLORREF 转 D2D1_COLOR_F
D2D1_COLOR_F RGBToColor(COLORREF rgb) {
    return D2D1::ColorF(
        GetRValue(rgb) / 255.0f,
        GetGValue(rgb) / 255.0f,
        GetBValue(rgb) / 255.0f
    );
}
```
