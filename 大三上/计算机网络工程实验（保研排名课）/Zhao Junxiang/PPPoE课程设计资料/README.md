## 本层内容介绍

这里是“计算机网络工程实验”课程下的“PPPoE课程设计资料”目录，主要用于整理该项课程实践的相关材料，具体内容见下方文件与子目录。

**阅读建议：**先读任务或报告了解目标，再看代码、数据和结果；借鉴方法后独立完成自己的任务。
