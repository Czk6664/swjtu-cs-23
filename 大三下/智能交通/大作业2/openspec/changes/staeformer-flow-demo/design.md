## Context

大作业1 的 `STAEformer_Package/` 包含完整的模型定义、数据加载、训练脚本。`results/` 目录下已有 5 个数据集 × 4 个模型的训练 checkpoint 和指标 JSON。METRLA 数据集的测试集包含 207 个传感器节点、12 步输入 → 12 步输出的流量预测任务。

## Goals / Non-Goals

**Goals:**
- 加载已训练的 STAEformer baseline checkpoint（不重新训练）
- 在 METRLA 测试集上运行推理，得到预测值和真实值
- 生成 3 张可视化图：单节点预测曲线、多节点热力图、逐步指标柱状图
- 输出 MAE/RMSE/MAPE 指标到 JSON 文件
- 将可视化结果复制到报告 figures 目录

**Non-Goals:**
- 不训练任何模型
- 不修改大作业1 的代码
- 不实现态势融合层（只提供预测模块的 demo 结果）

## Decisions

### 决策 1：复用大作业1 代码 vs 独立重写

**选择**：通过 `sys.path` 引用大作业1 的 STAEformer_Package

**理由**：
- 模型定义、数据加载、指标计算都已写好且经过验证
- 避免代码重复，保持一致性
- checkpoint 格式与原始代码完全兼容

**替代方案**：独立重写 → 工作量大且容易出错

### 决策 2：数据集选择

**选择**：METRLA（207 节点，洛杉矶高速公路）

**理由**：
- 最常用，checkpoint 最完整（baseline/DGL/LA/MST 都有）
- 数据量适中，推理快
- 结果有代表性

### 决策 3：可视化方案

**选择**：3 张图
1. 单节点预测曲线：选一个典型节点，画 12 步预测 vs 真实的折线图
2. 多节点热力图：展示多个节点在同一时间段的预测/真实流量热力图
3. 逐步指标柱状图：展示 1-12 步的 MAE/RMSE 变化趋势

**理由**：这 3 张图分别展示"点"（单节点）、"面"（多节点）、"趋势"（逐步精度）三个维度

## Risks / Trade-offs

- **[路径依赖]** → demo 依赖大作业1 的绝对路径。缓解：用 Path 对象，开头配置根目录
- **[Python 版本]** → 大作业1 可能用不同 Python 版本。缓解：只用基础 numpy/torch/matplotlib
- **[checkpoint 兼容性]** → 如果模型类定义变了 checkpoint 就加载不了。缓解：用原始代码不修改
