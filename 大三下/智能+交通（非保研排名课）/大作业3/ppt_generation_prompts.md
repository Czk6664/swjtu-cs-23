# 大小模型协同的智能交通出行问答系统 — PPT 生成 Prompt 手册

> **说明**：本手册为 19 张幻灯片逐页提供完整生成 prompt。模板风格参照西南交通大学（SWJTU）学术 PPT 模板：深蓝/暗红配色、校训"竢实扬华 自强不息"、SWJTU 校徽、左上角彩色斜向标题栏、内容卡片式布局、箭头连接流程图。Prompt 可直接喂给 AI PPT 生成工具（如 Gamma、Beautiful.ai）或人工制作时作为排版指引。

---

## 模板全局样式说明（所有幻灯片通用）

```
【全局设计规范】
- 宽高比：16:9（宽屏）
- 主色：深蓝 #1A3A6B / 强调红 #C0392B / 金色 #D4A017
- 背景：白色 #FFFFFF 或浅灰 #F5F6FA
- 标题字体：思源黑体 Bold，36–40pt
- 正文字体：思源宋体 Regular，16–20pt
- 数据标注：思源黑体 Medium，14pt
- 左上角固定元素：SWJTU 校徽 logo + "竢实扬华 自强不息" 校训文字
- 右下角固定元素：页码 + 课程名"智能交通"
- 内容卡片：圆角矩形 r=8px，浅蓝填充 #EBF3FB，深蓝边框
- 流程箭头：深蓝实线，箭头填充深蓝，宽度 2px
- 标题栏：左侧带斜切平行四边形装饰，主色填充，白色标题文字
```
