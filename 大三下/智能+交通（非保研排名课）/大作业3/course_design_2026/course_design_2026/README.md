## 本层内容介绍

这里是“智能+交通”课程下的“course_design_2026”目录，主要用于整理文档排版源文件及配套资源。

**阅读建议：**阅读内容时先找同组的 PDF 成稿；修改排版时需要结合主文档和引用资源。
