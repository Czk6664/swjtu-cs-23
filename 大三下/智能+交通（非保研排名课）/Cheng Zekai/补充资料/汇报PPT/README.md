## 本层内容介绍

这里是“智能+交通”课程下的“汇报PPT”目录，主要用于整理演示文稿或汇报材料。

**阅读建议：**先通读演示稿了解主题与结构，再结合对应报告或代码补充细节。

### 本层有哪些内容

本目录及子目录共收录 **4 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **演示文稿（4 份）**：[大作业2_交通场景多目标识别与态势研判_汇报版.pptx](%E5%A4%A7%E4%BD%9C%E4%B8%9A2_%E4%BA%A4%E9%80%9A%E5%9C%BA%E6%99%AF%E5%A4%9A%E7%9B%AE%E6%A0%87%E8%AF%86%E5%88%AB%E4%B8%8E%E6%80%81%E5%8A%BF%E7%A0%94%E5%88%A4_%E6%B1%87%E6%8A%A5%E7%89%88.pptx)、[大作业2_交通标志检测_imagegen版.pptx](%E5%A4%A7%E4%BD%9C%E4%B8%9A2_%E4%BA%A4%E9%80%9A%E6%A0%87%E5%BF%97%E6%A3%80%E6%B5%8B_imagegen%E7%89%88.pptx)等；完整列表见本页导航。
