# 项目说明

## 1. 项目概述

本项目是一个基于 TT100K 数据集的交通标志检测课程设计，核心目标是在真实道路场景下完成交通标志目标检测实验，并形成可用于课程报告撰写的完整工程链路。项目采用 Ultralytics YOLO 框架，覆盖了数据集转换、训练、验证、预测、指标整理和报告素材导出等环节。

从当前文件内容来看，这个项目已经不是单纯的“模型训练脚本集合”，而是一个较完整的课程作业工程，主要由以下三部分组成：

- `traffic_sign_detection`：交通标志检测代码与实验产物。
- `datasets`：TT100K 原始数据集及相关文件。
- `课程设计模版_2026年`：课程报告 LaTeX 模板与已生成的报告材料。

## 2. 项目目标

本项目围绕“基于 TT100K 数据集的交通标志检测”展开，具体目标包括：

- 将 TT100K 原始标注转换为 YOLO 可训练格式。
- 构建适用于课程实验环境的轻量化交通标志检测流程。
- 使用 YOLO11 系列模型完成训练、验证与预测。
- 统计 Precision、Recall、mAP50、mAP50-95 等指标。
- 导出图表和实验素材，为课程设计报告提供支撑。

## 4. 技术方案

项目整体流程为：

1. 读取 TT100K 原始标注与图像。
2. 将标注转换为 YOLO 检测格式。
3. 按训练集、验证集、测试集划分样本。
4. 基于实验配置调用 Ultralytics YOLO 进行训练。
5. 对训练结果进行验证与推理。
6. 汇总指标和图像素材，用于报告展示。

当前实现中，项目聚焦于 12 个交通标志类别，分别为：

- `speed_limit_20`
- `speed_limit_30`
- `speed_limit_40`
- `speed_limit_50`
- `speed_limit_60`
- `speed_limit_70`
- `speed_limit_80`
- `no_stopping`
- `no_parking`
- `no_honking`
- `go_straight`
- `turn_left`

这些类别由 `src/tt100k/classes.py` 中的映射规则统一管理，说明项目并不是直接训练 TT100K 全类别，而是针对课程设计做了一个更适合复现和分析的子集实验。

## 5. 核心脚本说明

### 5.1 数据准备

- `scripts/prepare_tt100k.py`
  - 将 TT100K 原始标注转换为 YOLO 格式。
  - 自动建立 `images/train`、`images/val`、`images/test` 与对应标签目录。
  - 自动生成 `configs/dataset/tt100k.yaml`。

- `scripts/split_tt100k.py`
  - 基于设定比例重新生成训练/验证/测试划分。

当前已生成的数据集规模为：

- 训练集：2705 张图像
- 验证集：772 张图像
- 测试集：386 张图像

总计参与训练流程的有效样本为 3863 张。

### 5.2 模型训练

- `train.py`
  - 读取实验 YAML 配置。
  - 加载指定 YOLO 模型。
  - 支持命令行覆盖设备、批大小、训练轮数、输入尺寸、线程数和实验名。

### 5.3 模型验证

- `val.py`
  - 调用 YOLO 的验证接口。
  - 输出并保存 `map50`、`map50_95`、`precision`、`recall` 等指标。

### 5.4 模型预测

- `predict.py`
  - 使用已训练权重对单张图片或目录进行推理。
  - 可输出带检测框的预测结果图。

### 5.5 报告素材整理

- `scripts/collect_metrics.py`
  - 从结果目录提取指标并输出为 JSON/CSV。

- `export_report_assets.py`
  - 将图表和指标文件复制到报告使用目录，方便插入 LaTeX 文档。

## 8. 运行方式

在 `traffic_sign_detection` 目录下，可按以下步骤运行：

### 8.1 安装依赖

```bash
pip install -r requirements.txt
```

主要依赖包括：

- `ultralytics`
- `pyyaml`
- `pandas`
- `matplotlib`
- `opencv-python`
- `Pillow`
- `numpy`
- `scikit-learn`

### 8.2 准备数据

```bash
python scripts/prepare_tt100k.py --src "datasets/tt100k_2021/tt100k_2021" --dest data/tt100k_yolo
```

### 8.3 训练模型

```bash
python train.py --config configs/experiments/yolo11n_tt100k_cpu_finetune.yaml
```

### 8.4 验证模型

```bash
python val.py --config configs/experiments/yolo11n_tt100k_cpu_finetune.yaml --weights runs/xxx/weights/best.pt
```

### 8.5 进行预测

```bash
python predict.py --config configs/experiments/yolo11n_tt100k_cpu_finetune.yaml --weights runs/xxx/weights/best.pt --source data/tt100k_yolo/images/test
```
