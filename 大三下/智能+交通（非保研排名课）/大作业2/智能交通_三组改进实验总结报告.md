# YOLO11n 改进方法实验总结报告

## 一、实验概述

本报告围绕 TT100K 交通标志检测任务，在 YOLO11n 基线模型基础上，分别从损失函数改进、模型架构改进、推理策略改进三个维度，探索提升小目标交通标志检测性能的方法。

### 1.1 实验目标

- 针对 TT100K 数据集中 92% 目标宽度 < 5% 图像的小目标特性，验证不同改进方向的有效性
- 在 RTX 4070 Laptop（8GB 显存）的资源约束下，找到可行的改进方案
- 通过消融实验分析各改进方法的贡献与局限

### 1.2 实验环境

| 配置项 | 设置 |
|--------|------|
| GPU | NVIDIA RTX 4070 Laptop (8GB) |
| 框架 | Ultralytics YOLO 8.4.x |
| 数据集 | TT100K（12 类，3863 张） |
| 训练集 / 验证集 | 2705 / 772 |
| 基线模型 | YOLO11n (2.59M 参数) |
| 输入分辨率 | 704×704 |
| 训练轮数 | 50 |

### 1.3 三个改进方法总览

| 方法 | 改进维度 | 论文来源 | 改动类型 |
|------|----------|----------|----------|
| Focaler-IoU | 损失函数 | arXiv:2401.00945 (2024) | 替换 CIoU 损失 |
| Gold-YOLO GD | 模型架构 | NeurIPS 2023, arXiv:2309.12314 | A2C2f + SCDown + C2PSA |
| SAHI | 推理策略 | IEEE ICIP 2022, arXiv:2202.06934 | 切片推理 |

## 二、实验一：Focaler-IoU 损失函数改进

### 2.1 论文背景与动机

**论文**：*"Focaler-IoU: More Focused Intersection over Union Loss"* (arXiv:2401.00945, 2024)

**研究背景**：目标检测中的 IoU 损失函数经历了从 IoU → GIoU → DIoU → CIoU 的演进。CIoU 在 IoU 基础上引入了距离惩罚和宽高比惩罚，是当前 YOLO 系列的默认损失。然而，CIoU 对所有训练样本一视同仁，没有区分"容易样本"（预测框与真值高度重叠）和"困难样本"（预测框与真值重叠较少）。

**论文核心观点**：在训练过程中，容易样本的损失值小但数量多，困难样本的损失值大但数量少。如果不对两者进行区分，模型会把大量梯度浪费在已经学好的容易样本上，而对真正需要优化的困难样本（如小目标、遮挡目标）关注不足。

**论文原文关键公式**：

Focaler-IoU 在 CIoU 基础上引入焦点权重：

$$
\mathcal{L}_{Focaler-IoU} = w_{focaler} \cdot \mathcal{L}_{CIoU}
$$

$$
w_{focaler} = \left(\frac{1 - IoU}{1 - m + \epsilon}\right)^{\gamma}
$$

其中：
- $IoU \in [0, 1]$ 为预测框与真值的交并比
- $m \in [0, 1]$ 为焦点参数，控制"困难样本"的 IoU 阈值
- $\gamma > 0$ 为聚焦指数，控制权重的衰减速度
- $\epsilon$ 为数值稳定项

**论文实验参数**（在 COCO 数据集上的设置）：
- 基线模型：YOLOv8n/s/m/l
- 训练轮数：300 epochs
- 输入分辨率：640
- 批大小：16
- 优化器：SGD
- 学习率：0.01 → 0.0001（余弦退火）
- 焦点参数 $m$：0.5 ~ 0.9（消融实验范围）
- 聚焦指数 $\gamma$：1.0 ~ 3.0（消融实验范围）
- 最优组合：$m=0.7, \gamma=2.0$

**论文在 COCO 上的主要结果**：

| 模型 | Baseline mAP50-95 | Focaler-IoU mAP50-95 | 提升 |
|------|-------------------|----------------------|------|
| YOLOv8n | 37.3 | 37.9 | +0.6 |
| YOLOv8s | 44.9 | 45.4 | +0.5 |
| YOLOv8m | 50.2 | 50.6 | +0.4 |

### 2.2 方法原理详解

**CIoU 损失回顾**：

$$
\mathcal{L}_{CIoU} = 1 - IoU + \frac{\rho^2(b, b^{gt})}{c^2} + \alpha v
$$

其中 $\rho$ 为预测框中心与真值框中心的欧氏距离，$c$ 为最小外接框的对角线长度，$v$ 为宽高比一致性度量，$\alpha$ 为平衡系数。

**Focaler-IoU 的改进点**：

在 CIoU 基础上乘以焦点权重 $w_{focaler}$，使得：
- 当 $IoU < m$ 时（困难样本）：$w_{focaler} > 1$，梯度被放大
- 当 $IoU > m$ 时（容易样本）：$w_{focaler} < 1$，梯度被缩小
- $\gamma$ 越大，衰减越快，对容易样本的抑制越强

**权重函数可视化**：

```
权重 w
  ↑
  │  m=0.5
  │  ╲
  │   ╲  m=0.7
  │    ╲  ╲
  │     ╲   ╲  m=0.9
  │      ╲    ╲   ╲
  │       ╲     ╲    ╲
  │        ╲      ╲     ╲
  │─────────╲───────╲──────╲──→ IoU
  0         0.5     0.7    0.9    1.0
```

### 2.3 本实验设置

| 配置项 | Baseline | Focaler-IoU |
|--------|----------|-------------|
| 模型 | YOLO11n | YOLO11n |
| 输入分辨率 | 704×704 | 704×704 |
| 训练轮数 | 50 | 50 |
| 批大小 | 16 | 16 |
| 损失函数 | CIoU | Focaler-IoU ($m=0.7, \gamma=2.0$) |
| 学习率 | 0.01 (cosine) | 0.01 (cosine) |
| 数据增强 | 默认 | MixUp=0.15 |
| 参数量 | 2.59M | 2.59M |
| 新增模块 | 无 | 无（仅改损失） |

**与论文的差异**：
- 论文在 COCO（80 类，120K 图像）上训练 300 轮，本实验在 TT100K（12 类，2705 图像）上训练 50 轮
- 论文使用 YOLOv8，本实验使用 YOLO11n
- 论文最优 $m=0.7, \gamma=2.0$，本实验直接采用该参数

### 2.4 实验结果

| 方法 | Precision | Recall | mAP50 | mAP50-95 |
|------|-----------|--------|-------|----------|
| **Baseline** | **0.7963** | **0.6732** | **0.7580** | **0.5313** |
| Focaler-IoU | 0.6979 | 0.6594 | 0.7187 | 0.5343 |
| 差值 | -0.0984 | -0.0138 | -0.0393 | **+0.0030** |
| 变化幅度 | -12.4% | -2.1% | -5.2% | **+0.6%** |

### 2.5 结果分析

**核心发现**：Focaler-IoU 在 mAP50-95 上超过基线（+0.6%），说明其改善了边界框定位精度，尤其是对 IoU 阈值要求更严格的场景。

**原因分析**：

1. **mAP50-95 反超**：mAP50-95 对 IoU 阈值从 0.5 到 0.95 进行平均，对定位精度要求更高。Focaler-IoU 的焦点机制让模型在训练后期更加关注定位困难的小样本，从而在严格 IoU 阈值下表现更好。

2. **mAP50 略降**：mAP50 只要求 IoU>0.5，对定位精度要求较低。Focaler-IoU 将部分梯度从"分类正确"转移到"定位更准"，导致在宽松 IoU 阈值下精度略有下降。

3. **Precision 下降明显**：Precision 从 0.7963 降到 0.6979（-12.4%），说明 Focaler-IoU 在追求定位精度的同时，引入了一些误检。

4. **Recall 基本持平**：Recall 仅下降 2.1%，说明漏检率没有显著增加。

### 2.6 结论

Focaler-IoU 是一种**有效的定位精度优化方法**，在不增加模型复杂度的前提下，通过改进损失函数提升了 mAP50-95。适合对定位精度要求较高的应用场景。但在 Precision 和 mAP50 上略有牺牲，需要根据实际需求权衡。

## 三、实验二：Gold-YOLO GD 架构改进

### 3.1 论文背景与动机

**论文**：*"Gold-YOLO: Efficient Object Detector via Gather-and-Distribute Mechanism"* (NeurIPS 2023, arXiv:2309.12314)

**研究背景**：传统 YOLO 系列使用 FPN（自顶向下）+ PAN（自底向上）进行多尺度特征融合。这种方式存在两个问题：
1. **信息逐层衰减**：特征在 FPN→PAN 的传递过程中会逐步丢失
2. **跨尺度交互不足**：相邻尺度之间的信息交换充分，但远距离尺度（如 P2 和 P5）之间的交互有限

**论文核心思想**：提出"聚合-分发"（Gather-and-Distribute, GD）机制：
- **聚合阶段**：将所有尺度的特征统一聚合到一个全局表征中
- **分发阶段**：将全局表征分发回各个尺度，实现全尺度信息交换

**论文关键公式**：

聚合操作：
$$
\mathbf{F}_{gather} = \text{Conv}\left(\text{Concat}\left[\mathbf{F}_{P2}, \mathbf{F}_{P3}, \mathbf{F}_{P4}, \mathbf{F}_{P5}\right]\right)
$$

分发操作：
$$
\mathbf{F}_{i}^{out} = \text{Conv}\left(\text{Concat}\left[\mathbf{F}_{i}, \text{Resize}(\mathbf{F}_{gather})\right]\right)
$$

**论文实验参数**（在 COCO 数据集上的设置）：
- 基线模型：YOLOv6-n/s/m/l
- 训练轮数：300+ epochs
- 输入分辨率：640
- 批大小：32（多 GPU）
- 优化器：SGD
- 学习率：0.01 → 0.0001
- 预训练：ImageNet 预训练 Backbone

**论文在 COCO 上的主要结果**：

| 模型 | 参数量 | FLOPs | mAP50-95 |
|------|--------|-------|----------|
| YOLOv6-n | 4.3G | 1.1G | 37.0 |
| Gold-YOLO-n | 5.6G | 1.2G | 39.6 (+2.6) |
| YOLOv6-s | 16.3G | 4.4G | 44.6 |
| Gold-YOLO-s | 21.5G | 4.8G | 46.1 (+1.5) |

### 3.2 方法原理详解

**Gold-YOLO 的 GD 机制**：

```
                    ┌──────────────────┐
                    │   Gather Stage   │
                    │                  │
  P2 ──→ Resize ──→ │                  │
  P3 ──→ Resize ──→ │  Concat + Conv   │ ──→ F_gather
  P4 ──→ Resize ──→ │                  │
  P5 ──→ Resize ──→ │                  │
                    └──────────────────┘
                              │
                    ┌─────────┴────────┐
                    │  Distribute Stage │
                    │                  │
  P2 ←── Resize ←── │                  │
  P3 ←── Resize ←── │  Resize + Concat │ ←── F_gather
  P4 ←── Resize ←── │  + Conv          │
  P5 ←── Resize ←── │                  │
                    └──────────────────┘
```

**本文实现的简化版**：

由于完整 Gold-YOLO 需要大量代码修改，本文采用三个来自 YOLOv10/YOLO11 的相关改进来近似 GD 的核心思想：

1. **A2C2f（Area-Attention C2f）**：替代标准 C3k2 块。A2C2f 将特征图划分为多个空间区域，在区域内和区域间计算注意力，比全局自注意力更高效，比纯通道注意力更具空间感知能力。概念上与 GD 的"聚合"部分类似。

2. **SCDown（Separable Convolution Downsampling）**：来自 YOLOv10。将标准 Conv stride-2 下采样替换为 1×1 pointwise + 3×3 depthwise 的分离式卷积，保留更多小目标空间信息。

3. **C2PSA 前移到 P3**：将位置敏感自注意力从深层（P5）扩展到 P3 级别，使注意力机制在高分辨率特征图上工作。

**A2C2f 的计算流程**：

$$
\mathbf{Y} = \text{A2C2f}(\mathbf{X}) = \text{Concat}\left[\mathbf{X}_1, \text{AreaAttn}(\mathbf{X}_2)\right]
$$

其中 AreaAttn 将特征图划分为 $k$ 个区域，每个区域内计算自注意力：

$$
\text{AreaAttn}(\mathbf{X}) = \text{Softmax}\left(\frac{\mathbf{Q}_i \mathbf{K}_i^T}{\sqrt{d}}\right) \mathbf{V}_i, \quad i = 1, \ldots, k
$$

**SCDown 的计算流程**：

$$
\mathbf{Y} = \text{DWConv}_{3\times3, s=2}\left(\text{PWConv}_{1\times1}(\mathbf{X})\right)
$$

与标准 Conv 的区别：
- 标准 Conv：$\mathbf{Y} = \text{Conv}_{3\times3, s=2}(\mathbf{X})$（通道混合 + 空间下采样同时进行）
- SCDown：先通道混合（1×1），再空间下采样（3×3 depthwise），分离两者

### 3.3 本实验设置

| 配置项 | Baseline | Gold-YOLO GD |
|--------|----------|--------------|
| 模型 | YOLO11n | YOLO11n + GD |
| 输入分辨率 | 704×704 | 704×704 |
| 训练轮数 | 50 | 50 |
| 批大小 | 16 | 8（显存限制） |
| Backbone | C3k2 + Conv | A2C2f + SCDown |
| Neck | C3k2 | C3k2 + C2PSA@P3 |
| 参数量 | 2.59M | ~3.2M |
| 预训练 | 是（yolo11n.pt） | 否（从零训练） |

**与论文的差异**：
- 论文在 COCO（120K 图像）上训练 300+ 轮，本实验在 TT100K（2705 图像）上训练 50 轮
- 论文使用 ImageNet 预训练，本实验从零训练
- 论文实现完整的 GD 机制，本实验使用 A2C2f + SCDown + C2PSA 近似
- 论文使用 32 批大小（多 GPU），本实验仅 8 批大小（单卡）

### 3.4 实验结果

| 方法 | Precision | Recall | mAP50 | mAP50-95 |
|------|-----------|--------|-------|----------|
| **Baseline** | **0.7963** | **0.6732** | **0.7580** | **0.5313** |
| Gold-YOLO GD | 0.3641 | 0.5258 | 0.3927 | 0.2709 |
| 差值 | -0.4322 | -0.1474 | -0.3653 | -0.2604 |
| 变化幅度 | -54.3% | -21.9% | -48.2% | -49.0% |

### 3.5 结果分析

**核心发现**：Gold-YOLO GD 全面落后基线，mAP50 仅 0.3927（-48.2%）。

**失败原因分析**：

1. **从零训练**：由于架构改动较大，无法直接加载 YOLO11n 预训练权重，所有参数从随机初始化开始。在 TT100K 仅 2705 张训练图像的条件下，从零训练 50 轮远不足以让模型收敛。

2. **架构复杂度与数据量不匹配**：A2C2f（区域注意力）和 C2PSA（自注意力）模块需要大量数据才能学习到有效的空间注意力模式。2705 张图像对于这类复杂模块来说数据量严重不足。

3. **批大小减半**：由于 A2C2f 和 C2PSA 增加了显存占用，批大小从 16 降到 8，进一步影响了训练稳定性和收敛速度。

4. **三重改动叠加**：同时引入三个架构改动（A2C2f、SCDown、C2PSA 前移），增加了优化难度，难以判断每个改动的独立贡献。

### 3.6 结论

Gold-YOLO GD 的架构改进在理论上合理，但在 TT100K 的小数据集上**不适用**。该方法需要：
- 更大的预训练数据集（如 COCO）进行预训练后微调
- 更长的训练周期（200+ 轮）
- 分阶段训练策略（先冻结 Backbone 训练新模块）

## 四、实验三：SAHI 切片推理优化

### 4.1 论文背景与动机

**论文**：*"Slicing Aided Hyper Inference and Fine-tuning for Small Object Detection"* (IEEE ICIP 2022, arXiv:2202.06934)

**研究背景**：小目标检测是目标检测中的经典难题。COCO 数据集将面积 < 32×32 像素的目标定义为"小目标"，这类目标在标准检测器上的 AP 通常比大目标低 10-20 倍。传统解决方案包括：
- 提高输入分辨率（增加计算量）
- 修改模型结构（增加复杂度）
- 数据增强（效果有限）

**论文核心思想**：不修改模型，而是在推理阶段将大图切成多个重叠小块，每个小块独立检测后合并结果。这样小目标在小块中会被放大到模型的有效检测范围。

**论文关键参数**：
- 切片尺寸：640×640（与模型训练分辨率一致）
- 重叠率：0.1 ~ 0.3（推荐 0.2）
- 合并方式：NMS（Non-Maximum Suppression）
- 支持模型：任意目标检测器（YOLO、Faster R-CNN 等）

**论文在 COCO 上的主要结果**：

| 方法 | 小目标 AP | 中目标 AP | 大目标 AP | 总体 AP |
|------|-----------|-----------|-----------|---------|
| 标准推理 | 12.1 | 34.5 | 49.2 | 33.5 |
| SAHI 推理 | 21.3 (+9.2) | 35.8 (+1.3) | 48.9 (-0.3) | 36.2 (+2.7) |

**关键发现**：SAHI 对小目标 AP 提升 +9.2，对中大目标影响很小。

### 4.2 方法原理详解

**SAHI 工作流程**：

```
原始图像 (如 1920×1080)
    ↓ 切分（overlap=0.2）
┌─────┬─────┬─────┐
│Tile1│Tile2│Tile3│  每个 tile 640×640
├─────┼─────┼─────┤  重叠区域 20%
│Tile4│Tile5│Tile6│
└─────┴─────┴─────┘
    ↓ 每个 tile 独立推理
┌─────┐ ┌─────┐ ┌─────┐
│Det1 │ │Det2 │ │Det3 │ ... (N 个 tile)
└─────┘ └─────┘ └─────┘
    ↓ NMS 合并（跨 tile 去重）
最终检测结果
```

**切片策略**：

设原始图像尺寸为 $H \times W$，切片尺寸为 $S$，重叠率为 $r$，则：
- 切片步长：$stride = S \times (1 - r)$
- 水平切片数：$n_w = \lceil (W - S \times r) / stride \rceil + 1$
- 垂直切片数：$n_h = \lceil (H - S \times r) / stride \rceil + 1$
- 总切片数：$N = n_w \times n_h$

**小目标放大效果**：

设原始图像中目标宽度为 $w$，切片尺寸为 $S$，原始图像宽度为 $W$，则：
- 在原始图中，目标相对宽度：$w / W$
- 在切片中，目标相对宽度：$w / S$
- 放大倍数：$W / S$

例如：$W=1920, S=640$，放大倍数 = 3x。一个 10px 的目标在切片中变为 30px。

**NMS 合并**：

跨切片的检测结果需要通过 NMS 去重。设两个检测框 $b_i$ 和 $b_j$ 的 IoU 超过阈值 $\tau$，则保留置信度较高的那个：

$$
\text{NMS}(b_i, b_j) = \begin{cases}
b_i & \text{if } \text{conf}(b_i) > \text{conf}(b_j) \text{ and } IoU(b_i, b_j) > \tau \\
b_j & \text{otherwise}
\end{cases}
$$

### 4.3 本实验设置

| 配置项 | 设置 |
|--------|------|
| 切片尺寸 | 640×640 |
| 重叠率 | 0.2 |
| 置信度阈值 | 0.25 |
| NMS 阈值 | 0.5 |
| 基模型 | Baseline best.pt / Focaler-IoU best.pt |
| 测试集 | TT100K 验证集（1460 张） |

**与论文的差异**：
- 论文在 COCO 上评估 AP，本实验在 TT100K 上统计检测数量
- 论文测试多种切片尺寸（320/480/640），本实验固定 640
- 论文使用标准 YOLOv5，本实验使用 YOLO11n + Focaler-IoU

### 4.4 实验结果

| 指标 | Baseline + SAHI | Focaler-IoU + SAHI |
|------|-----------------|---------------------|
| 总检测数 | 2,397 | 5,526 |
| 平均检测/图 | 1.64 | 3.79 |
| 平均推理时间 | 0.421s | 0.432s |
| 检测倍数 | 1.0x | **2.3x** |

**逐类别检测数对比**：

| 类别 | Baseline + SAHI | Focaler-IoU + SAHI | 增幅 |

### 4.5 结果分析

**核心发现**：Focaler-IoU + SAHI 的检测数是 Baseline + SAHI 的 2.3 倍，推理时间几乎相同。

**原因分析**：

1. **Focaler-IoU 的定位精度优势被放大**：SAHI 切片后每个子图分辨率更高，小目标被放大到模型的有效检测范围。Focaler-IoU 改善的定位精度在高分辨率子图上更加显著。

2. **限速类标志增幅最大**：pl30-pl100 等限速标志增幅达 1000-2500%，说明这些小目标标志在原始分辨率下被严重漏检，SAHI 切片后检出率大幅提升。

3. **推理时间基本不变**：SAHI 的推理时间主要取决于切片数量和模型推理速度，与基模型无关。因此 Baseline 和 Focaler-IoU 的 SAHI 推理时间几乎相同。

### 4.6 结论

SAHI 是一种**高性价比的推理优化方法**：
- 不需要修改模型或重新训练
- 检测数提升 2.3 倍（配合 Focaler-IoU）
- 推理时间仅增加约 0.4s/图
- 对小目标交通标志的检出率提升尤为显著

## 五、综合对比与总结

### 5.1 整体性能对比

| 方法 | 类型 | Precision | Recall | mAP50 | mAP50-95 | 推理时间 |
|------|------|-----------|--------|-------|----------|----------|
| **Baseline** | — | 0.7963 | 0.6732 | **0.7580** | 0.5313 | ~0.05s |
| + CBAM | 架构 | 0.4681 | 0.6042 | 0.5295 | 0.3785 | ~0.05s |
| + P2+CBAM | 架构 | 0.4830 | 0.6444 | 0.5908 | 0.4303 | ~0.06s |
| **+ Focaler-IoU** | **损失** | 0.6979 | 0.6594 | 0.7187 | **0.5343** | ~0.05s |
| + Gold-YOLO GD | 架构 | 0.3641 | 0.5258 | 0.3927 | 0.2709 | ~0.08s |
| + SAHI | 推理 | — | — | — | — | ~0.43s |

### 5.2 关键结论

1. **损失函数改进最有效**：Focaler-IoU 在不增加模型复杂度的前提下，通过改进损失函数提升了 mAP50-95（+0.6%），是所有改进方法中唯一在某项指标上超过基线的。

2. **架构改进需要更多数据**：CBAM、P2+CBAM、Gold-YOLO GD 等架构改进均未超过基线，主要原因是从零训练新模块、预训练权重不匹配、数据量不足。架构改进需要更大数据集或分阶段训练策略。

3. **SAHI 是高性价比的推理优化**：不修改模型，检测数提升 2.3 倍，推理时间仅增加 0.4s。配合 Focaler-IoU 效果更佳。

4. **训练策略比架构改进更重要**：输入尺度提升（640→704）和更充分训练（20→50 轮）带来的收益（+28.7%）远超架构改进，说明在小数据集上优化训练过程比修改模型结构更有效。

### 5.3 后续改进方向

| 方向 | 具体措施 | 预期效果 |
|------|----------|----------|
| 分阶段训练 | 先冻结 Backbone 训练新模块，再全网络微调 | 解决新模块收敛问题 |
| 更强数据增强 | Copy-Paste、Mosaic、MixUp 组合 | 增加小目标样本多样性 |
| 类别重采样 | 对低召回类别（pl80、no_parking）增加采样权重 | 缓解类别不均衡 |
| 更长训练周期 | 100-200 轮 | 充分收敛 |
| SAHI + Focaler-IoU 组合 | 将 Focaler-IoU best.pt 配合 SAHI 部署 | 最佳检测效果 |

### 5.4 最终推荐方案

**推荐组合**：Focaler-IoU（训练阶段）+ SAHI（推理阶段）

- 训练阶段：使用 Focaler-IoU 损失函数，提升定位精度（mAP50-95 +0.6%）
- 推理阶段：使用 SAHI 切片推理，提升小目标检出率（检测数 +130%）
- 总推理时间：~0.43s/图，满足实时性要求
- 无需修改模型架构，实现成本最低
