## 本层内容介绍

这里是“智能+交通”课程下的“results”目录，主要用于整理实验或程序产生的结果文件。

**阅读建议：**先了解生成这些结果的输入、参数与评价方法，再阅读图表和记录。

### 本层有哪些内容

本目录及子目录共收录 **53 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **模型与序列化文件（21 份）**：[baseline_METRLA_checkpoint.pth](baseline_METRLA_checkpoint.pth)、[baseline_PEMS03_checkpoint.pth](baseline_PEMS03_checkpoint.pth)等；完整列表见本页导航。
- **配置及其他配套文件（20 份）**：[baseline_METRLA_results.json](baseline_METRLA_results.json)、[baseline_PEMS03_results.json](baseline_PEMS03_results.json)等；完整列表见本页导航。
- **代码与脚本（2 份）**：[export_paper_xlsx.py](export_paper_xlsx.py)、[generate_figures.py](generate_figures.py)。
- **图片与图形（8 份）**：[fig1_model_comparison.png](fig1_model_comparison.png)、[fig2_heatmap.png](fig2_heatmap.png)等；完整列表见本页导航。
- **表格与数据（1 份）**：[paper_tables.xlsx](paper_tables.xlsx)。
- **文档与说明（1 份）**：[summary_table.txt](summary_table.txt)。
