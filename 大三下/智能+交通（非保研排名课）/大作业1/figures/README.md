## 本层内容介绍

这里是“智能+交通”课程下的“figures”目录，主要用于整理图像、插图或配套素材。

**阅读建议：**先在对应报告、课件或页面中查看这些素材的上下文，需要查图或复现时再打开原文件。

### 本层有哪些内容

本目录及子目录共收录 **54 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

| 子目录 | 内容与用途 |
| --- | --- |
| [beamer-theme-collection-master](beamer-theme-collection-master/README.md) | 随项目保留的第三方工具或模板资料 |

- **排版源文件（6 份）**：[_input-tex-settings.tex](_input-tex-settings.tex)、[presentation.tex](presentation.tex)等；完整列表见本页导航。
- **配置及其他配套文件（4 份）**：[presentation.nav](presentation.nav)、[presentation.snm](presentation.snm)等；完整列表见本页导航。
- **文档与说明（5 份）**：[presentation.pdf](presentation.pdf)、[staeformer_architecture.pdf](staeformer_architecture.pdf)等；完整列表见本页导航。
