## 本层内容介绍

这里是“智能+交通”课程下的“_input-tex”目录，主要用于整理报告文档或报告排版源文件。

**阅读建议：**阅读时优先打开成稿 PDF 或正文；需要研究排版与生成过程时再看源文件和素材。

### 本层有哪些内容

本目录及子目录共收录 **8 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。
