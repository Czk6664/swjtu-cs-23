## 本层内容介绍

这里是“智能+交通”课程下的“data”目录，主要用于整理项目使用的数据或样例输入。

**阅读建议：**先查上级说明中的数据来源、字段和处理方式，再查看具体文件；此处不一定包含完整数据集。

### 本层有哪些内容

本目录及子目录共收录 **16 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **配置及其他配套文件（16 份）**：[ffwd.net.0.bias](ffwd.net.0.bias)、[ffwd.net.0.weight](ffwd.net.0.weight)等；完整列表见本页导航。
