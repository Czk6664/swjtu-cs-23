## ADDED Requirements

### Requirement: 后端暴露统一业务 API
系统必须通过统一服务边界提供交通分析、结果查询、任务创建和任务状态查询接口。

#### Scenario: 前端请求交通分析
- **WHEN** 前端调用交通分析接口
- **THEN** 后端校验输入、调度对应流程，并返回结构化响应或任务标识

### Requirement: 后端管理异步任务生命周期
系统必须支持长耗时异步任务，例如报表生成、音频生成和每日总结。

#### Scenario: 用户触发长耗时任务
- **WHEN** 前端请求生成报表或语音播报
- **THEN** 后端创建一个可追踪任务，并将其状态暴露为排队中、运行中、成功或失败

### Requirement: 后端返回结构化输出
系统必须将预测、识别和决策结果统一整理为结构化 Schema，供前端和 Agent 工作流使用。

#### Scenario: 模型编排返回结果
- **WHEN** 编排层完成一次分析流程
- **THEN** 后端存储或返回包含模型输出、摘要和建议动作的结构化载荷
