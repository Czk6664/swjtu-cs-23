## ADDED Requirements

### Requirement: Hermes 能在工作区内生成结构化交通报表
系统必须支持一个基于 Hermes 的报表工作流，利用当前工作区内初始化的任务资源，根据分析结果或任务载荷生成结构化报表产物。

#### Scenario: 报表工作流收到分析结果
- **WHEN** 一个报表任务包含结果标识和场景上下文
- **THEN** Hermes 基于工作区内准备好的资源生成包含场景摘要、决策重点和关键指标的结构化输出

#### Scenario: 报表工作流完成
- **WHEN** 报表工作流成功执行
- **THEN** 系统把报表产物写入报表输出目录，并在任务结果中引用该文件

### Requirement: Hermes 能在工作区内生成播报稿
系统必须支持一个基于 Hermes 的语音工作流，利用工作区内初始化资源生成适合播报或后续 TTS 的交通播报稿。

#### Scenario: 语音工作流收到风险摘要
- **WHEN** 一个语音任务包含场景上下文和决策内容
- **THEN** Hermes 生成一段简洁、可直接播报的交通播报稿，体现当前风险等级和建议动作

#### Scenario: 语音工作流完成
- **WHEN** 语音工作流成功执行
- **THEN** 系统将生成的播报稿保存到音频或语音输出目录，并在任务结果中引用该文件

### Requirement: Hermes 能在工作区内生成每日运营总结
系统必须支持一个基于 Hermes 的每日总结工作流，利用工作区内初始化资源把近期分析结果和任务结果汇总成运营摘要。

#### Scenario: 手动触发每日总结
- **WHEN** 创建一个带有日期或上下文信息的 `daily-summary` 任务
- **THEN** Hermes 生成包含当日分析记录、重点风险和产物摘要的总结内容

#### Scenario: 每日总结工作流完成
- **WHEN** 每日总结工作流成功执行
- **THEN** 系统保存总结文件，并在任务结果中暴露其路径
