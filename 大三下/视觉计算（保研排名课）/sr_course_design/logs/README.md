## 本层内容介绍

这里是“视觉计算”课程下的“logs”目录，主要用于整理运行日志或过程记录。

**阅读建议：**按时间和运行批次定位记录，结合对应的配置、代码与结果分析问题。

### 本层有哪些内容

本目录及子目录共收录 **24 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **表格与数据（24 份）**：[ca_imdn_x2_edge_w001_20ep_metrics.csv](ca_imdn_x2_edge_w001_20ep_metrics.csv)、[ca_imdn_x2_no_edge_20ep_cosine_lr_metrics.csv](ca_imdn_x2_no_edge_20ep_cosine_lr_metrics.csv)等；完整列表见本页导航。
