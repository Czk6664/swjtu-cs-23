## 本层内容介绍

这里是“视觉计算”课程下的“checkpoints”目录，主要用于整理模型权重或训练检查点。

**阅读建议：**先阅读对应模型和实验说明，核对框架、结构及输入处理；这些文件需要配套代码加载。

### 本层有哪些内容

本目录及子目录共收录 **11 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **模型与序列化文件（11 份）**：[ca_imdn_smoke_x2.ckpt](ca_imdn_smoke_x2.ckpt)、[idb_imdn_smoke_x2.ckpt](idb_imdn_smoke_x2.ckpt)等；完整列表见本页导航。
