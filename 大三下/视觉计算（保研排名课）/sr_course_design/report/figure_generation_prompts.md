# 论文插图生成 Prompts

本文档整理了适合当前超分辨率课程设计报告使用的插图生成提示词。每条 prompt 已经内置统一风格要求，可以直接复制到图像生成工具中使用。

建议优先生成并加入报告的插图：

1. 本文整体实验流程图
2. IMDN 网络结构示意图
3. 边缘损失消融实验设计图
4. 训练-推理-评估闭环图

不建议用 AI 生成带精确数值的指标柱状图或真实视觉对比图。那两类图应优先使用真实实验结果绘制，避免数字或细节不准确。

## 1. 单图像超分辨率任务示意图

```text
请生成一张适合中文课程设计论文的学术插图。整体风格要求：白色或极浅灰背景，扁平矢量图，干净、克制、专业，适合插入 LaTeX 报告。使用统一配色：深青色 #2C7A7B 表示 IMDN 或主模型，暖橙色 #C97B63 表示 Bicubic 或传统方法，中性灰 #6C7A89 表示 SRCNN 或辅助模块，浅绿色 #4B8F29 表示 no-edge 消融模型，浅蓝色 #DCEFF5 表示数据或输入输出图像块。所有文字使用清晰中文标签，字体类似思源黑体或微软雅黑，避免艺术字。线条使用 1.5 到 2 px，箭头统一为实线箭头。图中不要出现水印、logo、英文大段文字、复杂纹理、照片级背景、3D 透视和夸张阴影。画面留白充足，节点对齐整齐，适合论文打印。输出比例 16:9，分辨率至少 3000×1688。即使转换为灰度，也要能通过形状、线型和标签区分不同模块。

生成“单图像超分辨率任务示意图”。画面从左到右排列四个主要部分。

左侧是低分辨率输入图像块，显示为较小、像素颗粒明显、边缘模糊的抽象图像，标签为“低分辨率输入 LR”。图像块下方标注“尺寸较小，细节缺失”。

中间是一个主模型处理模块，用深青色边框矩形表示，标签为“超分辨率重建模型”。矩形内部可以有简化神经网络图标，如卷积层小方块、特征通道线条和上采样箭头。LR 到模型之间用箭头连接，箭头上标注“输入”。

右侧是模型输出图像块，尺寸约为 LR 的 2 倍，边缘更清晰，标签为“超分辨率输出 SR”。从模型到 SR 的箭头上标注“×2 放大 + 细节恢复”。

最右上角放一个参考图像块，标签为“真实高分辨率 HR”，与 SR 用虚线连接，虚线旁标注“用于训练与评价”。SR 与 HR 下方放两个小指标标签：“PSNR”和“SSIM”。

整体表达：从 LR 恢复 SR，并与 HR 比较。不要放真实照片，用简洁抽象图像块即可。布局清晰，适合放在引言或任务定义部分。
```
