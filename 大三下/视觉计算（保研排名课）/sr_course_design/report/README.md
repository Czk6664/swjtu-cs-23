## 本层内容介绍

这里是“视觉计算”课程下的“report”目录，主要用于整理报告文档或报告排版源文件。

**阅读建议：**阅读时优先打开成稿 PDF 或正文；需要研究排版与生成过程时再看源文件和素材。
