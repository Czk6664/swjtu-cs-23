## 本层内容介绍

这里是“视觉计算”课程下的“tools”目录，主要用于整理处理数据、生成材料或辅助运行的脚本工具。

**阅读建议：**先阅读脚本的参数、输入与输出说明，再按项目步骤使用；这些文件通常不是课程阅读的起点。

### 本层有哪些内容

本目录及子目录共收录 **17 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **代码与脚本（17 份）**：[analyze_frequency.py](analyze_frequency.py)、[count_parameters.py](count_parameters.py)等；完整列表见本页导航。
