## 本层内容介绍

这里是“视觉计算”课程下的“教学课件”目录，主要用于整理课堂讲授、章节讲义或复习课件。

**阅读建议：**按课堂章节顺序阅读，记录核心概念与例题；复习时回到不熟悉的章节查漏补缺。

### 本层有哪些内容

本目录及子目录共收录 **1 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（1 份）**：[1课程概要.pdf](1%E8%AF%BE%E7%A8%8B%E6%A6%82%E8%A6%81.pdf)。
