**⑤ 学术背景可靠，AIM 2019双赛道冠军**  
IMDN发表于ACM MM 2019，在AIM 2019挑战赛受限资源赛道与速度赛道同时获得冠军，是轻量超分领域的重要参考工作。

## Slide 10：模型结构与机制——组合损失函数设计

**版式**：标题和内容版式

**Prompt**：

设计一张学术PPT内容页，标题"模型结构与机制"，副标题"组合损失函数设计"。

**页面左侧（约55%宽）：损失函数说明区**

用大号公式展示组合损失（公式用白底蓝色方框或浅蓝色卡片高亮）：

$$L = L_1(\hat{I}, I) + \lambda_e L_{edge}(\hat{I}, I) + \lambda_l L_{lap}(\hat{I}, I)$$

下方分三行解释每项（14pt，左对齐）：

- **L₁ 像素重建损失**：约束输出图像与HR真值的逐像素L1误差，是主损失项，保证全局像素保真度
- **L_edge 边缘损失**（λe可配置，默认0.05，消融中使用0.01/0.02）：对图像水平和垂直方向做有限差分，约束预测图像与HR在梯度图上的差异，鼓励网络在边界区域保留更清晰的变化趋势
- **L_lap 二阶拉普拉斯结构损失**（λl = 0.01，探索性）：使用四邻域离散拉普拉斯算子（ΔI_{i,j} = I_{i−1,j} + I_{i+1,j} + I_{i,j−1} + I_{i,j+1} − 4I_{i,j}）提取二阶结构响应，约束局部曲率和高频震荡，作为一阶边缘损失的补充探索

**页面右侧（约45%宽）：示意图区**

放置一张损失函数结构示意图（流程图风格）：
```
预测图像 ↘             ↗ L1损失
            比较框
HR真值   ↗             ↘ 梯度图差异（Edge Loss）
                         ↘ 拉普拉斯响应差异（Lap Loss）
                              ↓
                         加权求和 → 总损失 L
```

底部注意事项（12pt，斜体，深灰）：
"注：边缘损失和拉普拉斯损失均为探索性结构约束，本文实验结果显示当前权重下未稳定提升PSNR，报告为负结果消融。"

CA-IMDN新增的通道注意力机制（用流程图展示）：
```
融合特征 → 全局平均池化（GAP）→ 1×1卷积（降维r=4）→ ReLU → 1×1卷积（升维）→ Sigmoid → 通道权重
                                                                                           ↓
                                                                            原融合特征 × 权重 = 重标定特征
```

**右侧（60%）：设计动机与参数量对比**

设计动机（14pt，三个要点）：
- 通道注意力受HAT等Transformer工作启发，将注意力思想引入轻量卷积网络
- 让网络在重建时自动提高纹理、边缘和结构相关通道的权重，减少低效通道对融合特征的干扰
- 仅增加约 **2,048个参数**（0.173M vs 0.171M），参数开销极小

**参数量对比小表格**（12pt，交大蓝表头）：

| 模型 | 参数量 | 20ep PSNR |
|------|-------|---------|
| IMDN width32 depth4（主模型） | 0.171M | 33.46 dB |
| CA-IMDN width32 depth4 | 0.173M（+2048） | 33.48 dB |
| CA-IMDN + Edge Loss（λe=0.01） | 0.173M | 33.64 dB |
| CA-IMDN 50 epoch | 0.173M | 33.03 dB（↓早停问题） |

## Slide 21：结论与展望

**版式**：标题和内容版式

**Prompt**：

设计一张学术PPT内容页，标题"结论与展望"，副标题"主要发现与后续改进方向"。

**主体：左右两部分布局**

**左侧（55%）：主要结论**（五条，每条带交大蓝序号标）

**结论一（充分训练的关键性）**  
短训（5ep）IMDN暂不超过Bicubic（31.95 dB），长训后性能跃升：**IMDN 50ep达34.21 dB，较Bicubic +1.74 dB，在100/100张验证图均超越Bicubic**，证明训练预算是轻量模型的关键瓶颈

**结论二（浅层基线重新评价）**  
SRCNN 20ep达33.29 dB，超越Bicubic；早期2ep的SRCNN低于Bicubic并非结构问题，而是训练不足导致——学习型超分结构本身具有有效性

**结论三（模型容量：宽度优于深度）**  
在本文课程级实现中，增加通道宽度（width48: 33.66 dB）比增加深度（depth6: 33.19 dB）更有效；参数效率上width16也有33.41 dB，可作为极轻量选择

**结论四（结构损失：谨慎结论）**  
边缘损失（λe=0.01）20ep时PSNR（33.06 dB）低于no-edge同轮（33.46 dB），但SSIM略高；二阶拉普拉斯损失同样未稳定提升PSNR——**结构损失提升结构一致性但当前权重下牺牲PSNR，尚需系统调参**

**结论五（感知与像素指标的权衡）**  
IMDN 50ep LPIPS（0.1197）明显优于Bicubic（0.1830），但NIQE略差（4.92 vs 4.75），印证超分中像素保真与感知自然度的常见矛盾；多维评价（PSNR/SSIM/LPIPS/NIQE）更全面

**右侧（45%）：后续改进方向**（竖向时间轴或bullet列表，蓝色图标）

- 🔵 **模型改进**：引入多尺度特征融合或频域损失，形成比简单Edge Loss更有辨识度的改进模块
- 🔵 **训练策略**：CA-IMDN配合余弦学习率衰减与更精细早停，解决50ep PSNR退化问题
- 🔵 **扩大数据覆盖**：每张训练图增加随机patch数量，提升纹理/边缘区域覆盖度
- 🔵 **完整复现**：实现更接近原始IMDN的IDB split-and-fuse结构（IDB-IMDN-Lite），缩小与论文级结果的差距（当前Set5差距约2 dB）
- 🔵 **主观评价**：补充LPIPS/NIQE之外的人工视觉主观对比，形成感知质量完整评价
