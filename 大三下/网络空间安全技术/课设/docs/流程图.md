## 图 1　系统总体流程图

对应文件：`app.py`（路由分发）

```mermaid
flowchart TD
    A([用户访问系统]) --> B{已登录?<br/>session 中有 username}
    B -- 是 --> C[进入个人中心 /dashboard]
    B -- 否 --> D{选择操作}
    D -- 注册 --> E[/register: 输入用户名口令/]
    E --> E1{输入校验+口令强度<br/>security.validate_*}
    E1 -- 不合格 --> E2[提示错误, 返回注册页]
    E1 -- 合格 --> E3[口令哈希存储<br/>security.hash_password]
    E3 --> F[/login 登录页/]
    D -- 登录 --> F
    F --> G[登录认证流程<br/>见图2]
    G -- 成功 --> C
    G -- 失败 --> F
    C --> H[/audit 安全审计/]
    H --> I[运行全量审计<br/>audit.run_full_audit, 见图4]
    I --> J([输出审计结果])
```

## 图 2　用户登录认证流程图（核心）

对应函数：`security.authenticate()`

```mermaid
flowchart TD
    A([输入用户名 + 口令]) --> B[查询用户<br/>db.get_user]
    B --> C{账号是否锁定?<br/>security.is_locked}
    C -- 是 --> C1[记录 locked 日志] --> C2([拒绝: 账号已锁定])
    C -- 否 --> D{用户是否存在?}
    D -- 不存在 --> D1[记录 user_not_found 日志] --> D2([统一提示: 用户名或口令错误])
    D -- 存在 --> E{口令校验是否通过?<br/>verify_password 恒定时间比较}
    E -- 否 --> F[记录 wrong_password 日志] --> G[进入登录失败限制流程<br/>见图3]
    E -- 是 --> H[记录 ok 成功日志]
    H --> I[清零失败计数+解除锁定<br/>db.reset_user_security]
    I --> J[实时异常检测<br/>audit.detect_realtime]
    J --> K{是否命中异地/非工时/高频?}
    K -- 是 --> K1[弹出异常登录提醒]
    K -- 否 --> L
    K1 --> L([登录成功, 写入 session])
```

## 图 3　登录失败限制流程图

对应代码：`security.authenticate()` 中口令错误分支 + `count_recent_failures()`

```mermaid
flowchart TD
    A([口令校验失败]) --> B[写入失败日志]
    B --> C[统计窗口内失败次数<br/>count_recent_failures<br/>窗口=5分钟]
    C --> D[更新 users.failed_count]
    D --> E{失败次数 >= 阈值?<br/>MAX_FAILED_ATTEMPTS=5}
    E -- 否 --> E1([提示: 还可尝试 N 次])
    E -- 是 --> F[计算锁定截止时间<br/>now + 10 分钟]
    F --> G[写入 users.locked_until<br/>db.set_lock]
    G --> H[生成暴力尝试告警<br/>db.add_alert brute_force]
    H --> I([提示: 账号已锁定 10 分钟])
```

## 图 4　异常登录审计流程图

对应函数：`audit.run_full_audit()`

```mermaid
flowchart TD
    A([开始审计]) --> B[清空旧告警<br/>db.clear_alerts]
    B --> C[按时间顺序读取全部日志<br/>db.get_all_logs]
    C --> D{遍历每条日志}
    D --> E{失败日志?}
    E -- 是 --> E1{5分钟内失败>=5?}
    E1 -- 是 --> E2[记暴力尝试告警]
    D --> F{成功登录?}
    F -- 是 --> F1{是非工作时段?<br/>23:00-06:00}
    F1 -- 是 --> F2[记非工作时间告警]
    F -- 是 --> G{10分钟内 IP 数>=2?}
    G -- 是 --> G1[记异地登录告警]
    D --> H{60秒内请求>=10?}
    H -- 是 --> H1[记高频登录告警]
    E2 --> I
    F2 --> I
    G1 --> I
    H1 --> I
    D -- 遍历完成 --> I[汇总各类告警计数]
    I --> J([输出审计报告:<br/>日志数/成功/失败/告警明细])
```

## 图 5　测试与处置流程图

对应文件：`run_tests.py` + 异常处置策略

```mermaid
flowchart TD
    A([运行 run_tests.py]) --> B[每个用例重建数据库<br/>fresh_db 保证隔离]
    B --> C[执行 TC1~TC8 断言]
    C --> D{断言全部通过?}
    D -- 否 --> D1[定位失败用例<br/>检查规则/阈值/实现] --> B
    D -- 是 --> E[进入异常处置]
    E --> F{告警类型?}
    F -- 暴力尝试 --> F1[账号临时锁定 10 分钟]
    F -- 异地登录 --> F2[标记可疑, 提示二次验证]
    F -- 非工作时间 --> F3[记录并提醒, 人工复核]
    F -- 高频登录 --> F4[限流/拉黑来源 IP]
    F1 --> G
    F2 --> G
    F3 --> G
    F4 --> G([输出处置结论 + 审计报告])
```
