# 网络空间安全技术 · 学习系统 — Cloudflare 部署说明

本目录是一个**纯静态网站**（只有 HTML/CSS/JS，无需构建），部署方式与 `swjtu_game` 完全一致，使用 **Cloudflare Pages**。

## 🌐 部署后访问地址

```
https://netsec-study.pages.dev
```

（项目名 `netsec-study` 可在 `wrangler.toml` 和 `deploy.bat` 里修改）

---

## 🚀 部署步骤（首次）

### 方法 1：一键脚本（推荐）

在本目录（`课件\讲解`）打开终端，运行：

```
deploy.bat
```

脚本会自动：① 检查登录 → 未登录则弹出浏览器登录 → ② 上传 → ③ 显示访问网址。

> 在 Claude Code 里，你也可以直接在输入框输入：`! deploy.bat`（用 `!` 前缀在当前会话执行）。

### 方法 2：手动命令

```bash
# 1. 登录（会打开浏览器授权，首次或 token 过期时需要）
wrangler login

# 2. 部署（在 课件\讲解 目录下执行）
wrangler pages deploy . --project-name=netsec-study
```

### 方法 3：网页拖拽上传（不想用命令行时）

1. 访问 https://dash.cloudflare.com/
2. Workers & Pages → Create application → Pages → Upload assets
3. 把 `课件\讲解` 文件夹里的所有 `.html` 文件拖进去上传

---

## 🔄 更新流程

改完内容后，重新运行 `deploy.bat`（或方法 2 的第 2 条命令），等约 30 秒，浏览器 Ctrl+F5 刷新即可。

## ⚙️ 配置文件说明

| 文件 | 作用 |
|------|------|
| `wrangler.toml` | Cloudflare 配置（项目名、输出目录=当前目录）|
| `.assetsignore` | 排除非网站文件（*.md / *.bat / *.toml 等）|
| `deploy.bat` | 一键部署脚本（含自动登录检测）|
| `.gitignore` | Git 忽略规则 |

## 🔧 常见问题

**Q: 运行后报 `invalid_grant` / 未登录？**
A: token 过期了，运行 `wrangler login` 重新授权（会开浏览器）。

**Q: 中文文件名的网址能打开吗？**
A: 可以，Cloudflare Pages 支持 UTF-8 文件名（URL 会自动百分号编码）。若个别浏览器异常，可把 9 个 HTML 改成英文名并同步改各页顶部"章节切换栏"里的链接。

**Q: 网站打不开 / SSL 报错？**
A: 首次部署后等 3-5 分钟，SSL 证书正在签发。

**Q: 想换项目名/网址？**
A: 改 `wrangler.toml` 的 `name` 和 `deploy.bat` 的 `project_name` 为同一个新名字即可。
