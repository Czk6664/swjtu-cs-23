## 三、七个实验详解

### 实验一：基础数字签名（`basic_signature.py`）

**流程：**
```
Alice 私钥 SK_A
    ↓ sign_basic(SK_A, M1)
签名 Sig
    ↓ verify_basic(PK_A, M1, Sig)
验签结果 True/False
```

**三种验证场景：**

| 场景 | 公钥 | 消息 | 期望结果 |
|------|------|------|----------|
| A1 正常流程 | PK_A（正确） | M1（原始） | ✅ 通过 |
| A2 消息被篡改 | PK_A | M1'（篡改） | ❌ 失败 |
| A3 公钥不匹配 | PK_B（错误） | M1 | ❌ 失败 |

> **结论**：RSA-PSS 签名与消息内容及密钥严格绑定，任意改动均导致验签失败。

### 实验二：摘要后签名（`digest_signature.py`）

**核心思想**：先对消息计算 SHA256 摘要，再对摘要签名（Prehashed 模式）。

```
M1 → SHA256 → H(M1) → RSA-PSS.sign(SK_A, H(M1)) → Sig
```

**完整性检测演示：**

```
Hash(M1)  = sha256("...学号=20260001")
Hash(M1') = sha256("...学号=20260002")
```

两者完全不同，哈希的**雪崩效应**保证即使一字节改变，摘要也面目全非。

| 对比项 | 结果 |
|--------|------|
| B1 原始消息验签 | ✅ 通过 |
| B2 篡改消息验签 | ❌ 失败 |
| B3 摘要是否不同 | ✅ 是（证明完整性保护生效） |

### 实验五：先签名后加密（`secure_signature.py`）

**方案**：`Sign → Encrypt`

```
明文 M1
  ↓ 签名（SK_A）→ 内部包 {明文 + 元数据 + 签名}
  ↓ AES-256-GCM 加密（会话密钥 K）
  ↓ RSA-OAEP 加密 K（用 PK_B）
→ 外部包 {encrypted_key, nonce, ciphertext, tag}
```

**解包流程（Bob 端）：**
```
RSA 解密 encrypted_key → K
AES-GCM 解密 ciphertext → 内部包
重建 signed_data → RSA-PSS 验签
```

**优点**：签名受加密保护，外部无法直接看到签名和明文。  
**局限**：先解密才能验签，Bob 必须先完成解密。

| E2 GCM Tag 篡改 | ❌ | — |
| E3 内部签名篡改 | ✅ | ❌ |
| E4 错误私钥解密 | ❌ | — |

### 实验六：先加密后签名（`secure_signature.py`）

**方案**：`Encrypt → Sign`

```
明文 M1
  ↓ AES-256-GCM 加密 → {encrypted_key, nonce, ciphertext, tag, metadata}
  ↓ 对上述字段整体签名（SK_A）
→ 外部包 {密文包 + signature_b64}
```

**解包流程（Bob 端）：**
```
RSA-PSS 验签（外层签名）
→ 验签通过后解密 → 明文
```

**优点**：可在不解密的前提下直接验证消息来源（签名在密文外层）。  
**局限**：签名不保护明文内容，理论上存在"签名挪用"风险。

## 五、密码学知识总结

### 两种组合方案对比

| | 先签名后加密 (STE) | 先加密后签名 (ETS) |
|--|--|--|
| 签名保护范围 | 明文（更强） | 密文 |
| 验签时机 | 解密后 | 解密前 |
| 防重放能力 | 需元数据辅助 | 需元数据辅助 |
| 签名挪用风险 | 无 | 理论存在 |
| 典型应用 | S/MIME | PGP |

### AES-GCM 的 AEAD 特性

AES-GCM（Galois/Counter Mode）是一种**认证加密**方案：
- **加密**：保证机密性
- **Tag（认证标签）**：保证密文完整性，任何篡改都会导致 `InvalidTag` 异常
- 无需额外 MAC，一步同时提供加密和完整性保护

### RSA-PSS vs RSA-PKCS1v15

| | RSA-PSS | RSA-PKCS1v15 |
|--|--|--|
| 安全性 | 更高（随机盐） | 较低（确定性） |
| 标准 | PKCS#1 v2.1 | PKCS#1 v1.5 |
| 推荐 | ✅ 现代标准 | ⚠️ 兼容旧系统 |
