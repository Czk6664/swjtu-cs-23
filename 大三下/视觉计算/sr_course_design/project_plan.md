# 课程设计题目与总体方案

## 推荐题目
《基于生成模型的图像超分辨率方法研究与轻量化改进设计》

## 研究目标
本课程设计围绕单图像超分辨率任务展开，重点研究近年来生成模型在图像超分辨率中的应用思路，并结合轻量化重建模型完成复现实验与改进设计。论文综述部分重点分析近五年代表性方法，包括生成对抗网络、扩散模型和轻量高效重建网络三类路线；实验部分以可复现、低风险为原则，基于 MindSpore 实现轻量超分模型，并在公开数据集上进行定量和定性分析。

## 研究内容
1. 梳理单图像超分辨率任务背景、应用场景与评价指标。
2. 阅读近五年 3 篇以上代表性论文，分析各类方法的模型结构、损失函数与性能特点。
3. 选择轻量模型作为主复现对象，完成 MindSpore 代码实现。
4. 设计一个轻量改进模块，例如边缘损失、感知损失或轻量注意力模块。
5. 对比基线模型与改进模型的实验结果，分析不同方法在 PSNR、SSIM 和视觉效果上的差异。

## 技术路线
- 文献综述层：生成式超分方法发展脉络分析
- 基线实现层：SRCNN / IMDN 的 MindSpore 实现
- 改进设计层：边缘约束或轻量注意力模块
- 评估层：PSNR、SSIM、定性图像对比

## 实验策略
由于笔记本长时间满载存在稳定性风险，实验采取分阶段策略：
- 第一阶段：完成文献、报告、代码骨架和最小前向验证
- 第二阶段：小规模样本验证训练流程
- 第三阶段：根据机器稳定性决定是否补充正式训练结果
