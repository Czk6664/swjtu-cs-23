# PPT 逐页配图生成 Prompts

基于 `视觉计算PPT.pptx` 模板，为全部 17 页幻灯片各写一条图片生成 prompt。生成的图片用于插入对应页面，与 PPT 风格统一。

## PPT 实际配色（从模板提取）

| 角色 | 色值 | 说明 |
|------|------|------|
| 主色青 | #009999 / #008C8C / #006699 | IMDN、主流程节点、重要模块 |
| 蓝色 | #0070C0 / #0032A1 | 标题文字、箭头、连接线 |
| 金黄 | #FFC000 | 强调标注、关键数值、星标 |
| 暖橙 | #ED7D31 | Bicubic/传统方法、对比色 |
| 银灰 | #7E7E7E / #B4B4B4 | 次要文字、SRCNN、辅助线 |
| 浅蓝底 | #F0F8FA / #BCE0F9 | 卡片底色、数据区域 |
| 红色 | #C85050 | 警示、劣势、下降指标 |
| 背景 | 白色 #FFFFFF | PPT 主背景 |
| 字体 | 微软雅黑 + Arial | 中/英文 |
| 模板装饰 | 浅灰曲线纹理 + 西南交通大学蓝色校徽 | 底纹及 logo |

## 统一风格前缀

每条 prompt 使用时，先粘贴此前缀，再接正文：

```
生成一张可直接插入白底学术PPT的配图。要求：纯白色背景（#FFFFFF），扁平矢量风格，干净专业，适合16:9幻灯片。配色——青色 #009999（主模型/IMDN）、深蓝 #0070C0（标题/箭头）、金黄 #FFC000（强调/高亮）、银灰 #7E7E7E（次要/SRCNN）、浅蓝 #F0F8FA（数据区块底色）、暖橙 #ED7D31（Bicubic/传统方法）、红色 #C85050（劣势/下降）。中文用微软雅黑，英文用 Arial。线条 1.5~2px，箭头实心三角。无水印、无阴影、无3D、无渐变光效、无照片背景。输出 3840×2160，16:9。
```

## 使用指南

1. **使用方法**：每条 prompt 使用时，先粘贴上方「统一风格前缀」代码块内容，再紧接对应 Slide 的 prompt 正文。
2. **推荐工具**：ChatGPT DALL-E 3、Midjourney、通义万象、文心一格。生成后检查中文标签是否正确渲染。
3. **优先生成顺序**：
   - 第一批（核心）：Slide 8（IMDN架构）、Slide 9（损失+注意力）、Slide 11（实验流程）、Slide 12（结果柱状图）
   - 第二批（辅助）：Slide 4（背景对比）、Slide 6（时间线）、Slide 13（消融图表）、Slide 16（结论卡片）
   - 第三批（装饰）：Slide 1（封面）、Slide 2（目录）、Slide 17（感谢）、章节页（3/5/7/10/15）
4. **不建议 AI 生成**：真实训练曲线用 `results/` 下已有图、真实 SR/HR 视觉对比用推理结果截图、精确数值表格在 PPT 中直接用文本框排版更准确。
5. **插入方式**：生成图片为白色背景，直接插入 PPT 后与模板白底融合，无需额外处理。
