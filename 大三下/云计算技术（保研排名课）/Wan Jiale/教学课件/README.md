## 本层内容介绍

这里是“云计算技术”课程下的“教学课件”目录，主要用于整理课堂讲授、章节讲义或复习课件。

**阅读建议：**按课堂章节顺序阅读，记录核心概念与例题；复习时回到不熟悉的章节查漏补缺。

### 本层有哪些内容

本目录及子目录共收录 **2 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（2 份）**：[11讲-大规模图计算.pdf](11%E8%AE%B2-%E5%A4%A7%E8%A7%84%E6%A8%A1%E5%9B%BE%E8%AE%A1%E7%AE%97.pdf)、[12-云原生平台-2026学年.pdf](12-%E4%BA%91%E5%8E%9F%E7%94%9F%E5%B9%B3%E5%8F%B0-2026%E5%AD%A6%E5%B9%B4.pdf)。
