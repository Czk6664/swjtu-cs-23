## 本层内容介绍

这里是“云计算技术”课程下的“知识点回顾期末_期末复习版.pptx.parts”目录，主要用于整理超大文件拆分后的分片及还原材料。

**阅读建议：**分片不能作为独立课件打开，请先阅读本目录原有还原说明，完整下载所需分片后按说明恢复文件。

### 本层有哪些内容

本目录及子目录共收录 **4 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **配置及其他配套文件（3 份）**：[manifest.json](manifest.json)、[part-001](part-001)等；完整列表见本页导航。
- **代码与脚本（1 份）**：[restore.py](restore.py)。
