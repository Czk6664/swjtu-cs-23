## 本层内容介绍

这里是“云计算技术”课程下的“cloud-report-tex”目录，主要用于整理文档排版源文件及配套资源。

**阅读建议：**阅读内容时先找同组的 PDF 成稿；修改排版时需要结合主文档和引用资源。

### 本层有哪些内容

本目录及子目录共收录 **98 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

| 子目录 | 内容与用途 |
| --- | --- |
| [docx-media](docx-media/README.md) | 图像、插图或配套素材 |
| [figures](figures/README.md) | 图像、插图或配套素材 |

- **排版源文件（3 份）**：[main_report.tex](main_report.tex)、[mybib.bib](mybib.bib)等；完整列表见本页导航。
- **文档与说明（3 份）**：[main_report_final.pdf](main_report_final.pdf)、[main_report_updated.pdf](main_report_updated.pdf)等；完整列表见本页导航。
