## 本层内容介绍

这里是“云计算技术”课程下的“docx-media”目录，主要用于整理图像、插图或配套素材。

**阅读建议：**先在对应报告、课件或页面中查看这些素材的上下文，需要查图或复现时再打开原文件。

### 本层有哪些内容

本目录及子目录共收录 **41 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **图片与图形（40 份）**：[contact-sheet.jpg](contact-sheet.jpg)、[docximg-02.png](docximg-02.png)等；完整列表见本页导航。
- **配置及其他配套文件（1 份）**：[docximg-01](docximg-01)。
