## 本层内容介绍

这里是“云计算技术”课程下的“templates”目录，主要用于整理页面、配置或文档模板。

**阅读建议：**先看文件后缀和上级说明，确定模板用途；HTML 通常供程序渲染，文档模板用于排版。

### 本层有哪些内容

本目录及子目录共收录 **34 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（1 份）**：[NOTES.txt](NOTES.txt)。
- **配置及其他配套文件（33 份）**：[_config.tpl](_config.tpl)、[_helpers.tpl](_helpers.tpl)等；完整列表见本页导航。
