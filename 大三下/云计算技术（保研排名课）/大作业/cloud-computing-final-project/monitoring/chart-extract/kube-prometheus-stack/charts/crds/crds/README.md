## 本层内容介绍

这里是“云计算技术”课程下的“crds”目录，主要用于整理部署配置或集群资源定义。

**阅读建议：**先阅读上级部署说明并确认所需环境，再理解各配置的作用；不要把它们当作普通课件打开学习。

### 本层有哪些内容

本目录及子目录共收录 **10 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。
