### 第1次课 云计算概论


大数据：
大数据的定义；
4V+1C 特征（Volume、Velocity、Variety、Value、Complexity）。

云计算的定义与本质：
NIST 定义；
五大本质特征（按需自服务、弹性扩展、资源池化、网络访问、按量计费）；
数据中心选址（电力与制冷成本）。

服务模式：
IaaS / PaaS / SaaS（房屋类比、控制等级、典型产品）；
三种交付模型对比；
新兴模式 FaaS / CaaS。

部署模式：
公有云、社区云、私有云、混合云（优缺点与适用场景）。

云计算核心技术栈：
计算（虚拟化、容器）、存储（分布式存储、对象存储）、网络（SDN、负载均衡）。

### 第2次课 虚拟化技术与Docker

虚拟化基础：
虚拟化的定义与优势。

虚拟化原理：
软件虚拟化 V.S. 硬件虚拟化（VMM 截获翻译 vs VT-x/AMD-v）；
Hypervisor/VMM 的职责；
寄居架构 V.S. 裸机架构；
CPU 虚拟化（指令分级、VT-x 根/非根模式）；
内存虚拟化（影子页表 SPT、扩展页表 EPT）。

Docker 基本原理：
虚拟化的局限性与容器化动机；
容器 V.S. 虚拟机（OS 依赖、启动速度、空间、性能、隔离级别）；
Docker 架构（Client / Daemon / Registry）；
Linux 内核基石：Namespace（进程隔离）与 Cgroup（资源限制）；
镜像与容器的分层结构、联合文件系统（UnionFS）。

### 第3次课 云原生基础与微服务

云原生的概念：
CNCF 定义与四大核心要素（容器化、微服务、声明式 API、不可变基础设施）；
云原生 V.S. 传统开发模式；
不可变基础设施。

微服务架构设计原则：
微服务核心特征（单一职责、独立部署、技术异构、去中心化数据）；
服务拆分策略（DDD 限界上下文、数据边界、变更频率）；
通信方式：同步（REST、gRPC）与异步（消息队列）；
服务发现与注册（客户端发现 vs 服务端发现；etcd / Consul / ZooKeeper / Nacos）；
负载均衡（策略与 L4/L7 层次）；
容错设计：熔断器（三态：Closed / Open / Half-Open）、限流、降级；
API 网关。

Docker Compose 多容器编排：
Compose 核心概念与文件结构（services、networks、volumes、configs、secrets）；
服务配置选项；
Compose 网络与服务发现。

### 第4次课 Kubernetes基础

Kubernetes 架构与核心概念：
Master-Worker 模型；
Master 组件（kube-apiserver、etcd、controller-manager、scheduler）；
Worker 组件（kubelet、kube-proxy、Container Runtime）；
声明式 API 与 YAML 四大字段（apiVersion、kind、metadata、spec）；
Namespace 逻辑隔离。

Pod：最小调度单元：
Pod 共享机制（共享网络、共享存储）；
资源配额（requests / limits）；
Pod 生命周期与 Init Containers；
探针（Liveness、Readiness、Startup）；
QoS 等级（Guaranteed / Burstable / BestEffort）。

Service：服务发现与负载均衡：
Labels & Selectors；
三种类型（ClusterIP、NodePort、LoadBalancer）；
DNS 服务发现（CoreDNS）；
Ingress 七层路由。

Deployment：应用编排：
维持副本数、滚动更新（maxSurge / maxUnavailable）、版本回滚；
Deployment → ReplicaSet → Pod 三层结构；
扩缩容与 HPA 水平自动扩缩容；
kubectl 常用命令。

### 第5次课 Kubernetes深入与服务网格

资源配置与调度：
Requests & Limits；
调度器原理（预选 Filtering / 优选 Scoring）；
节点亲和性、Pod 亲和性与反亲和性；
污点与容忍（Taints & Tolerations，三种 Effect）；
ResourceQuota 与 LimitRange。

StatefulSet 有状态应用管理：
StatefulSet V.S. Deployment（稳定标识、独立存储、有序启停）；
Headless Service；
VolumeClaimTemplates。

ConfigMap 与 Secret：
ConfigMap 非敏感配置（环境变量注入、卷挂载、热更新）；
Secret 敏感信息管理（Base64 编码、tmpfs、类型）。

持久化存储体系：
存储三层架构（PV / PVC / StorageClass）；
访问模式（RWO / ROX / RWX）与回收策略（Retain / Delete）；
静态供给 V.S. 动态供给（Provisioner）。

Service Mesh 与 Istio：
Service Mesh 定义与背景（通信逻辑下沉、语言无关）；
Istio 架构（控制面 istiod / 数据面 Envoy）；
Sidecar 代理（Envoy 自动注入）；
流量管理（VirtualService、DestinationRule）；
安全 mTLS；
金丝雀发布（Canary Release）与发布策略对比。

三种 Exchange 类型（Direct、Fanout、Topic）；

死信队列（DLQ）与延迟消息。
