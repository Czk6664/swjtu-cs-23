## 截取数据库口令哈希（截图 6 的命令）

在课设目录下运行（PowerShell）：

```powershell
python -c "import db; \
con=__import__('sqlite3').connect('data/secure_login.db'); \
[print(r[0],'->',r[1][:60],'...') for r in con.execute('select username,password_hash from users')]"
```

输出形如：

```
czk2023 -> pbkdf2:sha256:260000$mQ08o2ymVe7... ...
alice99 -> pbkdf2:sha256:260000$Xk2p... ...
```

截图即可证明：**数据库中存储的是加盐哈希，不含任何明文口令。**

## 中文终端显示乱码的处理

Windows 默认 GBK 终端可能让中文输出显示为乱码（不影响功能）。
截图前可执行 `chcp 65001` 切换到 UTF-8，或在 PowerShell 设置：

```powershell
$env:PYTHONIOENCODING="utf-8"
chcp 65001
python run_tests.py
```
