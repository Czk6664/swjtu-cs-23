## 二、防火墙基础概念（CH7 重点）

### 2.1 防火墙是什么？

**定义**：防火墙是一种**高级访问控制设备**，部署在**不同安全级别的网络之间**（比如内网和互联网之间），通过安全策略来**控制（允许、拒绝、监视、记录）**进出网络的访问行为。

**关键点：**
- 它是两个安全域之间通信流的**唯一通道**（所有流量必须经过它）。
- 它根据**访问控制规则**决定数据包能不能通过。

> 比喻：防火墙就像小区大门的保安，所有进出的人都得经过他检查，符合规定才放行。

### 2.2 为什么需要防火墙？（三个原因）

1. **阻止来自不可信网络的攻击**（最重要）。
2. **保护内部信息**不被窃取、篡改、删除。
3. **维护信誉**——减少因攻击造成的信誉损失（尤其银行、证券）。

### 2.3 防火墙的五个基本功能（必背）

1. **过滤**进、出网络的数据。
2. **管理**进、出网络的访问行为。
3. **封堵**某些禁止的业务。
4. **记录**通过防火墙的信息内容和活动（日志审计）。
5. 对网络攻击的**检测和告警**。

## 三、防火墙的核心技术（四种类型，必考）

这是作业3最重要的考点，要分清四种技术工作在哪一层、检查什么：

| 类型 | 工作层 | 检查什么 | 是否建连接状态表 | 特点 |
|------|--------|---------|----------------|------|
| **包过滤** | 网络层 | 只看**报头**（IP、端口、协议）| 否 | 快、简单、透明，但前后报文无关、应用层控制弱 |
| **应用代理** | 应用层 | 只看**数据**（应用层内容）| 否 | 应用层检测强，但慢、不透明、支持应用有限 |
| **状态检测** | 2~4 层 | 看**报头 + 连接状态** | **是** | 跟踪整个会话，性能高、应用广 |
| **完全内容检测** | 2~7 层 | **报头 + 状态 + 应用层内容**（还原会话）| 是 | 防护最强，能防混合威胁 |

### 3.1 包过滤防火墙（Packet Filter）

- 工作在**网络层**，只检查数据包的**报头**：IP 地址、端口号、协议类型。
- **优点**：规则简单、处理快、易配置、对用户透明（不用输额外密码）。
- **缺点**：
  - 只在网络层，**不能识别应用层协议**，**不维持连接状态**。
  - 前后报文无关，应用层控制很弱。
  - 不能防 IP 欺骗；静态策略可能成为漏洞。

### 3.2 应用代理防火墙（Application Proxy）

- 工作在**应用层**，能对应用内容过滤（比如禁止 FTP 的 `put` 命令）。
- **优点**：安全性好，所有数据在应用层检查。
- **缺点**：
  - 支持的应用数量有限，难支持新应用/协议。
  - **对用户不透明**。
  - **性能差**。
- 后来出现"**自适应代理**"，结合了代理的安全性和包过滤的高速度。

### 3.3 状态检测防火墙（Stateful Inspection）

- 工作在 **2~4 层**，核心是**建立状态连接表**，把进出数据当成一个个**会话**来跟踪。
- 检查每个包时，不仅看规则表，还看这个包**是否符合会话当前的状态**。
- **优点**：性能大幅提高、支持大量应用、在内核级实现检测过滤。
- 它克服了包过滤"只看单个包、不管连接状态"的缺点。

### 3.4 完全内容检测（Complete Content Inspection）

- 工作在 **2~7 层**，不仅分析报头、状态，还**还原应用层协议并分析内容**。
- 能有效防范**混合型安全威胁**。
- 网络层、应用层、会话保护都很强。

## 四、防火墙的体系结构（必考）

四种经典结构，安全性逐渐增强：

| 结构 | 组成 | 特点/弱点 |
|------|------|----------|
| **过滤路由器** | 一个路由器（ACL 过滤）| 唯一通道，但被攻陷难发现、无日志、不能识别用户 |
| **双宿主主机** | 一台双网卡堡垒主机 | 能维护日志，但堡垒主机一旦被入侵，内网全暴露 |
| **被屏蔽主机** | 屏蔽路由器 + 堡垒主机 | 两道屏障，但攻击者进入堡垒主机后内网仍受威胁 |
| **被屏蔽子网（DMZ）** | 两个路由器 + 堡垒主机 + 周边网络 | **最安全**，但成本高、配置复杂 |

### 4.1 被屏蔽子网 / DMZ（DeMilitarized Zone，重点）

**DMZ（隔离区 / 非军事区）** 是最重要的概念：

- 在内网和外网之间建立一个**被隔离的子网（周边网络）**，用**两台路由器**（外部路由器 + 内部路由器）夹起来，堡垒主机放在中间。
- **四个部件**：周边网络、外部路由器、内部路由器、堡垒主机。

**典型部署（企业三区）：**
- **内部网络**（可信）：用私有 IP。
- **DMZ 区**：放对外服务器（Web、FTP、Mail、DNS）。
- **外部网络**（不可信）：互联网。

**典型访问策略：**
- 外部网络**不允许**直接访问内部网络。
- 内部用户可按权限访问互联网。
- 内部和外部用户**只允许访问 DMZ 区指定服务器的指定服务**。

**DMZ 的核心价值**：即使攻击者攻破了 DMZ 里的堡垒主机，由于内部路由器的隔离，他也**无法监听到内部网络的信息**——把对外服务和内网核心隔离开。

## 五、NAT 与接入方式

### 5.1 NAT（网络地址转换）

- **作用**：把内部网络的私有地址转换成公网地址。
- **好处**：
  - 隐藏内部网络结构。
  - 内部网络可使用私有 IP。
  - 解决公网地址不足（IP 复用）。
- **MAP（地址/端口映射）**：把公网地址+端口映射到内部服务器，让公开服务器可以用私有地址对外提供服务。

### 5.2 防火墙的三种接入方式

| 方式 | 防火墙相当于 | 特点 |
|------|-------------|------|
| **路由接入** | 路由器 | 连接不同网段，要配 IP |
| **透明接入** | 网桥 | 内部主机配置不用改，防火墙在同一网段不用配 IP |
| **混合接入** | 路由 + 透明并存 | 大多数防火墙同时支持，按需选择 |

> 路由模式和透明模式的优点不能同时并存，但大多数防火墙两种都保留，使用时由用户选。

## 六、防火墙的性能指标（必背五大）

| 指标 | 含义 | 衡量标准 |
|------|------|---------|
| **吞吐量** | 不丢包情况下能达到的最大速率 | 越大越好 |
| **时延** | 输入帧最后1比特到达 → 输出帧第1比特输出的时间间隔 | 越小越好 |
| **丢包率** | 因资源不足该转发却没转发的帧的百分比 | 越小越好 |
| **背靠背** | 从空闲开始全速发包，出现第一个丢包时发送的帧数 | 体现缓冲能力，越大越好 |
| **并发连接数** | 穿越防火墙能同时建立的最大连接数 | 越大越好 |

> 注意：**"屏幕分辨率"之类的不是防火墙性能指标**——这种题考的就是你能不能分清。

## 七、防火墙的局限性（必考）

防火墙**不是万能的**，记住几个关键局限：

1. **防外不防内**——很难防范来自内部网络的攻击或滥用。
2. 不能防范**未经过防火墙或绕过防火墙**的攻击（比如内部用户私自拨号上网）。
3. 只实现了**粗粒度**的访问控制。
4. 难以管理和配置，易造成安全漏洞。
5. 基于报头检测，**无法阻断通过开放端口流入的有害流量**（不是蠕虫/黑客攻击的解决方案）。
6. 对**0day 攻击**（未知漏洞攻击）无能为力。

> 这就是为什么需要 **IDS、WAF** 等来补充防火墙的不足。

### 防火墙的"胖瘦之争"
- **胖防火墙**：功能大而全（集成防病毒、入侵检测、内容过滤等）。优点功能全，缺点性能降低、自身安全性弱。
- **瘦防火墙**：功能少而精，只做访问控制，靠多厂商联动实现综合防护。优点性能高、专业，缺点功能单一。

## 八、WAF：Web 应用防火墙（必考）

### 8.1 WAF 是什么？

- **WAF（Web Application Firewall）**：专门保护 **Web 应用** 的防火墙。
- 主要防护对象：**Web 应用**（不是路由器、不是交换机）。
- 防护的攻击：**SQL 注入、XSS（跨站脚本）、XML 注入、Web DDoS** 等。
- 因为重点防 SQL 注入，也有人叫它"SQL 防火墙"。
- **本质**：它防的是**应用层**攻击，从技术角度更应叫 **Web IPS**。

### 8.2 为什么传统防火墙防不住 Web 攻击？

- 传统包过滤/状态检测防火墙**主要工作在网络层和传输层**，**不分析应用层内容**。
- SQL 注入、XSS 这些攻击是藏在**正常的 HTTP/HTTPS 请求**里的（端口 80/443 本来就是开放的）。
- 所以传统防火墙看不出这些请求有问题，自然防不住。

### 8.3 WAF 的部署与技术

- **部署**：串行接入在 **Web 服务器前面**，所以要求高性能、需要 HA（高可用）和 Bypass 功能。
- **检测技术（核心考点）**：
  1. **代理服务**：双向代理，中断用户与服务器直连，能抑制 DDoS。
  2. **特征识别**：靠攻击者的"指纹"识别（如 SQL 注入的 `1=1`、缓冲区溢出的 Shellcode）。缺点：特征库庞大、易误报、对 0day 无效。
  3. **算法识别**：对攻击类型归类做模式化，进行**语义理解**而非"长相"识别。
  4. **模式匹配**：把攻击行为归纳成模式来匹配（IDS 传统技术）。
  5. **自学习技术**：先学习一段时间正常访问，建立"正常模式"，偏离的就预警/阻断。
- **最大挑战**：**识别率**（漏报和误报的平衡）。

### 8.4 基于机器学习的 Web 异常检测（CH7 延伸）

- 传统规则集难应对 **0day 攻击**。
- 思路转变：不去识别"入侵行为"，而是建模"**正常流量**"（Profile），不符合正常的就是异常——"以不变应万变"，更难被绕过。
- 方法：基于统计学习、文本分析（如 HMM 隐马尔科夫模型）、单分类模型（one-class SVM）、聚类模型。

## 九、入侵检测系统 IDS（必考）

### 9.1 IDS 是什么？

- **IDS（Intrusion Detection System）**：**监控**系统或网络，识别**违反安全策略的行为和攻击迹象**。
- IDS 是**防火墙的补充**——防火墙挡在门口，IDS 在里面"巡逻"，发现内部和绕过防火墙的攻击。
- 注意：IDS 主要是**检测和告警**，本身一般不主动阻断（能阻断的叫 IPS）。

### 9.2 Denning 模型

- 入侵检测的奠基模型。核心思想：通过**审计记录（Audit Records）**来识别异常和攻击行为。

### 9.3 CIDF 通用入侵检测框架

CIDF 把 IDS 分成**四个核心组件**：

| 组件 | 作用 |
|------|------|
| **事件产生器** | 采集数据，产生事件 |
| **事件分析器** | 分析事件，发现攻击 |
| **事件数据库** | 存储事件 |
| **响应单元** | 对分析结果做出反应 |

### 9.4 异常检测 vs 误用检测（必考对比）

这是 IDS 最重要的对比：

| 对比项 | 异常检测（Anomaly Detection）| 误用/特征检测（Misuse Detection）|
|--------|------------------------------|--------------------------------|
| 核心思想 | 建立**正常行为模型**，识别偏离正常的行为 | 匹配**已知攻击特征（签名）** |
| 能否检测未知攻击 | **能**（0day）| **不能**（只能查已知）|
| 主要缺点 | **误报率高**（正常的新行为也可能被当异常）| 漏报未知攻击，需不断更新特征库 |
| 是否需要先验知识 | 不需要攻击知识 | 需要攻击特征库 |

> 记忆：**异常检测**——"你不正常，我就报警"（能抓新攻击，但容易误伤）；**误用检测**——"你长得像通缉犯，我就抓"（准但只能抓已知的）。

### 9.5 HIDS vs NIDS（按检测范围分类，必考对比）

| 类型 | 全称 | 部署位置 | 特点 |
|------|------|---------|------|
| **HIDS** | 主机入侵检测系统 | 装在**单台主机**上 | 能把操作映射到具体用户，能检测**加密通信解密后**的内容；占主机资源 |
| **NIDS** | 网络入侵检测系统 | 部署在**网络节点**（监听网段流量）| 监控整个网段，但**无法直接分析加密通信**的内容（看不懂密文）|

还有**混合型（分布式）入侵检测**——结合两者。

> 选位置：监控**整个网段**用 NIDS；监控**关键服务器**且要看加密内容用 HIDS。

### 9.6 Snort

- 著名的**开源网络入侵检测系统**。
- 通过**规则（Rule）**进行检测，**规则由规则头和规则选项两部分组成**。
- 主要构成：嗅探数据包、预处理、检测引擎、日志/告警系统。

## 十、防火墙 vs IDS vs WAF 总结对比

| 设备 | 工作位置 | 主要作用 | 防什么 |
|------|---------|---------|--------|
| **防火墙** | 网络边界 | 访问控制（允许/拒绝）| 控制进出流量，防外部攻击 |
| **WAF** | Web 服务器前 | 防 Web 应用层攻击 | SQL 注入、XSS 等 |
| **IDS** | 网络/主机内部 | 检测并告警 | 内部攻击、绕过防火墙的攻击 |

> 它们是互补关系：防火墙挡门、WAF 护 Web、IDS 巡逻。组合起来才是完整的纵深防御。
