## 本层内容介绍

这里是“网络空间安全技术”课程下的“firewall_lab”目录，主要用于整理此模块的源码及配套文件。

**阅读建议：**从上级项目说明确认模块职责，再结合文件名查找实现；具体入口和运行方法以源码及原说明为准。

### 本层有哪些内容

本目录及子目录共收录 **17 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **代码与脚本（7 份）**：[common.py](common.py)、[main.py](main.py)等；完整列表见本页导航。
- **文档与说明（2 份）**：[firewall_complete.txt](firewall_complete.txt)、[report_notes.md](report_notes.md)。
- **配置及其他配套文件（3 份）**：[flowchart.arch.json](flowchart.arch.json)、[flowchart.drawio](flowchart.drawio)等；完整列表见本页导航。
- **图片与图形（4 份）**：[flowchart.svg](flowchart.svg)、[flowchart_preview-1.png](flowchart_preview-1.png)等；完整列表见本页导航。
