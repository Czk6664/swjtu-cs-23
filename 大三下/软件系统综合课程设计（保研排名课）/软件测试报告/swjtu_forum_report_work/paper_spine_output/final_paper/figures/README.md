## 本层内容介绍

这里是“软件系统综合课程设计”课程下的“figures”目录，主要用于整理图像、插图或配套素材。

**阅读建议：**先在对应报告、课件或页面中查看这些素材的上下文，需要查图或复现时再打开原文件。

### 本层有哪些内容

本目录及子目录共收录 **34 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。
