## 本层内容介绍

这里是“软件系统综合课程设计”课程下的“swjtu_forum_report_work”目录，主要用于整理此模块的源码及配套文件。

**阅读建议：**从上级项目说明确认模块职责，再结合文件名查找实现；具体入口和运行方法以源码及原说明为准。

### 本层有哪些内容

本目录及子目录共收录 **60 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

| 子目录 | 内容与用途 |
| --- | --- |
| [evidence](evidence/README.md) | 界面截图、渲染预览或检查记录 |
| [paper_spine_output](paper_spine_output/README.md) | 报告文档或报告排版源文件 |
| [selenium-junit](selenium-junit/README.md) | 包含依赖或构建配置的项目目录 |

- **配置及其他配套文件（4 份）**：[batch-api-results.json](batch-api-results.json)、[report_build_summary.json](report_build_summary.json)等；完整列表见本页导航。
- **代码与脚本（5 份）**：[build_report.py](build_report.py)、[build_test_artifacts.py](build_test_artifacts.py)等；完整列表见本页导航。
- **表格与数据（2 份）**：[测试用例.csv](%E6%B5%8B%E8%AF%95%E7%94%A8%E4%BE%8B.csv)、[缺陷清单.csv](%E7%BC%BA%E9%99%B7%E6%B8%85%E5%8D%95.csv)。
