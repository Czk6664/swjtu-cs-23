# 西南交大论坛交付验收操作说明

本文档用于课程设计最终交付、换机运行和服务器部署前检查。

## 1. 当前交付内容

- `backend/`：Spring Boot 后端，包含认证、帖子、评论、图片上传、关注、通知、成长积分、积分商城、内容治理、用户管理、推荐策略和后台统计接口。
- `frontend/`：Vite 多页面前端，所有页面通过统一运行时接入真实后端接口。
- `init-database.sql`：MySQL 建库入口脚本。
- `start.ps1`：源码模式一键启动脚本。
- `build-portable.ps1`：生成便携运行包。
- `packaging/`：便携包启动/停止脚本和静态前端服务器源码。
- `docs/`：系统设计、接口、数据库、安全和管理界面说明。

## 2. 本地源码启动

默认推荐使用 MySQL profile：

```powershell
mysql -u root -p < init-database.sql

$env:DB_USERNAME = "root"
$env:DB_PASSWORD = "你的 MySQL 密码"
$env:JWT_SECRET = "replace-with-a-long-random-secret-at-least-32-chars"
.\start.ps1
```

访问地址：

- 前端：http://localhost:4173
- 后端：http://localhost:8080/api
- 管理员：admin / admin123456

如果只是临时演示、没有 MySQL，可以使用 H2 demo 模式：

```powershell
.\start.ps1 -SpringProfile demo
```

## 3. MySQL 初始化与 seed 机制

MySQL 初始化分两步完成：

1. 执行 `init-database.sql` 创建 `swjtu_forum` 数据库，字符集为 `utf8mb4`。
2. 后端以 `mysql` profile 启动后，Spring Data JPA 根据实体自动同步表结构，Java seeder 自动写入基础数据和演示数据。

关键配置：

- MySQL profile：`backend/src/main/resources/application-mysql.yml`
- 默认 JDBC：`jdbc:mysql://localhost:3306/swjtu_forum?...`
- 建表策略：继承主配置 `spring.jpa.hibernate.ddl-auto=update`
- 基础管理员与基础版块：`app.bootstrap.enabled=true`
- 演示数据：`demo.seed.enabled=true`

如需关闭演示数据 seed：

```powershell
$env:DEMO_SEED_ENABLED = "false"
```

关闭后仍会保留基础管理员和基础版块初始化。

## 4. 服务器 MySQL 部署建议

服务器建议创建独立数据库用户，不直接使用 root：

```sql
CREATE DATABASE IF NOT EXISTS swjtu_forum
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

CREATE USER IF NOT EXISTS 'swjtu_forum'@'localhost'
  IDENTIFIED BY '请替换成强密码';

GRANT ALL PRIVILEGES ON swjtu_forum.* TO 'swjtu_forum'@'localhost';
FLUSH PRIVILEGES;
```

后端启动示例：

```bash
export DB_URL='jdbc:mysql://127.0.0.1:3306/swjtu_forum?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true'
export DB_USERNAME='swjtu_forum'
export DB_PASSWORD='请替换成强密码'
export JWT_SECRET='请替换成至少32位随机密钥'

java -Dfile.encoding=UTF-8 \
  -Dspring.profiles.active=mysql \
  -jar forum-1.0.0.jar \
  --server.port=8081
```

## 5. 生成便携交付包

便携包适合发给老师或同学直接运行，不依赖 MySQL、Node.js、Maven。

```powershell
.\build-portable.ps1
```

输出目录：

```text
release/swjtu-forum-portable/
```

运行方式：

```text
双击 release/swjtu-forum-portable/start.bat
```

说明：便携包使用 `demo` profile 和 H2 文件数据库，数据保存在便携包的 `app/backend/data` 中。

## 7. 功能验收重点

- 普通用户：注册、登录、浏览帖子、发帖、上传图片、评论、点赞、收藏、关注、签到、积分兑换。
- 管理员：管理总览、内容治理、用户管理、推荐策略、积分商品上架/下架。
- 页面行为：顶部“积分商城”进入普通积分商城；后台侧栏“积分奖励”进入积分商品管理。
- 数据：MySQL 模式下数据写入 `swjtu_forum`；便携包模式下数据写入 H2 文件。

## 8. 常见问题

- 登录 403：确认使用管理员账号进入后台；普通用户只能访问论坛前台功能。
- 页面请求超时：确认后端端口启动成功，前端代理的 `BACKEND_PORT` 与后端端口一致。
- MySQL 连接失败：确认数据库已创建、账号密码正确、MySQL 服务正在运行。
- 便携包打不开：优先检查 8080 或 4173 是否被占用，可改用 `start-portable.ps1 -BackendPort 8081 -FrontendPort 4174`。
