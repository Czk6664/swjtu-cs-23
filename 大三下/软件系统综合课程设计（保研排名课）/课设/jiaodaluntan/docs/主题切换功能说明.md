# 主题切换功能说明

## 功能概述

交大校园论坛系统现已支持深色/浅色主题自动切换功能，可以根据系统主题自动调整，也支持用户手动选择。

## 功能特性

### 1. 三种主题模式
- **浅色模式** - 白色背景，适合白天使用
- **深色模式** - 黑色背景，适合夜间使用
- **跟随系统** - 自动跟随操作系统的主题设置

### 2. 自动检测系统主题
- 系统会自动检测操作系统的主题设置
- 当系统主题改变时，应用会自动切换（在"跟随系统"模式下）
- 使用CSS媒体查询 `prefers-color-scheme` 实现

### 3. 主题持久化
- 用户选择的主题模式会保存在浏览器本地存储
- 下次访问时自动应用上次选择的主题
- 刷新页面不会丢失主题设置

### 4. 平滑过渡动画
- 所有颜色变化都有0.3秒的过渡动画
- 切换主题时界面平滑过渡，无闪烁

## 使用方法

### 切换主题
1. 点击顶部导航栏右侧的主题图标
2. 在下拉菜单中选择：
   - ☀️ 浅色模式
   - 🌙 深色模式
   - 🖥️ 跟随系统

## 技术实现

### 1. 主题管理（Pinia Store）

```javascript
// store/theme.js
- themeMode: 'light' | 'dark' | 'auto'
- isDark: boolean
- setThemeMode(mode): 设置主题模式
- toggleTheme(): 切换主题
- updateTheme(): 更新主题
```

### 2. CSS变量系统

```css
/* 浅色主题 */
:root {
  --bg-primary: #ffffff;
  --text-primary: #333333;
  ...
}

/* 深色主题 */
[data-theme="dark"] {
  --bg-primary: #121212;
  --text-primary: #ffffff;
  ...
}
```

### 3. 主题变量

| 变量名 | 浅色模式 | 深色模式 | 说明 |
|--------|----------|----------|------|
| --bg-primary | #ffffff | #121212 | 主背景色 |
| --bg-secondary | #f5f5f5 | #1a1a1a | 次要背景色 |
| --bg-card | #ffffff | #1a1a1a | 卡片背景色 |
| --bg-hover | #f0f0f0 | #2a2a2a | 悬停背景色 |
| --text-primary | #333333 | #ffffff | 主文字色 |
| --text-secondary | #666666 | #cccccc | 次要文字色 |
| --text-tertiary | #999999 | #999999 | 三级文字色 |
| --border-color | #e0e0e0 | #333333 | 边框颜色 |
| --shadow-color | rgba(0,0,0,0.1) | rgba(0,0,0,0.5) | 阴影颜色 |

## 常见问题

### Q1: 为什么我的主题没有跟随系统？
A: 请确保选择了"跟随系统"模式，并且你的操作系统支持主题检测。

### Q2: 如何设置默认主题？
A: 首次访问时默认为"跟随系统"模式，你可以手动切换并保存。

### Q3: 主题切换会影响性能吗？
A: 不会，我们使用CSS变量实现，性能开销极小。

### Q4: 可以自定义主题颜色吗？
A: 目前暂不支持，但这是我们的未来计划之一。

## 开发指南

### 添加新组件时如何适配主题？

1. 使用CSS变量代替固定颜色：
```css
/* ❌ 不推荐 */
.my-component {
  background: #ffffff;
  color: #333333;
}

/* ✅ 推荐 */
.my-component {
  background: var(--bg-card);
  color: var(--text-primary);
}
```

2. 添加过渡动画：
```css
.my-component {
  transition: var(--transition);
}
```

3. 测试两种主题：
- 在浅色模式下测试
- 在深色模式下测试
- 确保对比度足够
