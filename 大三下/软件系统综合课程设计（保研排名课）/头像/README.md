## 本层内容介绍

这里是“软件系统综合课程设计”课程下的“头像”目录，主要用于整理界面展示使用的图形素材。

**阅读建议：**这些文件用于界面显示，可在阅读页面实现或替换素材时查看。

### 本层有哪些内容

本目录及子目录共收录 **100 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **图片与图形（100 份）**：[001_adventurer_1.png](001_adventurer_1.png)、[002_adventurer_2.png](002_adventurer_2.png)等；完整列表见本页导航。

所属课程：[软件系统综合课程设计](../README.md)。
