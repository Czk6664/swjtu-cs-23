## Why

当前系统已经具备真实接口、登录、发帖、评论、成长中心和后台管理雏形，但作为课程设计的“论坛系统”仍显得功能偏薄，并且真实用户路径缺少系统化烟测，容易出现 403、跳转失效、页面静态内容覆盖动态数据等可见 bug。现在需要从“能演示”推进到“能按老师随机点击也基本可用”，补齐论坛核心闭环并稳定关键流程。

## What Changes

- 补齐普通用户论坛核心路径：搜索/筛选帖子、查看版块页、发帖后状态反馈、编辑/删除自己的帖子、查看自己的内容与互动记录。
- 增强帖子详情与互动体验：评论列表、评论提交、点赞、收藏、举报、待审核/被隐藏状态提示都应有清晰反馈。
- 补齐个人中心与账号体验：个人资料编辑、校园身份状态展示、我的帖子/收藏/浏览历史、基础通知或操作反馈入口。
- 增强后台治理闭环：管理员能够处理待审帖子、举报、用户封禁/解封、版块管理，并在前端获得真实操作结果反馈。
- 系统化修复真实路径 bug：登录回跳、权限提示、CORS 本地来源、空数据、接口错误、删除外键约束、静态样稿残留等问题进入统一验收。
- 建立关键用户旅程 smoke test：游客浏览、用户注册登录发帖评论、用户互动、管理员审核治理、异常权限访问。

## Capabilities

### New Capabilities

- `forum-content-lifecycle`: 覆盖帖子从浏览、搜索、发布、编辑、删除、状态展示到详情阅读的完整内容生命周期。
- `forum-engagement-workflows`: 覆盖评论、点赞、收藏、举报、浏览历史等论坛互动行为及其反馈。
- `forum-user-center-experience`: 覆盖个人资料、校园身份状态、我的内容、我的收藏、浏览历史和基础通知反馈体验。
- `forum-admin-governance-closure`: 覆盖后台待审内容、举报处理、用户管理、版块管理和治理结果展示。
- `forum-real-journey-stability`: 覆盖游客、普通用户、管理员三类角色的端到端路径稳定性、权限边界和错误/空态体验。

### Modified Capabilities

- None.

## Impact

- 前端：`frontend/assets/app.js` 的页面运行时、各 `frontend/*/code.html` 页面入口、共享样式、前端测试与 smoke test。
- 后端：帖子、评论、用户、成长、举报、后台治理相关 Controller/Service/Repository；必要时补充缺失的用户内容管理与版块管理接口。
- 数据库：可能需要确认评论/帖子删除策略、通知或操作记录字段、帖子状态与外键约束是否支持真实删除/隐藏流程。
- 验证：补充后端契约测试、前端运行时测试和真实浏览器烟测矩阵，确保课程展示路径不依赖口头解释。
