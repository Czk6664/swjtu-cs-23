## ADDED Requirements

### Requirement: 管理后台展示增强运营概览
系统 SHALL 在管理后台展示论坛运营数据概览，包括用户、帖子、评论、版块分布、热门话题和热帖。

#### Scenario: 管理员打开数据大屏
- **WHEN** 管理员进入后台数据大屏
- **THEN** 系统展示增强后的运营统计卡片、趋势数据和分布数据

### Requirement: 管理后台展示活跃用户统计
系统 SHALL 支持按日、周、月维度展示用户活跃度。

#### Scenario: 查看活跃用户趋势
- **WHEN** 管理员请求活跃用户统计
- **THEN** 系统返回可用于趋势图展示的时间序列数据

### Requirement: 管理后台展示互动数据统计
系统 SHALL 展示评论、点赞、收藏等互动数据统计。

#### Scenario: 查看互动趋势
- **WHEN** 管理员请求互动数据统计
- **THEN** 系统返回评论数、点赞数、收藏数等互动指标

### Requirement: 管理后台可以生成运营报告
系统 SHALL 提供运营报告数据或可打印报告页面。

#### Scenario: 导出运营报告
- **WHEN** 管理员点击生成报告
- **THEN** 系统生成包含核心指标、趋势、热门话题和热帖摘要的报告

### Requirement: 数据大屏接口仅管理员可访问
系统 MUST 保持后台统计增强接口需要管理员权限。

#### Scenario: 普通用户访问后台统计
- **WHEN** 普通用户请求管理端数据大屏接口
- **THEN** 系统拒绝访问，并且普通首页热榜不依赖该后台接口
