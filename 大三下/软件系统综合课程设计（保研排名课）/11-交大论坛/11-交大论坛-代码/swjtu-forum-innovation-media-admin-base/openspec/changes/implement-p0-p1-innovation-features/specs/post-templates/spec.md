## ADDED Requirements

### Requirement: 发帖页按版块提供模板
系统 SHALL 在用户选择特定版块后提供对应的结构化正文模板。

#### Scenario: 选择课程互助版块
- **WHEN** 用户在发帖页选择课程互助版块且正文为空
- **THEN** 系统自动填入课程名称、问题描述、已尝试方法和希望帮助等模板字段

### Requirement: 模板不得覆盖用户已输入内容
系统 MUST 保留用户已经输入的正文内容。

#### Scenario: 正文已有内容时切换版块
- **WHEN** 用户正文不为空并切换版块
- **THEN** 系统不自动覆盖正文内容

### Requirement: 模板能力不改变后端数据模型
系统 SHALL 将帖子模板作为前端辅助能力，不新增数据库表。

#### Scenario: 提交模板帖子
- **WHEN** 用户基于模板填写内容并提交帖子
- **THEN** 系统按普通帖子创建流程保存标题、正文、版块和标签
