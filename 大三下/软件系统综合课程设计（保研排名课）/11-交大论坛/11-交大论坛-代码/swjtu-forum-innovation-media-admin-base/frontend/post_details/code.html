犀浦图书馆期中周自习位几点最容易找到？我把一周观察到的高峰时段整理出来了

LT
李同学
信息科学与技术学院 · Lv.6 · 已实名认证

这类帖子很像校园论坛真正有价值的内容：不是“泛泛分享”，而是围绕一个具体校内问题，给出真实可用的经验整理。

我连续观察了这周一到周五的图书馆情况，发现上午 8:10 到 8:40 之间最容易在五楼和六楼找到连续空位；如果是下午去，14:00 之后流动会明显快一些。临近周末的时候，自习区高峰会提前。

另外，如果只是想找插座位，建议直接去靠近窗边那一圈；如果是小组复习，四楼讨论区周三和周四相对更空。顺手补一句，二食堂晚饭高峰差不多从 17:35 开始，人流跟图书馆晚高峰重叠得很明显。
