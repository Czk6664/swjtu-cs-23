## 一、缺陷排查与修复（含严重级别）

通过多视角静态审查 + 业务一致性分析，定位并修复了以下真实缺陷：

| 级别 | 缺陷 | 影响 | 修复方式 |
|------|------|------|----------|
| CRITICAL | 奖励兑换库存/积分存在「检查—执行」竞态（TOCTOU），并发兑换会超卖、积分变负 | 数据不一致、薅羊毛 | `RewardItemRepository.decrementStock` / `UserRepository.deductPoints` 改为**原子条件 UPDATE**（`WHERE stock>0` / `points>=cost`），返回 0 即回滚事务。退款/退库同理用 `incrementStock`/`addPoints` |
| HIGH | `commentCount` 统计含已隐藏评论，且版主隐藏/恢复评论后不回写计数 | 评论数虚高、永不回落 | 计数改为只统计可见评论 `countByPostAndStatus(post,1)`；隐藏/恢复时同步回写 |
| HIGH | 举报「采纳」只改工单状态，不处理被举报帖子 | 审核闭环形同虚设 | 采纳时将被举报且仍在展示的帖子置为隐藏（`STATUS_HIDDEN`） |
| HIGH | 匿名访问 `/posts/mine`、`/posts/favorites`、`/posts/history` 命中宽松的 `GET /posts/**` 放行，进而 `authentication.getName()` 触发 500 | 接口稳定性 | 在 SecurityConfig 中将这些读接口显式置于 `authenticated()`（顺序前置） |
| MEDIUM | 签到并发重复提交时唯一约束异常以 500 抛出 | 体验/稳定性 | `saveAndFlush` 捕获 `DataIntegrityViolationException`，转换为「今日已签到」400 |
| MEDIUM | 推荐方法未声明事务，`post.getTags()` 懒加载有 `LazyInitializationException` 隐患 | 潜在崩溃 | 为 `recommendPosts`/`previewRecommendations` 增加 `@Transactional(readOnly=true)` |

## 二、安全加固

| 项 | 加固前 | 加固后 |
|----|--------|--------|
| JWT 密钥 | 弱密钥无校验 | 启动时 `@PostConstruct` 校验密钥 ≥ 32 字节，否则 fail-fast |
| 登录爆破 | 无限制 | 新增 `LoginAttemptService`：同一账号 5 次失败锁定 5 分钟（内存滑窗，零外部依赖），返回 429 |
| CORS | `allowCredentials=true` 与 Bearer 鉴权不匹配（CSRF 关闭下的隐患） | 改为 `false`（纯 Header Bearer 不需要凭证化 CORS） |
| 异常映射 | 无 429 | `GlobalExceptionHandler` 增加 429 → `TOO_MANY_REQUESTS` |

> 已确认良性项（无需改动）：BCrypt 存储、密码 `@JsonIgnore`、JPQL 全参数化（无注入）、`findByIdAndAuthor` 防 IDOR、被封禁用户每请求重校验 `enabled`、分页上限 50 防滥用。

## 三、新增功能（闭合需求缺口）

1. **站内通知系统** `Notification` 实体 + `/notifications`：未读数、列表、单条已读、全部已读。事件触发：被评论、被回复、举报被处理、升级、兑换审核、新增粉丝。前端在顶栏加入通知铃铛 + 未读角标 + 下拉面板。
2. **楼中楼评论（二级回复）** 复用既有 `parent_id`：评论支持 `parentId`，被回复者收到通知；`GET /posts/{id}/comments` 直接返回每条评论的 `replies`/`replyCount`，前端嵌套渲染。
3. **用户关注 + 社交化推荐** `UserFollow` 实体 + `/users/{id}/follow`（关注/取关/统计）。推荐引擎把「关注作者的帖子」纳入候选并给予加分（解释文案「来自你关注的用户」），补齐需求中推荐算法的社交因子。
4. **搜索升级** 搜索从「标题/正文 LIKE」扩展为**标题 + 正文 + 作者名 + 标签名**联合匹配，按热度排序。

## 四、创新点（差异化亮点）

1. **运营数据看板 / 舆情监测** `GET /admin/analytics`：KPI 总览、近 7 日发帖趋势、版块分布、**热门标签 Top10（舆情信号）**、热门内容榜。前端用纯 CSS 柱状图呈现，无第三方图表依赖。对应需求创新点「数据分析模块 / 舆情监测」。
2. **成就徽章体系** `GET /growth/achievements`：从既有用户数据**实时派生**徽章（初来乍到/笔耕不辍/人气作者/连续签到/等级达人/积分新贵），含进度条与「即将达成」态，零额外数据表、不会与真实数据漂移。
3. **推荐可解释性增强**（在既有解释基础上）：新增社交因子解释，让「千人千面」推荐对用户透明、对管理员可调。
4. **签到防并发 + 原子积分账本**：积分变动全程原子化并写 `points_history` 流水（含兑换退款流水），账目可追溯。
