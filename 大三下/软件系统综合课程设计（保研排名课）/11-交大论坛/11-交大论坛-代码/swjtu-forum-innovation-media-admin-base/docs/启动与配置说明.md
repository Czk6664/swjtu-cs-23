# 启动与配置说明

## 0. 当前推荐启动方式

当前项目默认就是可用版本：后端使用本地 H2 持久化数据库，自动初始化基础版块、默认管理员和站务公告，不再需要 MySQL 密码，也不需要 `demo` profile。

后端：

```powershell
cd backend
mvn spring-boot:run
```

前端：

```powershell
cd frontend
npm install
npm run dev
```

访问：

- `http://127.0.0.1:5173`
- `http://localhost:8080/api`
- `http://localhost:8080/api/h2-console`

默认管理员：`admin / admin123456`

H2 本地数据库文件：`backend/data/swjtu-forum-local.mv.db`

MySQL 仍作为可选正式部署 profile：

```powershell
cd backend
$env:DB_USERNAME = "root"
$env:DB_PASSWORD = "<your-mysql-password>"
$env:JWT_SECRET = "replace-with-a-long-secret"
mvn spring-boot:run -Dspring-boot.run.profiles=mysql
```

下面保留原课程文档说明。

## 2. 后端配置

后端默认配置文件：
- `backend/src/main/resources/application.yml`

当前支持通过环境变量覆盖以下配置：

| 变量名 | 说明 | 默认值 |
|---|---|---|
| `DB_URL` | MySQL 连接串 | `jdbc:mysql://localhost:3306/swjtu_forum?...` |
| `DB_USERNAME` | 数据库用户名 | `root` |
| `DB_PASSWORD` | 数据库密码 | 空 |
| `REDIS_HOST` | Redis 主机 | `localhost` |
| `REDIS_PORT` | Redis 端口 | `6379` |
| `REDIS_PASSWORD` | Redis 密码 | 空 |
| `REDIS_DATABASE` | Redis 数据库编号 | `0` |
| `SERVER_PORT` | 后端端口 | `8080` |
| `JWT_SECRET` | JWT 密钥 | 无默认值，必须显式提供 |
| `JWT_EXPIRATION` | JWT 过期时间（毫秒） | `86400000` |
| `JPA_SHOW_SQL` | 是否输出 SQL | `false` |
| `JPA_FORMAT_SQL` | 是否格式化 SQL | `false` |
| `APP_LOG_LEVEL` | 业务日志级别 | `INFO` |
| `SECURITY_LOG_LEVEL` | Spring Security 日志级别 | `INFO` |

> 开发环境若需要排查问题，可临时显式设置：
>
> - `JPA_SHOW_SQL=true`
> - `JPA_FORMAT_SQL=true`
> - `APP_LOG_LEVEL=DEBUG`
> - `SECURITY_LOG_LEVEL=DEBUG`
>
> 在共享演示环境和正式环境中，建议保留默认值，并显式设置：
>
> - `JWT_SECRET`
> - `DB_PASSWORD`

## 3. 数据库初始化

数据库结构以以下文件为准：
- `backend/src/main/resources/schema.sql`

根目录文件：
- `init-database.sql`

用于在 MySQL 客户端中快速创建数据库并执行主结构脚本，其核心作用是调用：

```sql
SOURCE backend/src/main/resources/schema.sql;
```

### 推荐初始化方式
在项目根目录下，通过 MySQL 客户端执行：

```bash
mysql -u root -p < init-database.sql
```

执行后将创建：
- 数据库 `swjtu_forum`
- 基础表结构
- 初始推荐配置
- 初始版块数据

## 4. 后端启动

### 开发环境示例

```bash
cd backend
export JWT_SECRET="your-local-dev-secret"
mvn spring-boot:run
```

默认启动后：
- 端口：`8080`
- 基础路径：`/api`

### 启用 demo profile
若需要演示数据能力，可使用：

```bash
cd backend
export JWT_SECRET="your-demo-secret"
mvn spring-boot:run -Dspring-boot.run.profiles=demo
```

`application-demo.yml` 会覆盖数据源为 H2 本地文件数据库，默认路径为 `backend/data/swjtu-forum-demo.mv.db`，并提供演示用 JWT 默认值。该 profile 适合课程答辩和本机 smoke test，不需要 MySQL 账号密码。

H2 控制台地址：

```text
http://localhost:8080/api/h2-console
```

连接信息：

```text
JDBC URL: jdbc:h2:file:./data/swjtu-forum-demo
User Name: sa
Password: 留空
```

## 6. 联调启动顺序

推荐顺序：

1. 演示环境：直接使用 `mvn spring-boot:run -Dspring-boot.run.profiles=demo` 启动后端，H2 会自动建表并写入 demo 数据。
2. 正式 MySQL 环境：启动 MySQL 和 Redis，初始化数据库，设置 `JWT_SECRET` 与必要数据库配置。
3. 启动前端。

## 8. 常见问题

### 8.1 后端启动时报 JWT 配置错误
请检查：
- 是否已显式设置 `JWT_SECRET`
- 环境变量是否在当前终端会话中生效

### 8.2 后端无法连接数据库
请检查：
- 演示环境是否已经使用 `-Dspring-boot.run.profiles=demo`
- 正式环境下 MySQL 是否启动
- `swjtu_forum` 是否已创建
- `DB_URL` / `DB_USERNAME` / `DB_PASSWORD` 是否正确

### 8.3 前端页面请求失败
请检查：
- 后端是否已启动在 `8080`
- 前端是否通过 Vite 启动
- `/api` 代理是否正常生效
