# 交大校园论坛系统 - 前端开发完成说明

## 一、技术栈

### 1.1 核心技术
- Vite 5.0.0 - 前端构建与开发服务器
- 原生 HTML / JavaScript - 页面渲染与交互逻辑
- 多页面应用（MPA）结构 - 每个页面独立入口

### 1.2 前后端协作方式
- 前端通过 Vite 开发服务器运行在 `5173`
- 所有前端请求统一访问 `/api/...`
- `vite.config.js` 将 `/api` 代理到后端 `http://localhost:8080`

## 三、架构说明

### 3.1 多页面架构
本项目当前前端不是 Vue Router 驱动的单页应用，而是 **Vite 多页面应用**。每个业务页面都有独立 HTML 入口，并通过 `vite.config.js` 注册为构建入口。

### 3.2 共享逻辑入口
前端的主要业务逻辑集中在：
- `frontend/assets/app.js`

该文件负责：
- 页面初始化与跳转逻辑
- 本地会话管理（token / userInfo）
- 通用 API 请求封装
- 各页面的数据加载与交互逻辑
- Toast 提示、错误处理、基础工具函数

### 3.3 页面识别机制
每个页面通过 `body data-page` 标识当前页面类型，共享脚本在启动时根据页面类型分发到对应初始化逻辑。

该测试主要验证：

## 六、当前不足与后续优化方向

### 6.1 架构层面
- `assets/app.js` 仍承担较多页面逻辑，后续可继续模块化拆分
- 页面数量增加后，共享脚本维护成本会上升

### 6.2 测试层面
- 缺少关键用户流程 E2E 测试
- 缺少更细粒度的页面交互回归测试

### 6.3 产品层面
- 举报、通知、评论治理、版块管理等闭环仍可继续补强
- 页面体验和空态/异常态仍有优化空间
