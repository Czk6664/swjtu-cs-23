# 后端安全证据

## Repository 查询审计

审计命令：

```powershell
rg -n "@Query|nativeQuery|createNativeQuery|EntityManager|StringBuilder|SELECT|select|\\+.*Query|Query.*\\+" backend/src/main/java/com/swjtu/forum/repository backend/src/main/java/com/swjtu/forum/service
```

当前审计结果：

| 文件 | 查询 | 结论 |
|---|---|---|
| `PostRepository.java` | `searchPublished` | JPQL 命名参数 `:status`、`:keyword`，未拼接 SQL |
| `PostRepository.java` | `recommendByTagIds` | JPQL 命名参数 `:tagIds`、`:tagIdsEmpty` |
| `PostRepository.java` | `findHotPosts` | 固定 JPQL，无用户输入 |

未发现 `nativeQuery`、`createNativeQuery`、`EntityManager` 动态 SQL 或 `StringBuilder` 拼接查询。

## SQL 注入结论

所谓 “PostRepository SQL 注入” 属于误报。当前查询使用 Spring Data JPA JPQL 参数绑定，用户输入作为参数传递，不会拼入 SQL 语句结构。

新增测试：

- `GrowthDiscoveryServiceTest.searchPostsTreatsHostileKeywordAsBoundQueryData`

该测试使用包含 SQL 片段和脚本片段的 hostile keyword，验证业务层只做 trim，并把该字符串作为参数传给 `postRepository.searchPublished`。

## DTO 校验覆盖

| DTO | 校验点 |
|---|---|
| `LoginRequest` | 用户名、密码非空 |
| `RegisterRequest` | 用户名长度、密码长度、邮箱格式 |
| `PostRequest` | 标题非空和长度、正文非空和长度、封面链接长度 |
| `CommentRequest` | 评论非空和长度 |
| `CreateReportRequest` | 举报原因非空和长度、补充说明长度 |
| `RecommendationConfigRequest` | 推荐权重范围 |
| `UserProfileUpdateRequest` | 头像、简介、学院、专业、学号长度 |
| `CampusIdentityVerifyRequest` | 校园邮箱格式、学号格式 |
| `AdminPostManageRequest` | 管理员编辑帖子字段长度和状态范围 |

## 权限覆盖

后台接口通过 `@PreAuthorize` 控制：

- `hasRole('ADMIN')`
- `hasAnyRole('MODERATOR', 'ADMIN')`

安全测试和控制器测试覆盖认证、权限、校验和核心服务契约。后续新增后台接口时，应同步补充权限注解和测试。
