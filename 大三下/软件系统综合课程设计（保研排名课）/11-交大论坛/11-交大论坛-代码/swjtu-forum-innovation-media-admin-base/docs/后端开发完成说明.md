# 交大校园论坛系统 - 后端开发完成说明

## 一、技术栈

### 1.1 核心框架
- Spring Boot 3.2.0
- Java 17
- Maven

### 1.2 数据与缓存
- Spring Data JPA
- MySQL 8.x
- Redis

### 1.3 安全认证
- Spring Security
- JWT 无状态认证
- BCrypt 密码加密

### 1.4 其他基础能力
- Jakarta Validation
- Lombok

## 二、项目结构

```text
backend/
├── pom.xml
└── src/
    ├── main/
    │   ├── java/com/swjtu/forum/
    │   │   ├── ForumApplication.java
    │   │   ├── controller/            # 认证、帖子、用户、成长、管理等接口
    │   │   ├── service/               # 核心业务逻辑
    │   │   ├── repository/            # Spring Data JPA 数据访问层
    │   │   ├── entity/                # 实体模型
    │   │   ├── dto/                   # 请求/响应 DTO
    │   │   ├── security/              # JWT、权限、认证失败处理
    │   │   ├── exception/             # 全局异常处理
    │   │   └── config/                # demo seed 等配置
    │   └── resources/
    │       ├── application.yml
    │       ├── application-demo.yml
    │       └── schema.sql
    └── test/
        └── java/com/swjtu/forum/      # 服务层、安全契约、异常契约测试
```

## 四、数据库模型

当前数据库结构以：
- `backend/src/main/resources/schema.sql`

为主要结构来源。

根目录的：
- `init-database.sql`

用于本地快速初始化数据库，并通过 `SOURCE backend/src/main/resources/schema.sql;` 调用主结构脚本。

主要数据表包括：
- `users`
- `sections`
- `tags`
- `posts`
- `post_tags`

- `post_browse_history`
- `operation_logs`
- `points_history`
- `reward_items`
- `redemption_requests`

## 五、接口风格与安全控制

### 5.1 返回结构
后端接口统一采用 `ApiResponse<T>` 返回：
- `code`
- `message`
- `data`

### 5.2 权限控制
- 登录、注册开放匿名访问
- 帖子/版块部分 GET 接口允许匿名访问
- 用户交互能力需要登录
- 管理后台接口通过角色控制（`MODERATOR` / `ADMIN`）

### 5.3 安全实现
- 使用 JWT 进行无状态认证
- Spring Security 统一权限控制
- 用户密码采用加密存储
- 全局异常统一转换为 API 响应

## 七、运行方式

```bash
cd backend
mvn spring-boot:run
mvn test
mvn clean package
```

默认情况下：
- 服务端口：`8080`
- 上下文路径：`/api`

可使用 `demo` profile 启用演示数据能力：

```bash
mvn spring-boot:run -Dspring-boot.run.profiles=demo
```

## 八、配置说明

项目运行配置以 `application.yml` 为基础，并支持通过环境变量覆盖数据库、Redis、JWT 与日志参数。

重点说明：
- `JWT_SECRET` 必须显式提供，不能依赖公共默认值
- `DB_PASSWORD` 应通过环境变量注入
- 开发阶段可保留较详细日志；共享环境与正式环境应降低日志级别，并关闭不必要的 SQL 输出

更完整的说明请参考：
- `docs/启动与配置说明.md`
