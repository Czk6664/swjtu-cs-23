## 本层内容介绍

这里是“软件系统综合课程设计”课程下的“部署手册”目录，主要用于整理项目说明、设计或报告材料。

**阅读建议：**优先阅读成稿了解目标、方法和结果，研究实现或排版时再查看源文件。

### 本层有哪些内容

本目录及子目录共收录 **11 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

| 子目录 | 内容与用途 |
| --- | --- |
| [figures](figures/README.md) | 图像、插图或配套素材 |

- **排版源文件（3 份）**：[deploy_report.tex](deploy_report.tex)、[mybib.bib](mybib.bib)等；完整列表见本页导航。
- **文档与说明（1 份）**：[部署手册.pdf](%E9%83%A8%E7%BD%B2%E6%89%8B%E5%86%8C.pdf)。
