## 本层内容介绍

这里是“智能嵌入式系统设计”课程下的“UCOSII其他学习文档”目录，主要用于整理芯片、模块或嵌入式系统相关参考文档。

**阅读建议：**先核对所用硬件型号和软件版本，再查阅接口、参数与使用方法。

### 本层有哪些内容

本目录及子目录共收录 **6 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（5 份）**：[UCOSII 2.90 ReleaseNotes.PDF](UCOSII%202.90%20ReleaseNotes.PDF)、[Ucos_II_中文注释版.pdf](Ucos_II_%E4%B8%AD%E6%96%87%E6%B3%A8%E9%87%8A%E7%89%88.pdf)等；完整列表见本页导航。
- **演示文稿（1 份）**：[uCOS-II信号量集.ppt](uCOS-II%E4%BF%A1%E5%8F%B7%E9%87%8F%E9%9B%86.ppt)。
