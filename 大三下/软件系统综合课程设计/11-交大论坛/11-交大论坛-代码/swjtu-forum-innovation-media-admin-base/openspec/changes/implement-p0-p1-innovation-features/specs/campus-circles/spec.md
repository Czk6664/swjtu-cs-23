## ADDED Requirements

### Requirement: 用户可以浏览校园兴趣圈子
系统 SHALL 提供校园兴趣圈子列表和圈子详情。

#### Scenario: 浏览圈子列表
- **WHEN** 用户打开圈子入口
- **THEN** 系统展示可见圈子的名称、简介、成员数和基础状态

### Requirement: 登录用户可以创建圈子
系统 SHALL 允许登录用户创建校园兴趣圈子，并记录创建者。

#### Scenario: 创建新圈子
- **WHEN** 登录用户提交合法圈子名称和简介
- **THEN** 系统创建圈子，记录创建者，并将创建者加入圈子成员

### Requirement: 用户可以加入和退出圈子
系统 SHALL 允许登录用户加入或退出可见圈子。

#### Scenario: 加入圈子
- **WHEN** 登录用户请求加入一个正常状态的圈子
- **THEN** 系统创建成员关系并更新圈子成员数

#### Scenario: 退出圈子
- **WHEN** 已加入用户请求退出圈子
- **THEN** 系统删除成员关系并更新圈子成员数

### Requirement: 帖子可以归属圈子
系统 SHALL 允许帖子可选关联到一个圈子，同时保留原版块归属。

#### Scenario: 发布圈内帖子
- **WHEN** 用户在发帖时选择圈子
- **THEN** 系统保存帖子所属圈子，并可在圈子详情页查询到该帖子

### Requirement: 圈子功能不影响普通发帖
系统 MUST 保持不选择圈子时的普通发帖流程不变。

#### Scenario: 发布普通帖子
- **WHEN** 用户发帖时不选择圈子
- **THEN** 系统按现有版块帖子流程创建帖子，帖子不归属任何圈子
