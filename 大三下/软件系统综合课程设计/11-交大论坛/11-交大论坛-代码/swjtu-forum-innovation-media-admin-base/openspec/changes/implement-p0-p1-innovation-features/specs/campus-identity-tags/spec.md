## ADDED Requirements

### Requirement: 用户可以查看可选校园身份标签
系统 SHALL 提供兴趣/身份标签列表，供用户在个人主页选择。

#### Scenario: 打开标签选择区
- **WHEN** 登录用户打开个人主页标签设置
- **THEN** 系统返回预置的校园身份和兴趣标签列表

### Requirement: 用户可以更新自己的身份标签
系统 SHALL 允许登录用户更新自己的兴趣/身份标签。

#### Scenario: 保存用户标签
- **WHEN** 登录用户提交标签 ID 或标签名称列表
- **THEN** 系统更新当前用户的兴趣标签集合并返回最新标签

### Requirement: 用户标签与帖子标签保持边界
系统 MUST 避免用户身份标签误修改帖子标签。

#### Scenario: 用户更新身份标签
- **WHEN** 用户保存个人兴趣标签
- **THEN** 系统只更新当前用户的 `user_tags` 关系，不修改任何帖子标签

### Requirement: 个人主页展示身份标签
系统 SHALL 在个人主页展示用户已选择的校园身份标签。

#### Scenario: 浏览个人主页
- **WHEN** 用户打开自己的个人主页
- **THEN** 页面展示当前身份标签，并允许继续编辑
