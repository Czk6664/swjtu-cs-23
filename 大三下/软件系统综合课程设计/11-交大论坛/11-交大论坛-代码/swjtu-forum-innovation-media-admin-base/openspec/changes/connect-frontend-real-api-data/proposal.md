## Why

当前前端页面已经完成了“西南交大论坛”风格落地，但大部分内容仍是静态示例，无法体现系统真实的数据流、权限边界和业务闭环。后端实际上已经提供了认证、帖子、成长、举报与后台治理接口，现在需要把多页前端真正接到这些接口上，才能把项目从“可展示原型”推进到“可联调演示系统”。

## What Changes

- 将共享前端运行时改造成真实的 `/api` 调用入口，统一处理 `ApiResponse` 包装、JWT、登录态恢复、错误反馈和空态展示。
- 将首页、帖子详情、发帖页、个人中心等论坛核心页面接入真实的帖子、评论、分区、收藏、点赞、浏览历史和个人资料接口。
- 将成长中心与积分商城接入真实的签到、积分流水、奖励列表、兑换申请与兑换记录接口。
- 将运营总览、内容治理、用户管理、推荐策略页面接入真实的举报、待审核帖子、用户列表、推荐配置与预览接口，并支持关键后台操作。
- 用真实接口返回的数据替换当前硬编码示例文案，同时为后端尚未覆盖的展示区保留显式“待接入”占位，不再混入 mock 内容。

## Capabilities

### New Capabilities
- `authenticated-forum-session`: 前端能够使用真实认证接口建立、恢复和清理论坛登录态，并在需要权限的页面保护写操作。
- `forum-live-content`: 论坛前台页面能够展示和提交真实的分区、帖子、评论、互动和个人帖子数据。
- `growth-live-operations`: 成长中心和积分商城能够展示真实成长数据，并触发签到与兑换等用户操作。
- `admin-live-operations`: 后台页面能够展示真实治理与运营数据，并执行审核、封禁、推荐配置等管理操作。

### Modified Capabilities
- None.

## Impact

- 前端：`frontend/assets/app.js`、多页 `code.html` 页面结构、共享样式中的加载/错误/空态容器。
- 后端联调面：`/api/auth/*`、`/api/users/*`、`/api/sections`、`/api/posts/*`、`/api/growth/*`、`/api/admin/*`。
- 测试与验证：前端构建、关键页面联调检查、必要的运行时 smoke test。
