# 服务器部署检查

本文档用于把西南交大论坛部署到服务器前做最后确认，覆盖后端、前端、环境变量和上线后验收。

## 1. 构建产物

后端：

```powershell
cd backend
mvn test
mvn -DskipTests package
```

产物位置：

```text
backend/target/forum-1.0.0.jar
```

前端：

```powershell
cd frontend
npm install
npm test
npm run build
```

产物位置：

```text
frontend/dist/
```

## 2. 后端部署环境变量

建议正式服务器使用 `mysql` profile，并显式设置以下环境变量：

```bash
SPRING_PROFILES_ACTIVE=mysql
SERVER_PORT=8080
DB_URL=jdbc:mysql://127.0.0.1:3306/swjtu_forum?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
DB_USERNAME=swjtu_forum
DB_PASSWORD=替换为数据库密码
JWT_SECRET=替换为至少32字符的随机密钥
APP_ADMIN_USERNAME=admin
APP_ADMIN_PASSWORD=替换为强密码
APP_ADMIN_EMAIL=admin@swjtu.edu.cn
APP_CORS_ALLOWED_ORIGIN_PATTERNS=https://你的域名,http://你的服务器IP:4173
```

如果前端和后端通过 Nginx 部署在同一个域名下，并把 `/api` 反向代理到后端，`APP_CORS_ALLOWED_ORIGIN_PATTERNS` 可以保留默认本地配置。

启动后端：

```bash
java -Dfile.encoding=UTF-8 -jar backend/target/forum-1.0.0.jar
```

## 3. 前端部署方式

推荐使用 Nginx 托管 `frontend/dist`，并把 `/api` 转发到后端。

示例：

```nginx
server {
    listen 80;
    server_name your-domain.example;

    root /opt/swjtu-forum/frontend/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

如果临时使用 Vite preview：

```bash
cd frontend
BACKEND_PORT=8080 npm run preview -- --host 0.0.0.0 --port 4173
```

## 4. 数据库准备

创建数据库：

```sql
CREATE DATABASE swjtu_forum DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

项目当前使用 JPA `ddl-auto=update`，首次启动会自动建表。若课程要求导入 SQL，可使用：

```text
backend/src/main/resources/schema.sql
```

## 5. 上线后验收清单

普通用户：

- 注册新账号成功。
- 登录后进入首页不刷新循环。
- 首页能加载板块、帖子、今日热词云。
- 能发帖、评论、采纳评论。
- 能进入圈子并加入圈子。
- 能查看成长、徽章、个人页。
- 普通用户误入后台时不清空登录态，不出现权限不足卡死。

管理员：

- 使用管理员账号登录。
- 数据大屏正常加载。
- 用户管理正常加载。
- 内容治理正常加载待审核帖子和举报列表。

部署健康检查：

```bash
curl http://127.0.0.1:8080/api/sections
curl http://127.0.0.1:8080/api/posts/hot
curl http://你的域名/home_recommended_desktop/code.html
```
