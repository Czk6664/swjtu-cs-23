### 🚀 下一步操作

#### 最简单的启动流程：

1. **安装Maven**（5分钟）
   ```powershell
   # 管理员模式打开PowerShell
   choco install maven -y
   ```

2. **创建数据库**（2分钟）
   - 打开MySQL Workbench
   - 执行 `backend/src/main/resources/schema.sql`

3. **修改配置**（1分钟）
   - 编辑 `backend/src/main/resources/application.yml`
   - 修改MySQL密码

4. **启动后端**（2分钟）
   ```powershell
   cd backend
   mvn spring-boot:run
   ```

5. **验证**（1分钟）
   - 访问 http://localhost:8080/api/posts
   - 前端自动连接后端
