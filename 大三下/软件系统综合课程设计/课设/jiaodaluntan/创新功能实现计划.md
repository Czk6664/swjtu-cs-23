## 二、P0 功能详细设计

### 2.1 问答采纳功能

**目标：** 课程互助版块的帖子，楼主可以把某条回复标记为「最佳答案」，帖子标题自动加上 [已解决] 标记。

**数据模型变更：**

```sql
-- comments 表新增
ALTER TABLE comments ADD COLUMN accepted BOOLEAN NOT NULL DEFAULT FALSE;

-- posts 表新增
ALTER TABLE posts ADD COLUMN accepted_comment_id BIGINT;
```

**后端改动：**

| 文件 | 改动 |
|------|------|
| `entity/Comment.java` | 添加 `accepted` 字段 |
| `entity/Post.java` | 添加 `acceptedCommentId` 字段 |
| `repository/CommentRepository.java` | 添加 `countByAuthorIdAndAcceptedTrue()`、`countByAuthorId()` |
| `controller/PostController.java` | 添加采纳/取消采纳接口 |
| `service/PostService.java` | 采纳逻辑：只有帖子作者可采纳，每帖最多采纳 1 条 |

**API：**

```
POST   /posts/{postId}/comments/{commentId}/accept   → 采纳
DELETE /posts/{postId}/comments/{commentId}/accept   → 取消采纳
```

**业务规则：**
- 只有帖子作者可以采纳
- 每个帖子最多采纳 1 条（重新采纳自动取消之前的）
- 采纳后被采纳者 +10 贡献值
- 采纳后触发被采纳者徽章检查

**前端改动：**

| 文件 | 改动 |
|------|------|
| `detail.js` | 评论区显示「采纳」按钮（仅楼主可见）；已采纳评论高亮 |
| `ui.js` | 帖子卡片标题前显示 `[已解决]` 标记 |
| `home.js` | 帖子列表中显示 `[已解决]` |

## 四、P2 功能详细设计

### 4.1 弹幕评论

**目标：** 活动帖、视频帖支持弹幕式浮动评论。

**数据模型：**

```sql
CREATE TABLE danmaku (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    post_id BIGINT NOT NULL,
    user_id BIGINT NOT NULL,
    content VARCHAR(100) NOT NULL,
    color VARCHAR(10) DEFAULT '#FFFFFF',
    position INT DEFAULT 0,  -- 弹幕出现时间点（秒）
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

**后端新增文件：**

| 文件 | 职责 |
|------|------|
| `entity/Danmaku.java` | 弹幕实体 |
| `repository/DanmakuRepository.java` | 弹幕数据访问 |
| `service/DanmakuService.java` | 弹幕业务逻辑 |
| `controller/DanmakuController.java` | 弹幕 API |

**API：**

```
GET  /posts/{id}/danmaku       → 获取帖子的弹幕列表
POST /posts/{id}/danmaku       → 发送弹幕
```

**前端实现：**
- CSS animation 实现弹幕从右向左飘过
- 弹幕层覆盖在帖子内容上方（半透明背景）
- 发送弹幕输入框固定在帖子底部

**业务规则：**
- 弹幕最长 100 字
- 每人每帖每分钟最多 5 条
- 弹幕需要审核（status 字段）
- 管理员可关闭某帖子的弹幕功能

## 六、风险与注意事项

| 风险 | 应对 |
|------|------|
