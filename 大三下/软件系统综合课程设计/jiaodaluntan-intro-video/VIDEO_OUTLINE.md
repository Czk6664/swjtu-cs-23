# 交大论坛 — 演示视频大纲

> 格式：HyperFrames HTML 合成 → MP4
> 总时长：约 60 秒
> 分辨率：1920x1080 (16:9)
> 风格：交大蓝学术风（#308FF0 主色），深色背景 + 白色卡片，动效简洁

---

## 视觉风格

- **主色**：#308FF0（交大蓝）
- **渐变**：#0070C0 → #3354B5（深蓝渐变）
- **强调**：#0E6BC9（线条/边框）
- **辅助色**：#ED7D31（橙）、#70AD47（绿）、#FFC000（黄）
- **背景**：深色 #0A1628 → #1A2A4A 渐变
- **卡片**：白色圆角 + #0064D8 蓝色辉光阴影
- **字体**：微软雅黑（中文）、Arial（英文）
- **动效**：淡入淡出、缩放、滑入，节奏感强

---

## 场景分镜

### Scene 1 — 开场（0s ~ 5s）

**画面**：深蓝渐变背景 + 粒子/光点缓慢浮动
**动画**：
1. 西南交通大学 LOGO 淡入居中（0-1s）
2. 主标题「交大论坛」从下方滑入 + 缩放（1-3s），白色渐变字 + 辉光
3. 副标题「校园社区系统」淡入（3-4s）
4. 底部标签条淡入：`Spring Boot` `Vite` `JWT` `智能推荐`（4-5s）

---

### Scene 2 — 痛点引出（5s ~ 12s）

**画面**：三张卡片依次从左滑入
**动画**：卡片1（5-7s）→ 卡片2（7-9s）→ 卡片3（9-11s）→ 全部缩小排列（11-12s）

| 卡片 | 图标 | 标题 | 描述 |
|------|------|------|------|
| 1 | 碎片图标 | 信息碎片化 | QQ群/微信群/贴吧分散 |
| 2 | 学校图标 | 缺乏校园特色 | 通用平台无法满足校园场景 |
| 3 | 下降图标 | 互动不足 | 缺乏成长激励，留存率低 |

过渡文字淡入：「我们的解决方案 →」

---

### Scene 3 — 技术架构（12s ~ 20s）

**画面**：分层架构图从上到下依次构建
**动画**：
1. 顶层蓝色块「前端 Vite MPA · 17页面」从顶部落入（12-14s）
2. 中间绿色块「Spring Boot 3.2 · 10 Controller · 13 Service」从左滑入（14-16s）
3. 底层橙色块「MySQL / H2 · 24张表」从底部升起（16-18s）
4. 层间连线动画绘制：REST API / JPA（18-19s）
5. 右侧小标签浮现：`JWT认证` `RBAC权限` `AOP横切`（19-20s）

---

### Scene 4 — 核心功能展示（20s ~ 42s）

每个功能模块 3-4 秒，配网站截图 + 功能要点文字。

#### 4a — 首页推荐流（20-25s）
**画面**：左侧首页瀑布流截图（带手机框 mockup），右侧浮现文字
- 「四维加权推荐」标题淡入
- 四个小图标+文字依次出现：热度 · 标签匹配 · 社交关系 · 时效衰减
- 底部小字：「管理后台可动态调权」

#### 4b — 帖子与互动（25-30s）
**画面**：帖子详情页截图 + 互动按钮放大动画
- 左侧：发帖界面截图
- 右侧：点赞❤️/收藏⭐/评论💬 图标弹跳动画
- 文字：「富文本 · 版块标签 · 楼中楼评论 · 举报」

#### 4c — 成长激励（30-35s）
**画面**：成长中心 + 积分商城截图
- 进度条动画从 0 填充到 80%（经验值）
- 数字滚动：积分 0 → 2580
- 右侧文字列表：「签到 · 积分 · 等级 · 徽章 · 商城兑换」

#### 4d — 管理后台（35-42s）
**画面**：管理仪表盘截图 + 数据卡片动画
- 统计数字从 0 滚动上升（用户数、帖子数、评论数）
- 六宫格功能图标矩阵淡入：数据统计 / 内容审核 / 举报处理 / 用户管理 / 版块管理 / 推荐调控
- 推荐权重滑块滑动动画

---

### Scene 5 — 软件工程知识映射（42s ~ 50s）

**画面**：左侧课程章节列表，右侧对应项目实践，连线动画
**动画**：
1. 左列 6 个课程知识点从左侧依次滑入（42-46s）：
   - 需求工程 → 增量模型 → UML建模 → 体系结构 → AOP → 软件测试
2. 右列对应实践从右侧依次滑入（44-48s）：
   - 6大模块 → 3轮迭代 → 4种图 → B/S三层 → Spring AOP → 三层测试
3. 中间蓝色连线动画从上到下绘制（46-50s）

---

### Scene 6 — 创新亮点（50s ~ 55s）

**画面**：2×2 网格，四个亮点卡片同时从四角飞入
**动画**：四张卡片同时从屏幕四角向中心聚合（50-52s），然后依次高亮闪烁（52-55s）

| 位置 | 颜色 | 标题 | 关键词 |
|------|------|------|--------|
| 左上 | #308FF0 | 小红书式体验 | 瀑布流 · 移动适配 |
| 右上 | #ED7D31 | 四维推荐引擎 | 热度×标签×社交×时效 |
| 左下 | #70AD47 | 成长激励闭环 | 签到→积分→等级→商城 |
| 右下 | #FFC000 | 全链路治理 | 审核·举报·调控·仪表盘 |

---

### Scene 7 — 结尾（55s ~ 60s）

**画面**：回到深蓝渐变背景
**动画**：
1. 所有元素淡出（55-56s）
2. 「交大论坛」大标题重新淡入 + 辉光脉冲（56-57s）
3. 在线体验地址淡入：`http://47.108.218.39:8082/`（57-58s）
4. 团队信息淡入：程泽凯 · 金井直 · 赵祺 · 蒋焰（58-59s）
5. 西南交通大学 LOGO + 「软件系统综合课程设计 · 2026」淡入（59-60s）

