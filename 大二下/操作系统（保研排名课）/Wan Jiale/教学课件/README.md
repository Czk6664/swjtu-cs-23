## 本层内容介绍

这里是“操作系统”课程下的“教学课件”目录，主要用于整理课堂讲授、章节讲义或复习课件。

**阅读建议：**按课堂章节顺序阅读，记录核心概念与例题；复习时回到不熟悉的章节查漏补缺。

### 本层有哪些内容

本目录及子目录共收录 **12 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（12 份）**：[OS00-EN.pdf](OS00-EN.pdf)、[OS01-EN.pdf](OS01-EN.pdf)等；完整列表见本页导航。
