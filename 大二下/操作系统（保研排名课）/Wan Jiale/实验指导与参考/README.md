## 本层内容介绍

这里是“操作系统”课程下的“实验指导与参考”目录，主要用于整理实验目的、步骤或操作参考材料。

**阅读建议：**实验前阅读准备事项与操作过程，明确要观察和记录的结果，再动手完成实验。

### 本层有哪些内容

本目录及子目录共收录 **2 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（2 份）**：[实验6 系统调用.docx](%E5%AE%9E%E9%AA%8C6%20%E7%B3%BB%E7%BB%9F%E8%B0%83%E7%94%A8.docx)、[实验7 系统缺页次数统计.docx](%E5%AE%9E%E9%AA%8C7%20%E7%B3%BB%E7%BB%9F%E7%BC%BA%E9%A1%B5%E6%AC%A1%E6%95%B0%E7%BB%9F%E8%AE%A1.docx)。
