## 本层内容介绍

这里是“操作系统”课程下的“教学题目与参考”目录，主要用于整理教学题目、思考题或配套参考材料。

**阅读建议：**先独立分析题目，再对照已有参考材料检查思路；是否含解答以具体文件为准。

### 本层有哪些内容

本目录及子目录共收录 **2 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（2 份）**：[2020期末模拟.pdf](2020%E6%9C%9F%E6%9C%AB%E6%A8%A1%E6%8B%9F.pdf)、[2022年2020级《操作系统》期末试卷A卷4.docx](2022%E5%B9%B42020%E7%BA%A7%E3%80%8A%E6%93%8D%E4%BD%9C%E7%B3%BB%E7%BB%9F%E3%80%8B%E6%9C%9F%E6%9C%AB%E8%AF%95%E5%8D%B7A%E5%8D%B74.docx)。
