## 本层内容介绍

这里是“毛泽东思想和中国特色社会主义理论体系概论”课程下的“maogai”目录，主要用于整理该主题的文档与参考材料。

**阅读建议：**先根据下方文件名选择相关文档，再结合上级介绍理解背景；原文件中的说明优先。

### 本层有哪些内容

本目录及子目录共收录 **19 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **演示文稿（10 份）**：[0.0前言：自我介绍、为什么学、学什么、怎样学、怎样考核.pptx](0.0%E5%89%8D%E8%A8%80%EF%BC%9A%E8%87%AA%E6%88%91%E4%BB%8B%E7%BB%8D%E3%80%81%E4%B8%BA%E4%BB%80%E4%B9%88%E5%AD%A6%E3%80%81%E5%AD%A6%E4%BB%80%E4%B9%88%E3%80%81%E6%80%8E%E6%A0%B7%E5%AD%A6%E3%80%81%E6%80%8E%E6%A0%B7%E8%80%83%E6%A0%B8.pptx)、[0.0导论单选题和多选题.pptx](0.0%E5%AF%BC%E8%AE%BA%E5%8D%95%E9%80%89%E9%A2%98%E5%92%8C%E5%A4%9A%E9%80%89%E9%A2%98.pptx)等；完整列表见本页导航。
- **文档与说明（9 份）**：[0.1专题一（导论‘）：马克思主义中国化时代化的历史进程与理论成果.pdf](0.1%E4%B8%93%E9%A2%98%E4%B8%80%EF%BC%88%E5%AF%BC%E8%AE%BA%E2%80%98%EF%BC%89%EF%BC%9A%E9%A9%AC%E5%85%8B%E6%80%9D%E4%B8%BB%E4%B9%89%E4%B8%AD%E5%9B%BD%E5%8C%96%E6%97%B6%E4%BB%A3%E5%8C%96%E7%9A%84%E5%8E%86%E5%8F%B2%E8%BF%9B%E7%A8%8B%E4%B8%8E%E7%90%86%E8%AE%BA%E6%88%90%E6%9E%9C.pdf)、[0.2.专题二（第一章）毛泽东思想及其历史地位.pdf](0.2.%E4%B8%93%E9%A2%98%E4%BA%8C%EF%BC%88%E7%AC%AC%E4%B8%80%E7%AB%A0%EF%BC%89%E6%AF%9B%E6%B3%BD%E4%B8%9C%E6%80%9D%E6%83%B3%E5%8F%8A%E5%85%B6%E5%8E%86%E5%8F%B2%E5%9C%B0%E4%BD%8D.pdf)等；完整列表见本页导航。
