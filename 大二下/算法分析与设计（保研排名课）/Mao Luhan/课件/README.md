## 本层内容介绍

这里是“算法分析与设计”课程下的“课件”目录，主要用于整理课堂讲授、章节讲义或复习课件。

**阅读建议：**按课堂章节顺序阅读，记录核心概念与例题；复习时回到不熟悉的章节查漏补缺。

### 本层有哪些内容

本目录及子目录共收录 **7 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **文档与说明（7 份）**：[00.课程概述.pdf](00.%E8%AF%BE%E7%A8%8B%E6%A6%82%E8%BF%B0.pdf)、[01.绪论.pdf](01.%E7%BB%AA%E8%AE%BA.pdf)等；完整列表见本页导航。
