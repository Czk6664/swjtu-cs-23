## 本层内容介绍

这里是“算法分析与设计”课程下的“作业答案”目录，主要用于整理复习、试题或解答参考材料。

**阅读建议：**先用题目检验掌握程度，再核对解答并回看对应知识点；历史题目不代表本次考试范围。

本目录及子目录共收录 **7 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。
