## 本层内容介绍

这里是“算法分析与设计”课程下的“作业”目录，主要用于整理该项课程实践的相关材料，具体内容见下方文件与子目录。

**阅读建议：**先读任务或报告了解目标，再看代码、数据和结果；借鉴方法后独立完成自己的任务。

### 本层有哪些内容

本目录及子目录共收录 **30 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **演示文稿（4 份）**：[04分治法.pptx](04%E5%88%86%E6%B2%BB%E6%B3%95.pptx)、[07回溯法时间复杂性分析.pptx](07%E5%9B%9E%E6%BA%AF%E6%B3%95%E6%97%B6%E9%97%B4%E5%A4%8D%E6%9D%82%E6%80%A7%E5%88%86%E6%9E%90.pptx)等；完整列表见本页导航。
- **文档与说明（26 份）**：[05动态规划.pdf](05%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92.pdf)、[2024112639_Mao Luhan_作业2.pdf](2024112639_Mao%20Luhan_%E4%BD%9C%E4%B8%9A2.pdf)等；完整列表见本页导航。
