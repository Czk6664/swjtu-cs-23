## 本层内容介绍

这里是“数据库原理与设计”课程下的“教学题目与参考”目录，主要用于整理教学题目、思考题或配套参考材料。

**阅读建议：**先独立分析题目，再对照已有参考材料检查思路；是否含解答以具体文件为准。

### 本层有哪些内容

本目录及子目录共收录 **4 份文件**（不含各层 README）；下面先介绍本层直接可见的内容。

- **演示文稿（4 份）**：[1.实验必须完成的环节＆＆实验一.pptx](1.%E5%AE%9E%E9%AA%8C%E5%BF%85%E9%A1%BB%E5%AE%8C%E6%88%90%E7%9A%84%E7%8E%AF%E8%8A%82%EF%BC%86%EF%BC%86%E5%AE%9E%E9%AA%8C%E4%B8%80.pptx)、[2.实验内容2--数据对象的创建（DDL应用实践）.pptx](2.%E5%AE%9E%E9%AA%8C%E5%86%85%E5%AE%B92--%E6%95%B0%E6%8D%AE%E5%AF%B9%E8%B1%A1%E7%9A%84%E5%88%9B%E5%BB%BA%EF%BC%88DDL%E5%BA%94%E7%94%A8%E5%AE%9E%E8%B7%B5%EF%BC%89.pptx)等；完整列表见本页导航。
