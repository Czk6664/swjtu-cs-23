## 本层内容介绍

本页汇总大二下已收录的 6 门课程，帮助你从学期定位到具体课程。课程目录名的推免标注需结合课程页的专业对照表理解。

**怎么用：**先对照自己的课表选择课程，再进入课程页查看内容介绍和建议学习顺序。这里的归档按 2023 级方案整理，当前年级的开课安排以学校公布信息为准。
